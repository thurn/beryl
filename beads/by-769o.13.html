Description

This change is made in the Enact repository at ~/enact (scripts/enact.py, tests in tests/test_unit.py and tests/test_integration.py), not in Beryl. Read ~/enact/AGENTS.md first and follow that repository's workflow; record design decisions in ~/enact/docs/design.md. Keep changes backward compatible: projects and live sessions on every machine run this repository directly.

Why

A run never ends explicitly: it counts as active until its epic closes and every commit reaches master. Beryl's by-gdn3 was fully delivered but stays open because two children are deferred, so its run looked active indefinitely.

What to change

  • Add enact run finish <epic> --reason ..., which sets the run's control state (enact_control) to finished. vizier_active, stopped_runs and enact status treat a finished run as not active, and enact next on a finished run reports that it is finished.
  • The vizier's skill text (skills/enact/SKILL.md and the relevant role files) calls enact run finish as the run's last step.
  • When deciding whether a run's epic is done, count deferred children as done, and let close_finished_epics close such an epic or mark its run finished.

Done when

Tests cover finishing a run, an epic with only deferred children left, and vizier_active ignoring a finished run.
