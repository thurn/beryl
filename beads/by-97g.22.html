Description

Part of the ladder epic by-97g. Read docs/ai-strategy.md first: §2.2, §5's table and §6.1.

Rung 1, build. Greedy alone gets these five suite positions right and the champion loses each in a near-tie: decline-mana-crypt, decline-both-teferi-untaps, decline-second-teferi-untap, discard-emperor-over-spare-crypt, skip-beza-after-winds. The option guard exists (commit 1c43427, by-97g.6) and is set by no agent, so this bead changes what it means.

Where

  • rust/crates/beryl_search/src/long.rs: guarded (the match d.kind), its doc comment, Options::guard's doc comment, and the tests the_guard_holds_at_combat_and_finds_and_nowhere_else and a_guarded_search_plays_greedy_at_combat_unless_clearly_beaten.
  • rust/crates/beryl_search/src/rollout.rs: RolloutPolicy::view and Policy::action, for a play's score.

Build

With guard set, guarded returns true (greedy's answer stands unless the search leads clearly) in exactly these cases, and search != greedy in each:

  1. DecisionKind::Attacker. (As today.)
  2. DecisionKind::ChooseUpTo, whatever its purpose. (Today: only Purpose::Search.)
  3. DecisionKind::ChooseObject when every candidate is a card in the deciding player's own hand (obs.object(slot).zone() == Zone::Hand and its owner is d.player) and d.prompt.purpose is not Purpose::PutOnBottom: a discard or a card exiled as a cost. A mulligan's bottom card stays the search's.
  4. DecisionKind::Priority when the search's choice is Opt::Cast or Opt::Activate and Policy::action scores that option 0 or less, whatever greedy's own answer is. Keep the existing exemption for a card whose never_cast flag is set.

Remove DecisionKind::AttackTarget from the guard: greedy's attack target is wrong at spare-jace-wielder until the combat rung.

Without guard, guarded is unchanged (a cast against greedy's pass).

Tests

  • Update the two guard tests: the guard holds at the four cases above and not at AttackTarget.
  • A family without guard plays as before (the existing unguarded-equals-plain test still passes untouched).
  • just test-rust, just check.
