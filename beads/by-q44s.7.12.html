Description

Read first: docs/beryl-3d.md 'Checks and isolation' (the exceptions: each change outside Beryl 3D's paths is a bead of its own and is listed there) and 'Bug reports'; tools/src/beryl_tools/mobile_bugs.py (BUGS_RELATIVE, copy_reports, simulator_container, android_reports, device_reports, run: how it pulls reports from the simulator's app container, the Android emulator and, with --device, the paired iPhone, all for mobile.BUNDLE_ID = "ca.thurn.beryl") and tools/tests/test_mobile_bugs.py; milestone 3's bug report bead and shared shell crate bead under by-q44s.5 (where Beryl 3D's app saves a report: the folder under its data directory and the file names); the mobile-bugs recipe in the justfile.

Why. just mobile-bugs pulls the Tauri phone app's saved bug reports into the Mac's bugs folder, where just bugs and the /bugfix skill find them. Beryl 3D's phone app (bundle and application id ca.thurn.beryl3d) saves reports too once milestone 3's bug report exists, and nothing pulls them.

Build: just mobile-bugs also pulls from ca.thurn.beryl3d on each place it already pulls from (the simulator, the emulator, and with --device the iPhone), into the same bugs folder, keeping each report's folder as it is (a report's id is unique across both apps, since both use the shared shell crate's storage) and printing the counts for each app separately. This changes tools/src/beryl_tools/mobile_bugs.py, a file of the main tools, so it is one of the doc's exceptions: add it to the list in 'Checks and isolation' in the same change. A missing Beryl 3D app on a device is not an error.

Tests: in tools/tests/test_mobile_bugs.py, a test with the subprocess calls replaced that a report found under ca.thurn.beryl3d's container is copied and marked, and that a device without the app is skipped.

Run: just test-py tools/tests/test_mobile_bugs.py; just mobile-bugs with the simulator booted after just b3d ios-smoke --text (the command must run, list Beryl 3D's app, and copy any report it finds).

Acceptance criteria

just test-py tools/tests/test_mobile_bugs.py passes with a test that a report under ca.thurn.beryl3d is copied and a device without the app is skipped; just mobile-bugs runs with the simulator booted; docs/beryl-3d.md 'Checks and isolation' lists the change among its exceptions.
