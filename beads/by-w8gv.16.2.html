What is wrong

Two whole-run acceptance items of Project 50k are not met, and the plan document is about to be retired.

  1. About 255 comments in about 196 source files cite the plan by decision id, for example rust/crates/beryl_card/src/ability.rs:46 "(plan K1)", beryl_card/src/lib.rs:13 "(plan K12)", and the card crates' Cargo.toml "(plan, Crates)". Root AGENTS.md forbids references to planning documents in code. The Archivist (by-w8gv.17) retires docs/project-50k.md, after which every one of these points at nothing. By area: beryl_session 65, tools/src 40, beryl_cards 16, ui/src 13, beryl_kernel 13, beryl_card 13, ui/scripts 12, beryl_rules 12, beryl_cli 9, beryl_card_build 8, the rest under 4 each. Find them with: git grep -En '\(plan[,)]|project-50k|plan K[0-9]+|\bK(1[0-9]|2[0-9]|3[01]|[1-9])\b' -- 'rust/**/*.rs' 'rust/**/*.toml' 'ui/src/**' 'ui/scripts/**' 'tools/src/**' (the last alternative also matches unrelated K words; check each hit).
  2. data/card-names-allowlist.json still has three entries, but whole-run acceptance says it is empty outside the expert system and the overlay:
    • rust/crates/beryl_session/src/sessions.rs:11,38 imports beryl_cards::decks::WU_CONTROL as the default deck when a StartRequest names none. Take the deck from the caller (the app shell or StartRequest) instead, or move the default into beryl_cards::decks behind a deck-neutral name such as decks::DEFAULT.
    • ui/src/screens/samples.ts:67 is the component gallery's stand-in cards (Counterspell and others). The check only counts one; either move the file under a directory the check exempts for fixtures, or replace the real names with made-up ones.
    • tools/src/beryl_tools/specs.py:427 names 'Teferi, Time Raveler' in an argparse help example. Use a made-up example or a slug.

Change

  • Rewrite each plan reference: delete it where the sentence stands without it, or point at the section of docs/engine-architecture.md that holds the decision (the Archivist is moving the decisions there; if the section does not exist yet, just delete the reference).
  • Add a source check to the names lane in tools/src/beryl_tools/checks.py (beside two-player and board-door) that fails on plan K<n>, (plan, and project-50k in rust/, ui/src, ui/scripts and tools/src, so the references do not come back.
  • Empty the card-names allowlist as above and run python -m beryl_tools.checks card-names --shrink.

Do not change behavior. Mechanical work.
