Close reason

just b3d perf prints per-fixture frame timing and load; ui-perf job set in parity.json

Description

Read first: tools/src/beryl_tools/shots.py ui_perf and ui/scripts/perf.mjs (measure, byVerb: which fixtures just ui-perf plays, --verbs, --phone, and what it reports per fixture and per verb); docs/beryl-3d.md 'Driving the running app' (app --fixture, --window, --load, the frame log, frames); tools/src/beryl_tools/beryl3d/app.py (how just b3d app and frames run and read a log).

just ui-perf times the web interface's frames playing recorded fixtures. Beryl 3D's equivalent is to play the same fixtures in the running app and read the frame logs.

Build just b3d perf in a new module tools/src/beryl_tools/beryl3d/perf.py:

  • Plays each fixture ui-perf plays (read the list from the same source shots.py uses; do not copy it), or those named, through just b3d app --fixture <name> --window none --for <the recording's length plus 1 s>; --window background passes through for a measurement of presentation; --phone plays the phone layout; --verbs groups frames by the verb playing, as byVerb does, from the frame log's lines.
  • Prints one line per fixture: frames drawn, late frames, worst and 95th-percentile client time, worst encode time, worst wait for a drawable, and a last line with the load average (rule 10: times are reported with the load, never gated).
  • Reuses app.py's functions to run the app and to read a log's summary.

Test in tools/tests/test_beryl3d_perf.py, on frame logs written by hand: the per-fixture line and the per-verb grouping. Run: just test-py tests/test_beryl3d_perf.py.

Each skill keeps working for the web interface until the switch: add a Beryl 3D section, never replace the web instructions. Register any new command through MODULES in tools/src/beryl_tools/beryl3d/cli.py with a COMMANDS tuple in your own module, --help and two examples (rule 19). When the job works, set this job's b3d in data/beryl3d/parity.json's tools to the command or skill section that does it. Rule 17: no new recipe in the justfile and no change to tools outside tools/src/beryl_tools/beryl3d except the skill's own files.

Acceptance criteria

just b3d perf verbs-zones prints the fixture's line and the load (output in a comment); just test-py tests/test_beryl3d_perf.py passes; parity.json's ui-perf job names the command; enact push passes.
