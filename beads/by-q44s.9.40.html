Description

The UI Conventions entry "Manual table pile viewers" (data/ui-conventions.json, no-equivalent) is still open for Beryl 3D: its rule is that the pile browser can be searched, grouped by card type and sorted by name or mana value; the other player sees how many cards are lifted from a library during a look; and closing a full library search offers Shuffle and Don't shuffle, with Shuffle highlighted.

Beryl 3D today opens a viewer only for a graveyard or an exile pile (rust/beryl3d/crates/beryl_scene/src/manual/viewers.rs, opens; the browser is rust/beryl3d/crates/beryl_scene/src/inspect/viewer.rs). It has no library viewer: the table's look action (the web's TableViewers.look in ui/src/table/viewers.ts, with portionSlots) is not followed, so there is no full library search to close with Shuffle, and no lifted count for the other seat. by-q44s.9.26 split this off because it would pass about 600 lines with the selection and drop-halves work.

Build, following the web (ui/src/table/TableViewer.tsx TablePileViewer, sections, manaValue, typeGroup; ui/src/table/viewers.ts):

  • the library viewer opened by the table's look commands, for a portion or the whole library;
  • the viewer's controls: a search field "Search cards", a "Group by type" toggle and the sort (Pile order, Sort by name, Sort by mana value), and the client commands in data/table-commands.json that drive them (search_viewer, group_viewer_by_type, sort_viewer_by_name, sort_viewer_by_mana_value, close_viewer, close_and_shuffle, close_without_shuffle);
  • closing a full library search shows Shuffle (primary) and Don't shuffle;
  • the opponent's seat sees the count of cards lifted from the library during a look.

Add a screen recording that shows a library search (rust/beryl3d/crates/beryl_inspect/src/screens.rs builds screen/table), then replace the entry's {"open"} in data/beryl3d/conventions/no-equivalent.json with {"recording", "at", "do"?, "shows"} (rust/beryl3d/crates/beryl_inspect/tests/all/conventions.rs). Never edit data/ui-conventions.json or add a numbered exception.

Run: just b3d cargo-test -p beryl_inspect conventions, just b3d test, just b3d parity.

Acceptance criteria

The 'Manual table pile viewers' entry in data/beryl3d/conventions/no-equivalent.json is a recording entry that the conventions test passes; just b3d test passes; enact push passes.

Pushed aa93c882 to staging.

Built, following the web's TablePileViewer/TableViewers:

  • A look the table takes (Search, Look at top/bottom) opens the library viewer once the table answers Ok (Sent::Look in client/manual.rs); a portion lists only the cards it held when the look began (manual::viewers::Look).
  • Controls row: "Search cards" field, "Group by type" (selected, ember while on), and one sort button that steps Pile order -> Sort by name -> Sort by mana value. Deviation: the web uses a <select>; Beryl 3D has no select widget, so the sort is a single button showing the current order (named "Sort", as the web's aria-label).
  • Closing a whole-library search its player may shuffle offers Shuffle (primary) and Don't shuffle in place of Close; they send close_look alone or in a batch after shuffle {seat, all}. Deviation: the viewer closes when the action is sent, not after the table's answer as the web waits; a refusal still plays the refusal sound.
  • Client commands search_viewer, group_viewer_by_type, sort_viewer_by_*, close_viewer, close_and_shuffle, close_without_shuffle act on the open viewer (Act::Viewer); conditions open_viewer and whole_library now hold.
  • FaceList::mana_value works from the card record (split cards add both halves); the halves of a split card share one scan and so one listed face, so it cannot be read from faces.
  • The opponent's lifted count already showed (table/lifted.rs places CardHandling::Pile cards off the library); screen/table-search sets the opponent looking at their top 3, and the tree shows #17-#19 lifted beside their library.
  • The recording driver now answers a recorded table_act with Reply::TableAct instead of Done, so recordings can open a library viewer.
  • New recording screen/table-search; conventions entry "Manual table pile viewers" is now {recording screen/table-search, at end, do [key F3, press button "close"], shows button "Shuffle"}.

Avoided adding beryl_table as a beryl_scene dependency (it touches files, scene-purity forbids); Look reads the action's JSON as commands.rs writes actions.
