Description

Music and sound effects for Beryl, from CC0 assets, with an attribution entry on the main menu.

The user's request (verbatim)

Can you design and implement music and sound effects for Project Beryl? Please source creative commons assets for this. I've linked the NotJam music (CC0) which would be a good starting point. You can add an attribution thing to the main menu. Rule: Anything that happens in the UI gets a sound effect, especially user actions. If possible, it would be good to have something on CI that validates this, but I don't want to grow CI time by more than 1 second, so don't do it if that's hard.

Decisions (pre-flight)

  • Sources are staged locally; workers never download audio. ~/Library/Caches/beryl/audio-sources/ ($BERYL_CACHE/audio-sources):
    • notjam/: NotJam Music Pack, CC0 (licence.txt). Loopable/*_Loopable.wav (20 loops, 20-111 s) and Standalone/*.wav. 495 MB of WAV: never commit WAV.
    • kenney/kenney_{casino-audio,interface-sounds,impact-sounds,rpg-audio,ui-audio}/Audio/*.ogg: Kenney.nl CC0 packs (each has License.txt), 389 short .ogg. Casino Audio has card place/slide/shove/fan/shuffle, chips, dice; Interface Sounds clicks/confirm/error/toggles; Impact Sounds hits; RPG Audio books/cloth/metal; UI Audio clicks/switches.
    • Source URLs for credits: https://not-jam.itch.io/not-jam-music-pack (NotJam), https://kenney.nl/assets/<pack> (Kenney).
  • Committed assets: only the selected, transcoded files, under ui/public/audio/, total at most 12 MB. The repo is public; CC0 permits it.
  • Playback lives in the UI (Web Audio / HTMLAudioElement), not Rust: beryl_app stays thin.
  • CI validation: yes, but within +1 s of slow-CI time. Prefer zero-cost static guarantees (exhaustive TypeScript maps checked by tsc) plus assertions piggybacked on the existing just ui-test run. If a check would cost more than 1 s, drop it.
  • Review: inline cold review on the coverage bead. No Warden, Mason, Sage, Archivist or Marshal (small task-prompt run).

Acceptance (whole run)

  • Music plays on the start screen and in game, loops seamlessly, with volume/mute controls persisted across launches.
  • Every user action and every visible game change has a sound, timed with its animation.
  • The main menu credits NotJam and Kenney (CC0).
  • just check and just ci pass; slow CI grows by at most 1 s.

Code map

  • ui/src/App.tsx: routes; StartScreen (main menu) is in ui/src/screens/Game.tsx.
  • ui/src/game/playback.ts: paces views/beats on screen (window.berylShown); ui/src/game/beats.ts: cuts a view's events (GameEvent kinds in ui/src/generated/protocol.ts) into beats with HOLD times.
  • ui/src/game/Board.tsx, CardLayer.tsx, ChoiceOverlay.tsx, TurnBanner.tsx, ManaFlow.tsx, Stack.tsx, components/Controls.tsx: where things happen and the player acts.
  • ui/src/freeze.ts, ui/scripts/{shots,interactions,capture,motion}.mjs: headless capture and ui-test (Playwright WebKit). tools/src/beryl_tools/shots.py runs them.
  • Tests: cd ui && npm run typecheck, just ui-test, just ui-shots, just check, just ci.
