Description

Part of epic by-7wl (read it first). Checks the anchored agent on the positions that started it.

Build

beryl_cli review (rust/crates/beryl_cli/src/review.rs) re-searches a replay with the agent the replay names. Add --agent NAME, where NAME is a registered agent or a long-think entrant (family@budget, as longthink names entrants), so a replay can be re-searched by another agent. The replay's log still drives the game; the agent only searches, and REPLAY CHOSE marks where it differs.

Run

On docs/incidents/2026-11-06-deep-seer-misplays.replay.json, with pimc18/omniscient/rollout/tuned/anchor+mid@30M, then .../anchor@30M (to separate the two changes). About 3 minutes of wall time each on 18 cores. If the replay has drifted since the incident's commit, follow the incident doc to recreate it.

Report, for turn 14's Oust (priority and target), turns 10 and 12's Jace choice, and turn 14's Jace -1 on Subtlety: greedy's choice, the search's choice, mean(d) and its SE, and the move played. Expected: pass at Oust. For Jace, give the 0's mean with and without mid.

Put the findings in this bead's notes and close reason. Commit --agent, not the review output.
