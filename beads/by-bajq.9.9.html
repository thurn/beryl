Close reason

Decision back to 312 B (63-option cap) and decider set only on returned decisions: count 379,213,984 -> 379,131,151; 0.034% above a build with every control path stripped, left as per-decision, per-policy-pick and per-knowledge-write byte tests that cannot leave the common path (see comment)

Description

Symptom: the decision-protocol group (Mindslaver, by-bajq.9.1) raised the absent-cost count by +305,628 instructions (+0.08%) on the WU Control corpus, which never controls a player. rust/crates/beryl_bench/count-gate.toml says a mechanic absent from these decks must cost nothing at all.

Known causes from by-bajq.9.1's notes: Decision<Small> grew from 312 to 320 bytes for Decision::decider, and decisions are moved by value on every engine step; CR 724.4 knowledge is written through to the controller (State::sharer in beryl_kernel/src/turn.rs, knowledge.rs, zone.rs, derive.rs); the decider is set in beryl_rules engine/questions.rs controlled(), already cold.

Also measured by the Warden (by-bajq.9.5): keying the app's seat-based profile settings (Profile::step_stops, hides_pointless, taps_mana, asks_targets, full_control, quiet_pointless) to the decider instead of Decision::player cost another +0.07 to +0.13% from code layout, so it was left out. Today, a human controlling the opponent's turn gets the opponent's profile settings (their smart stops, no manual mana, lone targets announced, no full-control passes), and an agent controlling the human's turn gets the human's. If this bead finds a layout that makes the decider free, apply the decider to those reads too: stops.rs stops_for/asks_lone, engine.rs asks_pass, engine/questions.rs only_idle, cast/legal.rs activation_options, cast/parts.rs, mana/pay.rs, mana/solver.rs.

Approach to try: keep the decider out of Decision (store it only while State::turn().controller() is set, and read it through a cold accessor), or recover the 8 bytes elsewhere in Decision.

Acceptance criteria

just count-gate shows the WU corpus count within 0.01% of what it was before by-bajq.9.1 (392,333,187 on that bead's base; compare on one base by reverting), or the close reason names each remaining cost and why it cannot move off the common path. Mindslaver's scenarios and the beryl_session controlled and decider_saves tests still pass.
