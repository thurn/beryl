MCTS in beryl_search (59c1ffd): UCT over factored decisions under smart stops, full-game greedy rollouts, iteration budgets, root-parallel trees summed in order. mcts-omniscient and mcts-hidden registered; determinism, information-independence and paused-resolution tests. Also fixed inline continuation of a paused resolution ignoring its record.

Description

Part of Milestone 1 (epic by-b0q): a rules-exact engine, game UI and AI opponents for a mirror match of the 40-card WU Control main deck in docs/sample-decks/2026-10-17-PrinceJools-wu-control.txt (29 distinct cards). Read the epic's description (plan, card table) and design field (decisions) first; docs/engine-architecture.md is the design. Rules code cites the Comprehensive Rules with yawgatog links and quotations (AGENTS.md).

Design decision 5 and architecture section 19.1.

  • beryl_search: UCT (UCB1, constant tuned) over factored decisions under the smart-stop search profile; single-candidate decisions skipped. Nodes store choices; each iteration copies the root and replays its path. Rollouts to the end of the game under the rollout policy; a stall scores 0.5. Iteration budgets; deterministic for a seed. Independent trees run root-parallel with std::thread::scope, root visit counts summed in a fixed order.
  • mcts-omniscient: K trees on the true state with different seeds. mcts-hidden: K determinizations of the searcher's Observation, one tree each. Register both.
  • Extend the information-independence test to mcts-hidden.
  • Defaults: a budget that keeps a UI decision near 2 s on this Mac with root parallelism; tournaments take a budget flag and one thread per game.

Acceptance criteria

  • Over at least 100 seeded games per pairing, seats alternated: mcts-omniscient wins at least 60% and mcts-hidden at least 55% against greedy, and both at least 90% against random. Results with intervals in a comment on the epic.
  • Determinism test: the same seed and budget choose the same move with root parallelism on.

Executor notes (design, deviations):

  • Engine: agents were handed Observation::new(view(s)), which while a resolution is paused is the scratch replay (pending None, body half run); search cannot play on from it. Observation now also carries the committed root; engine::observe(s, t, x, viewer) builds it and every agent call site (CLI, session, test harness) uses it. Observation::unmasked_root() exposes the root for mcts-omniscient only (documented as cheating). determinize() now deals into the root, by the root's knowledge (keep_what_was_seen already carries what a paused body showed).
  • Engine bug fixed: an inline source continuing a paused resolution ignored its choice record (resolve.rs ran the body with an empty record), so a rollout started below a paused tree node panicked ('a stack entry to resolve'). It now replays the record first. Covered by tests/mcts.rs a_search_plays_on_from_a_paused_resolution (fails without the fix).
  • State::reseed(seed) added: per-tree root seeds (omniscient) and per-rollout seeds so sibling rollouts diverge (§14).
  • engine::collapse: card-equality pre-check before building signatures (same result; ~24% fewer cycles per greedy game, collapse was the top profile entry). Mana Sources::of and legend checks are the next hot spots; left for the rollout-benchmark bead.
  • Registry: AgentInfo::new takes a Budget {iterations per decision shared by the trees, trees, parallel}. Tournaments force parallel=false (one thread per game); CLI play/tournament take --iterations and --trees.
  • Tree nodes play under smart stops after the root (root keeps the game's profile; payment mode kept so a payment in progress is never re-asked under another). Rollouts use the existing rollout() under the same profile.
  • Information independence for mcts-hidden lives in tests/mcts.rs (one-tree budget past the candidate count so visits follow rewards); a mutation making the hidden search read the true state fails it.
  • Tests run in the debug profile, so budgets there are tiny; strength is measured with CLI tournaments (results on the epic).
