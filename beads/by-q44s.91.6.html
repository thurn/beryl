Description

Read the epic's contract first; this bead builds against it. Doc: docs/beryl-3d.md, 'Migration and compatibility' and 'The agent interface'.

The web interface uses about 69 linear and radial gradients, 10 gradient masks, and the brightness, grayscale and blur filters. Style.background is one flat color, so Beryl 3D draws all of these wrong.

Change: let Style's background be a color or a list of gradients (linear with an angle and stops, radial with a shape and stops). Add mask (a gradient applied to the element's and its children's alpha) and filter (brightness, grayscale, blur). Draw them in the renderer to match WebKit within the conformance suite's tolerance. Gradients interpolate in the same color space WebKit uses, premultiplied sRGB. Blur on an element subtree is the expensive one, since the web uses it once, so find that use and choose the cheapest approach that matches it. Port every web element that uses these properties. This bead follows the shadows bead in the same lane, because both edit the shader and the material table.

Files: as the shadows bead, plus beryl_scene/src/layout/style.rs.

Acceptance criteria

Every gradient, mask and filter sample passes, the gates pass, and the web's elements that use them are ported.
