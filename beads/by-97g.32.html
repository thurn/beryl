Description

Part of the ladder epic by-97g. Read docs/ai-strategy.md first: §2.2 and §6.6.

A yardstick, never a champion. The expert alone gets 18 of the 20 suite positions right; the champion gets 2. This bead adds an option expert that anchors the search to the expert's answer at every decision, so that one measurement (by-97g.33) can say how much the root alone can fix and what it costs in strength. It is off by default and set by no registered agent.

Where

  • rust/crates/beryl_search/src/long.rs:
    • LongSearch::choose: greedy's answer is computed there (self.policy.choose(&self.table, obs, d)), passed to guarded, and checked against the search's choice (check, AnchorCheck::played).
    • guarded: which decisions keep the default answer.
    • Options, to_name, FromStr: commit 1c43427 shows how an option is added.
    • LongSearch::new, resumed, rewind and impl Widen for LongSearch<Small>: everywhere a LongSearch is built or copied.
  • rust/crates/beryl_search/src/expert/mod.rs: ExpertAgent::new(t, seed), its Agent::choose(&mut self, obs, d), and its Widen impl. Use the live expert here, not rust/crates/beryl_search/src/frozen/.

Build

  1. Add the option expert to Options. The fixed order of option names is: anchor, expert, guard, mid, means, hold, waste, combat, order (use the ones that exist when you build this). expert is refused without anchor, as guard is.
  2. LongSearch holds an Option<ExpertAgent<L>>, built from the search's seed when the option is set. Build it again wherever a LongSearch is built, resumed, rewound or widened.
  3. In LongSearch::choose, with expert set, the default answer is expert.choose(obs, d) in place of greedy's, at every decision the search searches.
  4. With expert set, guarded returns true at every decision kind whenever the search's choice differs from the default. The check that lets the search overrule it stays as it is (ANCHOR_MARGIN, ANCHOR_ERRORS).
  5. Change nothing for a family without expert.

Tests

  • A family with expert round-trips by name; …/expert without anchor is refused.
  • On crafted decisions, a search with expert set plays the expert's answer unless it is clearly beaten (copy an_anchored_search_plays_greedy_unless_clearly_beaten).
  • Two searches of one game from one seed with expert set choose alike.
  • A family without expert plays as before (the existing unguarded-equals-plain test passes untouched).
  • just test-rust, just check.
