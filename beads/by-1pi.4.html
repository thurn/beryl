Description

Major/design: modes/activation choices have animated entry but no exit lifecycle. Live confirmed: currency-converter / stops-main, play to live decision, click Converter, Cancel. probe.audit measured both ability-choice objects vanishing in 0 ms; evidence 023-converter-modes.png and 024-converter-cancel.png. ModeChooser.Frame animates from source; Cancel/Escape/pick unmounts the chooser directly, with no exit/AnimatePresence or dissolve. Risen similarly has only arrival motion. Stack indicators do have source-based flight, but AbilityOnStack exit is only opacity 0 + scale .9 over .35 s; CardElement removal is only opacity 0 over .3 s. Neither implements the user's dissolve. Currency Converter film shows activated/triggered indicators and token creation; existing tokenOrigins already sources the Rogue from the resolving indicator and should be retained, not replaced. Implement shared dissolve for temporary tokens when ceasing, resolved/countered activation/trigger indicators, unchosen/cancelled ability/mode abstractions and other short-lived card-like choices. Keep a chosen indicator continuous into the stack, and dissolve alternatives without losing source linkage. Real cards in Risen/browser/choices should return/move rather than dissolve. Source fallback must use last known geometry when removed/bounced/sacrificed, not pop/fade into destination. Preserve emblem/source-created-object paths. Code-backed acceptance extension: zero-top-stack tokenOrigins currently returns undefined; verify replacement-created tokens and multiple arrivals before deciding on a general source metadata change. Also code-backed: CardLayer's 3D flip currently responds only to object.facing changes on battlefield. Unknown hand/library cards becoming known swap CardBack to a face in Look without a turn. Verify/deliver actual face/back turns for draws, opponent casts, reveals and concealment; don't turn an already face-up card gratuitously. Existing battlefield flip is useful and should remain. Where: ModeChooser, Board AbilityOnStack/abilityPlacement/tokenOrigins, CardLayer CardElement/Look/flip, faces, physics, Risen, choiceFlight, playback. Use fast nonblocking effects, persistent identities and last-known positions; reduced motion gets a short safe alternative. Do not add per-card animation branches.

Implement general presentation/event behavior, not card-name special cases. Preserve hidden information. Hover previews are explicitly allowed by the updated AGENTS.md; prefer modest in-place enlargement when feasible, never force a huge original-card zoom.
