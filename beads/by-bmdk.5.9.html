Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Setup and match flow' (the four numbered starting steps and decision T15).

Interface code goes in ui/src/table/, registered with TableClient (ui/src/table/client.ts). Headless checks start a table with ui/scripts/table.mjs and go in ui/scripts/kept-table-<topic>.mjs; run one with just ui-test <title>.

Host side, rust/crates/beryl_table_session/src/flow.rs; interface, the opening screen ui/src/screens/Opening.tsx.

Starting a game runs these steps in order, each visible on the table, each built only from ordinary actions and host-held prompts (bead "Host-held prompts"):

  1. If set to roll, roll one die per seat (both shown by the existing banner). Re-roll ties. The winner gets TablePrompt::Choose { "Play", "Draw" }. With a named first player, or after a game when the loser chooses, the prompt goes to that seat. On a solo table skip this step.
  2. start: shuffle both libraries and deal each hand.
  3. Each seat gets TablePrompt::Opening: "Keep" or "Mulligan". A mulligan sends mulligan (shuffle the hand away, deal a new one of the same size). A player who keeps after n mulligans is asked to put n cards on the bottom (Bottom { card } answers, then Done), and may decline with Done at once. Both seats decide at the same time.
  4. When every seat has kept, the first player's turn begins at the untap phase (phase, and set the active seat).
  5. Nothing is enforced: any step can be skipped or redone by hand. The gear menu's "Next game" and the lobby's Start run the flow; a player can also draw seven by hand.
  6. Draw Opening on the existing opening screen (Opening.tsx shows keep and mulligan for engine games): extract its presentation so both use it; engine behavior unchanged. Arena's wording applies ("Keep", "Mulligan").

Tests: tests/flow.rs: a roll with a tie; play-or-draw choice; one seat mulligans twice and bottoms two while the other keeps; declining to bottom; solo. Every step appears in the log and can be undone. Check (kept-table-start.mjs, with pair()): the roll, the choice, a mulligan and a bottom card.

Acceptance criteria

Start runs roll, choice, deal, keep-or-mulligan with bottoming, and the first untap, all from ordinary logged actions and host-held prompts; both seats decide mulligans at once; the opening screen draws it with engine behavior unchanged; tests and a pair check pass.
