Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Cards and decks' (custom tokens), and the appendix tables 'Power and toughness', 'Counters on a card' and 'Tokens'.

How interface beads in this milestone fit together: ui/src/table/client.ts (bead "Table screen") is the manual table's pointer client. It owns the selection, sends actions with tableAct from ui/src/ipc.ts, and lets each interaction register handlers from its own file. Put your code in the file this bead names and register it; change client.ts only to add a registration point it lacks. Check your work on a live manual table in a headless browser: ui/scripts/table.mjs (same bead) starts one through the HTTP server and gives a Playwright page. Add one scripted check per behavior to ui/scripts/kept-table-<topic>.mjs and run it with just ui-test <title>.

File: ui/src/table/cardState.ts, TokenSearch.tsx.

  • Power and toughness: the six keys change by one (Cmd+= and Cmd+−, Option+= and Option+−, Cmd+Option+= and Cmd+Option+−), Cmd+P opens the stats prompt ("3/3" sets, "+1/+1" adjusts), Cmd+Option+0 resets. All send stats.
  • Counters: three quick slots as the appendix's table defines them. Slot A (Option+. add, Option+, remove, Option+/ set) is the card's first counter: +1/+1 on a creature, loyalty on a planeswalker, otherwise the first counter name its rules text mentions (match "<word> counter" in the text; fall back to "charge"). Slot B (Cmd+. , /) is −1/−1 on a creature, otherwise the second. Slot C (Cmd+> < ?) is a counter named "counter". "Add counter…" in the menu takes any name, offering +1/+1, −1/−1, loyalty, charge, lore and stun first. Cmd+Shift+A adds one to every counter on the card. Put the slot logic in a pure function with tests.
  • "Note…" (Option+N) opens the text prompt and sends note.
  • Tokens: Cmd+T opens TokenSearch: a search of the store's tokens (cardSearch with tokens: true), the tokens the selected card makes first, and "Custom token" as an entry opening a form with name, colors, type line, power and toughness and note. Cmd+G repeats the last token. Option+1 to Option+0 create the tokens the deck's cards make, in the order first listed (ask the host: add the list to TableView if it is not there). Cmd+Shift+T creates every token the card makes. A token row on a card creates it; "Attach to (name)" creates it attached. Shift creates it face down.
  • Clone (Cmd+J), "Doesn't untap" (Option+U), "Turn over" (Option+F), "Peek" (Option+L), Unattach (Cmd+Option+U): confirm each sends its action from the key (they are registry commands; this bead owns checking them).

Checks (kept-table-cardstate.mjs): add a +1/+1 counter and see power and toughness rise; set "3/3" then "+1/+1"; a note; create a store token and a custom token; repeat token. A fixture or kept moment with the token search open.

Acceptance criteria

Stats, the three counter slots, named counters, notes, token search, custom tokens and the token keys work as the appendix lists; the slot logic is unit tested; headless checks cover each group.
