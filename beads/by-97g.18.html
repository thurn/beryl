Description

Part of the ladder epic by-97g. Read docs/ai-strategy.md first: §4.3 and §5.

just gate CHALLENGER --claims A,B [--vs CHAMPION]: the suite for the champion and the challenger, compared, with a printed verdict. Gate beads run it and act on its last line, so it must be exact.

Where

  • rust/crates/beryl_cli/src/blunders.rs: Report (its open, fixed, drifted and per-entry results), the function that runs the suite for one agent, --json.
  • rust/crates/beryl_cli/src/ladder.rs: resolve (an agent or family name to an agent), DEEP_SEARCHER as the default champion.
  • rust/crates/beryl_cli/src/main.rs (subcommands) and the justfile (copy the blunders recipe: same profile, same low priority).
  • New file rust/crates/beryl_cli/src/gate.rs.

Build

beryl_cli gate <challenger> --claims NAME,... [--vs NAME]:

  1. Run the suite for the champion (--vs, default DEEP_SEARCHER) and for the challenger, each at 3M and 30M from 5 seeds: 10 runs an entry.
  2. For each entry count the runs passed of 10 for each agent. An entry is fixed at 10 of 10 and open below that.
  3. Print one line an entry: name, champion passes, challenger passes, and a mark: claimed-fixed (claimed, open for the champion, fixed for the challenger), re-opened (fixed for the champion, open for the challenger), worse (challenger passes at least 4 fewer than the champion), or nothing.
  4. Print the counts, then exactly one of GATE: PASS or GATE: FAIL.
    • With claims: PASS when there is at least one claimed-fixed, no re-opened and no worse.
    • With --claims none: PASS when there is no re-opened and no worse.
  5. Exit 0 on PASS, 1 on FAIL, 2 on a usage error, a drifted entry or a claimed name that is not in data/blunders.json.
  6. Write both runs' JSON under $BERYL_CACHE/ladder/gates/<date>-<challenger>/.

Tests

Unit tests on the comparison alone, from hand-made pass counts: one claimed entry fixed passes; a claimed entry at 9 of 10 does not count; a re-opened entry fails; a fall from 6 to 2 fails and from 6 to 3 does not; --claims none; an unknown claim is an error.
