Description

Part of the ladder epic by-97g. Read docs/ai-strategy.md first: §2.2 and §6.2.

Rung 2, build. The rollout policy acts at its first chance. Six of greedy's nine wrong suite answers are timing. With the rule hold set, an instant-speed cast or activation scores as a pass until the opponent's end step.

Claims: snapcaster-sorcery-speed, subtlety-main-phase-empty-stack, subtlety-before-own-draw, staff-in-upkeep, staff-before-combat-damage, jace-loots-before-draw, samurai-into-jace.

Where

  • rust/crates/beryl_search/src/rollout/policy.rs: Policy::action, Policy::cast, Policy::activate, Policy::rules (from the rules bead).
  • rust/crates/beryl_search/src/expert/mod.rs: Expert::timing reads the turn and step: obs.turn().active(), obs.turn().step(), TurnStep::*, obs.stack(). Copy that reading. Do not call the expert.
  • rust/crates/beryl_search/src/values.rs: CardInfo::draws.
  • Card data: Types::INSTANT, Keywords::FLASH, an ability's cost.loyalty, an ability's targets and each TargetSpec::kind (TargetKind::Spell, TargetKind::SpellOrPermanent).

Build

In policy.rs add fn held(&self, o: Opt<L>) -> bool, in its own function that Policy::action calls only when self.rules.hold is set. When it returns true, action returns 0. Name no card.

Policy::rules carries #[expect(dead_code, ...)] (commit 8d57db7e) because nothing read it yet. Remove that attribute now that action reads it, or the build fails on an unfulfilled expectation.

held(o) is false unless o is Opt::Cast or Opt::Activate. Then:

Step A: is it at instant speed? Let main be: the active player is me, the step is a main phase, and the stack is empty.

  • If not main: yes.
  • If main and o is a cast: yes when the face's types include instant or its keywords include flash; otherwise no.
  • If main and o is an activation: yes when the ability's cost.loyalty is None; otherwise no.

If no, return false (not held).

Step B: is one of the six exceptions true? If any is, return false.

  1. The active player is not me and the step is the end step.
  2. The top of the stack is a spell an opponent controls, and the play's first target spec has kind Spell or SpellOrPermanent. For a permanent spell, use the first target of its targeted enters ability.
  3. The active player is not me and some creature has the ATTACKING flag.
  4. The active player is me, the step is a combat step, and the play has at least one target spec.
  5. The active player is me, the step is the end step, and me's hand holds more than seven cards.
  6. main is true and the play draws: info.draws(i) for an ability, or for a spell its spell ability's index. Check that Staff of the Storyteller's draw, Currency Converter's loot and Jace, Vryn's Prodigy's loot have the flag in their rollouts today (print it in a test). If one lacks it, fix how values.rs derives the flag from the definition; do not add a name.

Otherwise return true (held).

Tests

Write these before the rule and see them fail without it.

  • Scenarios with greedy and hold set, one each: a flash creature in its own main phase with an empty stack is not cast; the same creature is cast at the opponent's end step; a counterspell is still cast at an opponent's spell worth countering; a draw ability is used in its own main phase and not in its own upkeep; an untargeted activation is not made in its own combat.
  • Over the whole pool: for every card in beryl_cards::CARDS whose front face is an instant or has flash, held is true for its cast in me's precombat main phase with an empty stack unless exception 6 applies.
  • The end step is reached: in 50 seeded greedy mirror games with hold set for both seats, at least one flash creature or instant is cast in an opponent's end step. If none ever is, the engine is not giving priority there: stop, write that in the notes and close this bead as failed.
  • Without hold, a_cold_softmax_is_greedy and rollouts_never_change pass untouched.
  • just test-rust, just check.
