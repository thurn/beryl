Fast check 52 s. Fixed in 7715c6d:

  1. --upgrade sampled only fresh searches (chain == decision), so a perf change to subtree reuse that altered a move would be adopted, the exact risk for by-2l8.6. It now samples every searched decision of the cheapest rung and re-searches from its chain start through it. New test: a search that answers otherwise only on reused trees is refused (mutation-checked: fails on the old sampling); it also asserts the tiny run has reuse chains.

Left alone on purpose: --upgrade takes no lock (it only reads logs and renames the binary in; a running runner keeps its old inode, and adopting requires identical play); a SIGSEGV/SIGBUS crash has no panic-hook record so it is not skipped as crashed, but the supervisor gives up after 10 crashes without a finished game (no unsafe in these crates); syncing every searched line of the game log is what the spec asks.
