What to build

  1. A normalized diff. Compare each card's rendered text with its Oracle text from the card store (data/card-store.tsv, tools/src/beryl_tools/card_store.py) after normalizing both sides the same way: reminder text in parentheses removed, the card's own name replaced by the self-reference Oracle uses for it ("this creature", or the name, consistently), whitespace, punctuation and quote styles unified, mana symbols compared as symbols, case of the first letter of a sentence ignored, the order of keyword lines on one line ignored. Each normalization rule is a named function with a comment saying what Oracle variation it absorbs and an example; none mentions a card (the card-names check). Report per card: match, or the word-level diff of the paragraphs that differ.
  2. just card render [names | --all] prints rendered text and the diff; --all reports the match rate over the implemented cards (the 47 plus any landed since) and lists the mismatches by cause. just card check <name> runs it as its last step: a mismatch fails the check, printing the diff, since that is the error K13 exists to catch. Add an explicit, reviewed exception list only if a card's Oracle text cannot be rendered by its definition for a reason that is not a definition error (for example Oracle wording that changed with a rules update the vocabulary predates), in data/ with one line of reason each; default to none.
  3. Improve templates where the diff shows the template, not the definition, is wrong. Do not change a definition to make text match unless the diff shows a real rules error in the definition: that is a rules-engine bug, which gets a docs/bugs.md entry, its CR citation, and a scenario.
  4. Report the match rate on the 47 cards, with the remaining mismatches grouped by cause, on this bead and on the milestone epic by-w8gv.15. It is reported with no bar (run epic, "Defaults"): do not grind the last mismatches by special-casing.

Derek Thurn2026-11-13

Render diff report (by-w8gv.15.6): 30 of 47 implemented cards match their Oracle text after normalization (just card render --all). Before the two template fixes and the pronoun, mana-order and spell-paragraph normalizations it was 27 of 47.

Remaining 17 mismatches by cause:

  • Definition gaps that need vocabulary the pool lacks (no new rules features in Project 50k): Thieving Skydiver omits "If that artifact is an Equipment, attach it" (its file says no Equipment is in the pool); Damn omits "can't be regenerated" (no regeneration in the engine). Neither changes play with today's pool, so no definition was changed and no docs/bugs.md entry was needed.
  • Sentence order and joining in templates: Beza (render puts each "if" clause first; Oracle puts the effect first), Jace, Vryn's Prodigy ("exile Jace, then return him" vs two sentences), Thirst for Discovery and Jace, Wielder of Mysteries (Oracle's sentence-initial "Then"), Time Spiral (old Oracle wording "You untap"; newer Oracle such as Jace, Wielder of Mysteries omits "you", so not templated).
  • Pronoun versus name for the card itself: Malcolm ("put a chorus counter on it"), Sphinx of False Conclusions ("a copy of it"), The Wandering Emperor ("her loyalty abilities").
  • Word choices in templates: Mana Drain ("that amount", Amount::Carried has no source wording), Trinket Mage ("reveal that card"), Subtlety ("creature spell or planeswalker spell"), Elite Spellbinder (cast vs play, and choose-then-exile split into two sentences), Jace, Telepath Unbound ("in your graveyard" vs "from"), Currency Converter ("from your graveyard"; choose + "if you do" vs Oracle's direct put; "otherwise" vs "if it's a nonland card").
  • Combined static abilities: Swift Reconfiguration renders three statics where Oracle has one sentence ("is a Vehicle artifact with crew 5 and it loses all other card types").
  • Distributed effects: Winds of Abandon's ForEachPlayer/ThoseOf sentence.

Decisions: no exception list was added (data/), since every remaining mismatch is a template or a definition gap, not Oracle wording the vocabulary cannot express. Normalizations each absorb only presentation (reminder text, self-reference, quotes/dashes, whitespace, character pronouns, mana-choice order, mana symbol form, sentence case, paragraph breaks inside a spell ability per CR 113.3a, keyword grouping and order). Per the packet's "no bar" default the last mismatches were not special-cased.
