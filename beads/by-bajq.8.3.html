Description

Card

Worldgorger Dragon, 7/7 flying, trample: "When this creature enters, exile all other permanents you control. When this creature leaves the battlefield, return the exiled cards to the battlefield under their owners' control."

The loop

Animate Dead returns the Dragon. The Dragon exiles Animate Dead. The Dragon is sacrificed. Its leaves trigger returns Animate Dead, which enters and must enchant a creature card in a graveyard. If the Dragon is the only one, the loop has no way to stop and the game is a draw (CR 104.4b: "If a game ... somehow enters a 'loop' of mandatory actions, repeating a sequence of events with no way to stop, the game is a draw. Loops that contain an optional action don't result in a draw."). Today the engine would run until the trigger budget and end Stalled, which every test treats as a failure.

What to build

Plan: Designs 7, "Mandatory loops"; decision R13.

  • State gains ten bytes: a count of resolutions in a row in which no player made a choice other than passing priority or an answer with one candidate, and a stored hash.
  • Past eight such resolutions, compute a canonical hash of the state as each one ends: every field Hash feeds, with incarnations left out and timestamps read as ranks, and without the budgets. Compare it with the stored one; replace the stored one when the count reaches a power of two (Brent's method, so one hash finds a loop of any length). A match ends the game as Outcome::Draw.
  • Any real choice resets the count. A loop with an optional action in it is therefore never a draw here, and runs to its budget as today.
  • The canonical hash is a kernel function beside State's Hash. Shuffles change the random stream's state, which is hashed, so a loop that shuffles is not a repeat.

Ordinary play pays one increment and one compare of a small counter per resolution.

Scenarios

The Dragon and Animate Dead alone: a draw. With a second creature card in a graveyard: Animate Dead's controller may choose it and the loop ends. Worldgorger Dragon's own text: the exile and the return, with a land that entered tapped returning untapped.

Handoff: beryl_kernel/src/repeats.rs holds Repeats (quiet: u16, stored: u64; +16 bytes, State<Small> 20,128 -> 20,144), State::note_choice / note_resolution / canonical_hash. The canonical hash reuses State's Hash via hash_game(h, with_budgets=false) and a thread-local switch read by the manual Hash impls of ObjectRef, Target (stack.rs), Affects and ContinuousEffect (effects.rs), Object and Zones: incarnations read relative to each slot's current one, timestamps as ranks among live ones, stale timestamps as 0. Ordinary hashes are byte-for-byte unchanged (rollouts_never_change and frozen saves pass). Rules hooks: resolve::resolve counts each finished resolution and ends the game Outcome::Draw on a repeat; engine::perform resets for a non-priority decision with >1 candidates, perform_priority's action arm resets for any non-pass priority action, resolve::answer_inline resets for inline answers with >1 candidates. Deviation from the bead: 16 bytes not 10 (u64 alignment), within the allotment. Count gate 384,443,088 -> 384,694,675 (+0.065%): ~35k is the bigger state, the rest is the per-resolution count; a first placement of the choice test in perform cost +0.17% and was moved. Worldgorger Dragon (rust/cards/cards_2002/jud/worldgorger_dragon.rs): 3 hand-written scenarios; the draw needs 13 explicit Resolves (first hash at the 9th quiet resolution, loop is 4 long). Oracles: XMage passes all 4 after tools changes (xmage_java.outcome_lines checks a draw after execute; BerylScenarioTest answers XMage's 'Draw game because of infinite looping?' yes and, with the answer queue empty, picks a lone candidate of a required choice); Forge has no loop rule, divergence recorded (CR 104.4b). Also split engine.rs (engine/land.rs) and stack.rs (stack/tests.rs) for the 800-line limit. Reviewer: check the thread-local approach in repeats.rs and that every place an incarnation or timestamp is hashed goes through it (a missed one only makes a loop go undetected, never a false draw).
