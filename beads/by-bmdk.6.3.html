Restored hosted guided openings from saved history and verified reopen, undo and rewind on staging 814845d6.

Description

A hosted game reopened after the opening deal shows turn zero without either opening prompt. The saved game replays the deal, mulligans and keeps, while PublishedTable::new recreates its prompt vector empty. The pending first-player decision can likewise disappear between the dice roll and the deal. In-process guest reconnect works because PublishedTable::reset_seat still sees the live prompts.

Give the guided opening one durable source of truth. Reconstruct the committed setup phase from typed, replayable transitions for the first-player choice and each seat's opening progress. Reuse existing log actions where they unambiguously describe the transition. Build fresh prompts and viewer slots from that state on reopen; drafts such as a still-unconfirmed bottom-card selection can be cleared. Avoid persisting prompt closures or viewer IDs. Preserve old saves and normal in-process reconnect.

Start in rust/crates/beryl_table_session/src/{flow,publication,sessions,saves}.rs, the table log/actions as needed, and the offline connection helpers in rust/crates/beryl_table_session/tests/flow.rs. Use the existing host quit/reopen path and test both viewer publications. Run just test-rust -p beryl_table -p beryl_table_session.

Reuse linked_table and receive in tests/flow.rs for guest/host publication waits. For a persisted host reopen, follow a_drop_freezes_actions_and_resume_replays_the_save_for_the_same_guest in tests/host.rs. The host entry point is TableConnections::resume in src/connections.rs; it delegates to the saved-table session path in src/sessions.rs. Run cargo clippy --manifest-path rust/Cargo.toml --locked -p beryl_table -p beryl_table_session --all-targets -- -D warnings as focused verification. The workspace fast check can defer Clippy under load.

Acceptance criteria

An offline MemoryLink test reopens a real host save before the play/draw answer and after one seat keeps and the other mulligans. The same seat gets the play/draw question without a second roll. The kept seat stays done, the other sees its original mulligan count and hand, and finishing enters turn 1 exactly once. Check saved-log replay and undo/rewind against the resumed opening.
