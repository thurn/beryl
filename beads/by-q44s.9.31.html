On the web, a permanent shows its manual table note on one line with an ellipsis, a value chosen as it entered (a color, a creature type, a card name) on one line the same way, and a "Copy" label where a token shows "Token". Beryl 3D shows all three only in the inspection panel: a card's face on the table draws no free text, because Badges shapes only digits and signs once.

Draw the note and the chosen value as one line of text on the permanent's face, cut with an ellipsis to the card's width, and the copy label, following the web's placement. Give each a tree element (or a state word) so just b3d tree shows it, then replace the three open entries in data/beryl3d/conventions/not-seen.json with {"recording", "at", "shows"} entries (the manual table's sample view in rust/beryl3d/crates/beryl_inspect/src/screens.rs can be given a note; painters-servant recordings have a chosen color; glasspool-mimic/the-mimic-enters-as-a-shapeshifter-rogue-copy has a copy).

Run: just b3d cargo-test -p beryl_inspect conventions, just b3d test, just b3d gate (a new element on the table moves work counters; raise limits only with old and new numbers in the commit body).

Acceptance criteria

The three entries of data/beryl3d/conventions/not-seen.json are recording entries that pass just b3d cargo-test -p beryl_inspect conventions; just b3d test and just b3d gate pass; enact push passes.
