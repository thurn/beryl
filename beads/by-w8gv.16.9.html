Description

by-w8gv.16.5 added beryl_session::prompt::ObjectId (a transparent u16 newtype that is number in TypeScript) and uses it for the prompt's wire types: PromptView.about, ShapeBody's tray, about and aiming, Pile.cards and Pair.from. The rest of the wire still names objects by bare u16: in rust/crates/beryl_session/src/protocol/view.rs, ObjectView.slot, the zone lists (battlefield, library, graveyard), pending_attackers, attached_to, exiled_by, exiled_with, Combat's planeswalker and attacker, AbilityRef's source, and Subject::Object { slot } in src/script. They were left out because converting only some of them mixes ObjectId and u16 in comparisons such as o.attached_to == Some(host.slot) (beryl_cli fixture predicates, checkpoint.rs, snapshot.rs). Convert them together, consider moving ObjectId to protocol, and keep ui/src/generated/protocol.ts unchanged apart from the alias (TypeScript sees number either way). Mechanical: compile errors guide it; just test-rust -p beryl_session -p beryl_cli and cd ui && npm run typecheck verify it.

Acceptance criteria

Every object id in beryl_session's wire types is an ObjectId; Rust tests, clippy and the UI typecheck pass.
