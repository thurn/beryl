Description

This change is made in the Enact repository at ~/enact (scripts/enact.py, tests in tests/test_unit.py and tests/test_integration.py), not in Beryl. Read ~/enact/AGENTS.md first and follow that repository's workflow; record design decisions in ~/enact/docs/design.md. Keep changes backward compatible: projects and live sessions on every machine run this repository directly.

Why

To find slow-CI failures nobody is repairing, a session today has to read enact status, then check each run's routes and each Steward bead's assignee by hand. Beryl now has a scheduled routine that does this every 30 minutes, and it has to guess which sessions are alive.

What to change

  • enact status reports unowned_stewards: open Steward beads filed for this machine (enact_ci_host) that no fresh local vizier lease covers and whose assignee, if any, has not renewed a lease or updated the bead recently. Use the lease from the lease bead this depends on.
  • For each entry in active_runs, report each route's lease age, and mark a run stale when no route has a fresh lease, so a stale run is visible at a glance.

Done when

Unit tests cover each case above, and enact status output in Beryl shows lease ages for its runs.
