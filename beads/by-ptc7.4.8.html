One query for each rules question the module answers (delete the parallel readers), no parameter nobody reads, no wrapper that only forwards, no comment that restates the code, and the L: Layout decision applied. Remove or generalise the one-card logic the Mason listed. Keep every Comprehensive Rules citation and quotation.
