Close reason

Landed reversible player, turn, roll, arrow, and match actions on staging as ecd70e5d.

Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), sections 'The table', 'Actions', 'Arrows' (under Interaction), 'Turn and phase', 'Setup and match flow'.

Fill apply/players.rs and apply/game.rs in rust/crates/beryl_table/src/.

players.rs: life, player_counter (add or set; a leading sign in the interface is the caller's business, this takes add or set), roll (n dice of s sides, s from 2 to 1,000,000, n from 1 to 100; a coin is 2 sides; outcomes from Chance, recorded), arrow, clear_arrows.

  • An arrow's kind is computed once here, from the doc's Arrows section: attack, block, friendly target or hostile target. Use beryl_card_store::facts::is_creature if bead "card facts" has landed; otherwise read the type line from STORE directly.
  • clear_arrows removes only the acting seat's arrows.

game.rs: phase, next_turn, load_deck, sideboard, ready, start, next_game, concede.

  • next_turn: the next seat in order becomes active (on a one-seat table the same seat), phase returns to untap, all arrows and all marked damage are cleared.
  • start: needs every seat's deck loaded. It builds each library from the deck, shuffles, sets life and deals the starting hand. It does not roll for first or ask about mulligans: that guided flow is a later bead built from roll, mulligan and move.
  • next_game records a result (a seat wins, or none), updates the score and returns the table to the lobby state with decks kept. concede is next_game with the other seat winning; on a one-seat table it records no result.
  • sideboard swaps cards between a seat's deck and sideboard while in the lobby state.
  • "Untap all" is not an action: it is tap over many objects. Add pub fn untap_all(table, seat) -> Action in src/helpers.rs that builds it, skipping cards flagged as not untapping.

Tests: each action, the solo-table cases, arrow kinds for each of the four cases, and that a replayed roll gives the same numbers. Run just test-rust -p beryl_table.

Acceptance criteria

All listed actions are implemented and tested, including one-seat behavior; arrow kinds match the doc's four cases; untap_all skips flagged cards.
