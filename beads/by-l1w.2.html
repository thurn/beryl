Close reason

UI queues streamed views and plays them back paced with a thinking indicator, game log, spell announcements, End Turn/Continue halts and a start flow that never strands; staging 867fff0, a4b4b10

Description

Builds on the session streaming bead (views after every agent action and step change, a non-deciding acting status, session-level halts at the human's first main phase and the opponent's end step).

In the UI (ui/src/screens/Game.tsx, ui/src/game/Board.tsx, ui/src/components/Stack.tsx, ui/src/ipc.ts):

  • Queue incoming views and play them back at a readable pace (about 0.5 to 1 s per action, faster for trivial steps), animating what each view's events say: casts moving to the stack, resolutions, counters (a countered spell visibly countered, e.g. Mana Drain), zone changes, damage, life changes, land drops, attacks.
  • A clear, persistent "opponent is thinking / acting" indicator whenever the opponent acts or the session is working, so the UI never looks frozen.
  • A compact game log listing what happened ("Opponent cast Mana Drain targeting Thieving Skydiver", "Thieving Skydiver was countered"), naming cards in full.
  • An End turn button and a Continue button for the session's halts; a turn where the player has no plays is visible as it passes, never a sudden jump.
  • Start flow: after Start the screen shows the game starting (the first view now arrives at once); "No game in progress" never shows while a game is starting, and the start screen offers to return to a game in progress instead of stranding the player.
