Description

Part of epic by-7wl (read it first): changes 1 and 2, the anchor option.

Where

rust/crates/beryl_search/src/long.rs: Family (Display, FromStr), LongSearch::choose, grow, settled, leader, totals, Search.

Build

  • Family names gain an optional fifth part, a +-joined set of options (anchor, and mid from by-7wl.3), e.g. pimc18/omniscient/rollout/tuned/anchor. Whichever of the two beads lands first adds the parsing. No fifth part plays exactly as today.
  • Anchor: at a searched decision, g = greedy's argmax from the agent's own observation (RolloutPolicy::choose). b = today's choice (most visited, ties by mean).
  • Verify: grow to 75% of the work as today (exact stop and all). If b != g, spend the remaining 25% on b and g only (root selection restricted to those two children, UCT below them as usual). If b == g, spend it as today.
  • Choose: d_t = mean_t(b) - mean_t(g) for each tree t. Play b only if mean(d) > max(2·sd(d)/sqrt(T), δ), else g. δ is a named constant: by-7wl.1's recommendation if it has closed, else 0.01 until it does. Families with one tree use the δ floor alone.
  • Moves still depend only on the seed, never on the threads.
  • Record in Search (and from there in longthink's decisions.jsonl, as optional fields that change no transcript): greedy's choice, whether the anchor overrode the search, mean(d) and its SE.
  • Kept trees descend to the child actually played, as now.

Tests

The rule on crafted per-tree statistics (a tie plays greedy's choice; a clear lead plays the search's; one tree uses δ alone), family names round-trip with and without the fifth part, and an existing family's search is unchanged.

just test-rust; clippy pedantic.
