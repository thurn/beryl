Description

Why

A text-changing effect (CR 612) replaces every instance of a color word, a basic land type or a creature type in an object's text. In Beryl those words are plain Colors and Subtype values inside filters, keyword parameters, conditions and modifications, read in dozens of places. If each read has to remember to apply the object's changes, one will be missed, and at 50,000 cards nobody will find it. This bead makes the read the only way to the value. It changes no behavior and adds no card.

What to build

Plan: Designs 4, "Words"; decision R9.

  1. Types. ColorWord, LandTypeWord and CreatureTypeWord in beryl_card, each with a private field and no accessor but read(&self, words: &Words) -> .... Words is the set of changes on one object: for each kind, a small map from a word to a word. The identity Words::NONE is a constant.
  2. Where they go. Every place a card's text names a color, a basic land type or a creature type as that kind of word: Filter::Colors, Filter::Subtype, protection from a color, landwalk (by-bajq.1.6), Modification::AddSubtype, SetLandTypes, SetColors, AddColors, an amount or condition that names one, a mana ability's "of the chosen color" does not (a mana symbol is not a color word). A type line's own subtypes are words too (CR 612.1 names the type line): Mind Bend on a Forest makes it an Island. A token's printed characteristics defined by an effect are the effect's text.
  3. The builders keep their names (Filter::Colors(Colors::RED) in a card file must still compile, through a const fn that takes the plain value), so the 48 card files change little or not at all.
  4. The readers take a Words: the kernel's filter evaluation (beryl_kernel/src/filter.rs), layers::passes, the interpreter's scene (beryl_rules/src/interpret/scene.rs), trigger matching, the renderer (beryl_card/src/render/). Every one passes Words::NONE in this bead, behind a function State::words_of(object) that returns the identity. by-bajq.5.3 makes it real.
  5. A Capability says whether any card of the game can change text. words_of is the identity without reading anything when it is false.
