Scope (plan: State, K4):

  • Effects store: generalize FloatingEffect (state.rs:669, one object only) to affect an object, a player, a locked-in set or the game, with payloads for layer changes, rule changes, replacements, cost changes and permissions. Rule (card.rs:910, a u8 mask capped at 8) and static rule changes resolve through it.
  • Remove, by moving into stores: Player::sorceries_as_flash (state.rs:407; effect.rs:551, cast.rs:130, mana.rs:998, turn.rs:76, start.rs:33, relayout.rs:216, setup.rs:142); CastPermission's extra, exile and flashback fields (state.rs:600); Continuous::ExileInsteadOfGraveyard; State::entered_x; ObjectFlags KICKED, OFFSPRING, IMPENDING, EVOKED, EXILED_UNTIL, EXILED_WITH, LOYALTY_ACTIVATED (Memos); Counters' single long-tail kind (state.rs:158), with counter kinds generated from a list rather than CounterKind::Story and Chorus being special.
  • Trackers for this-turn and this-game counts, kept only when a card in the game reads them (GameTable capability bits, architecture §6.4).
  • Each store implements duration and expiry, relayout, checkpoint and save description, and observation once. Indexed by kind; an absent kind costs one AND.
  • State<Small> stays within 20 KiB (state.rs:868).
  • Label tier:fable the one or two beads that settle the design the rest build on (the three stores: their kinds, capacities, expiry and indexing); everything else follows the run epic's Models policy.

Models (2026-11-10, overrides the tier rules above)

Consequences for the design bead:
  15. A "locked-in set" as an effect's affected side is a 32-byte bitboard in Small. Sixty-four entries each carrying one would not fit: keep the sets in their own small table and name one by index, or cap how many effects affect a set.
  16. Counter kinds "each with its own count" cannot be per-object fields (255 objects): a keyed store of (object, kind, count).
  17. Where more bytes are, if needed: the stack is 64 x 60 = 3,840, a third of it the 8 targets per entry; delayed is 32 x 20. Put the size in the design bead's acceptance (a number, not "fits"), and have each store bead report the size at its push as the count is reported.
  18. The count gate has 0.10% of its own under the bar (404,858,188 against 405,276,238), plus the 1% tolerance. The stores are on the rollout's path wherever the layers read effects, so the design bead should say what an absent kind costs (the plan: one AND on a GameTable capability bit) before the other beads build on it.
  19. Carried from the M2 Mason (comment 7 on by-w8gv.5.1), still true: Continuous::Layer(Modification) stores the vocabulary's type, and Modification::Control(Seat) (beryl_card/src/continuous.rs:81) names a seat no definition can (K7); it exists for one site in effect.rs. The Effects store's payload should be the resolved form, as kernel Duration (floating.rs, carries the Seat) already is to beryl_card::Duration, and Modification::Control then loses its Seat.
  20. What the kernel's contract asks of a store (beryl_kernel/src/lib.rs): a store's writes are State mutators, #[inline] and generic over the layout; one whose change a player sees returns its Event and pushes nothing; a full store returns fixed::Full; the mutator that changes a layer input sets derived_dirty itself (Legacy::start_effect does today), so no rules code holds the flag; expiry is a mutator the rules call with the duration that ended, since the kernel moves the turn and holds none of its rules. by-w8gv.6.2 (this gate) adds a check that rules code never opens State::board().

  4. Found while reading, not on the audit's list: ObjectFlags::ENTERED_THIS_TURN is read by one static ability (The Wandering Emperor's rule, cast.rs) and never by the rules. .2 decides its store and .8 moves it with LOYALTY_ACTIVATED: together they give the Trackers store two real kinds. No card of the 47 reads a this-game or per-player this-turn count, so .8 builds no such kind.
  5. Nothing of the 47 modifies more than one object, so the locked-in set (.5) cannot be shown by parity: its acceptance is its own tests.
  6. The WU mirror the count gate plays holds Jace, Snapcaster, Teferi, The Wandering Emperor and Currency Converter, so permissions, the rule changes, both per-turn facts and the exile link are on the counted path; no impending card is. Each bead records bench-count before and after and the state size.
  7. The prompts milestone (by-w8gv.11) has landed, so nothing here races it; by-w8gv.19.8 may still split cast.rs, effect.rs and mana.rs under these beads.
