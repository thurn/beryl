Close reason

Casting steps, stack items and pending triggers are tagged unions; is_spell gone; State 20,216->20,088; count +0.41%, gate holds

Description

Current design

  • Casting (rust/crates/beryl_kernel/src/pending.rs:~46-75) holds step, part, graveyard_from, chosen, left, remaining, substituted and the bools free, resolving, triggered. Most fields mean something only at one CastStep; their doc comments say "For CastStep::Objects...".
  • StackEntry (beryl_kernel/src/stack.rs:~166-185) has object: Option<..> and ability: Option<FaceAbility>; x and costs are valid only for spells and info only for triggers, and callers tell which by the is_spell() convention. PendingTrigger (stack.rs:~258) repeats source, card, face, ability, controller and info.
  • relayout.rs copies each of these field by field, so every extra field is maintained in two places.

The next project (docs/rules-coverage.md) adds alternative and additional costs, copies of spells and abilities on the stack, and more trigger kinds: each lands in exactly these structs.

Proposed design

enum CastStep { X, TargetCount, Target, Plan, Manual { remaining }, Objects { part, graveyard_from, chosen, left } }
enum Payment { Paid, Free }
struct AbilityRef { source: Option<ObjectRef>, card, face, ability, controller }  // shared
enum StackItem { Spell { object: ObjectRef, x, costs },
                 Activated { of: AbilityRef },
                 Triggered { of: AbilityRef, info } }

PendingTrigger becomes { of: AbilityRef, info }. Fields that only exist at one cast step move into that step's variant.

Eliminates: the invalid combinations, is_spell(), the duplicated trigger fields, and the matching lines in relayout.rs and names().

Must not change

Game behavior, rollouts_never_change, frozen saves, the count gate with no bump (measure with just bench-count), and the size of State (record it before and after).

Test

Existing casting and stack tests (beryl_rules/src/tests/cast.rs, casting.rs, events.rs) pass; no Option field on StackItem's spell variant; is_spell is gone.

Acceptance criteria

Casting steps and stack items are enums carrying only their own fields; PendingTrigger shares AbilityRef; is_spell gone; all tests, frozen saves and rollouts_never_change pass; count gate holds with no bump.
