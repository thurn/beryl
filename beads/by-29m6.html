Notes

Claimed 2026-11-12 by the session that pushed a7d2f9ff. Two causes. (1) a7d2f9ff's light canvas (ui/src/stage/glow.ts) was taken for a cover by the motion audit, which counts any canvas as hiding what is under it: verb:appear and verb:vanish failed in both layouts from both seats. Fixed in 1197fe04 (ui/scripts/audit.mjs: a .stage-lights canvas covers nothing, as an svg root does not). (2) The mobile check failed from the next run on: Tauri's build script (swift-rs) left a Swift module cache in rust/target that names the path of the CI worktree it was built in, the cache was saved, and every later worktree cloned it and had it refused ('was compiled with module cache path ..., but the path is currently ...'). Fixed in 09f6127f (tools/src/beryl_tools/warm.py forget_module_caches: a clone drops those caches; swift rebuilds them). by mobile-check passed in a fresh worktree cloned from the poisoned cache. Waiting on slow CI at 09f6127f.
