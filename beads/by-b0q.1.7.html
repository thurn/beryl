Event pipeline, triggers, replacements, SBAs and layers on staging 235cd13

Description

Part of Milestone 1 (epic by-b0q): a rules-exact engine, game UI and AI opponents for a mirror match of the 40-card WU Control main deck in docs/sample-decks/2026-10-17-PrinceJools-wu-control.txt (29 distinct cards). Read the epic's description (plan, card table) and design field (decisions) first; docs/engine-architecture.md is the design. Rules code cites the Comprehensive Rules with yawgatog links and quotations (AGENTS.md).

Architecture sections 5, 8 and 9: the event pipeline and derived characteristics, for the event kinds and effects the 29 cards use (epic card table). Test with test-only CardDefs.

  • Event (8.1): zone changes with reasons, damage, draw, life, counters, tap and untap, token creation, cast, attack, combat damage to a player, step boundaries, transform, gain control, win and lose.
  • The pipeline (8.2): replacement lookup and ordering (CR 614, 616), look-back triggers with LKI (CR 603.10), execution, trigger matching, the event sink for the UI.
  • Triggers (8.3, CR 603): enters, attacks and "whenever you attack", dies with an intervening if (CR 603.4), upkeep, end step, combat damage to a player, "one or more" token creation, cast, delayed triggers (CR 603.7) such as Mana Drain's, APNAP ordering (CR 603.3b). Coin flips (CR 705).
  • Replacement effects: entering tapped, conditionally or unless a cost is paid (CR 614.12); entering with counters; exile instead of the graveyard.
  • State-based actions (8.4, CR 704): lethal damage, zero toughness, zero loyalty, tokens outside the battlefield.
  • Layers (9, CR 613), recomputed from base when dirty: copy (CR 707, token copies), control, type (becoming a Vehicle artifact and losing other card types; impending's not-a-creature), abilities (first strike, a granted crew), characteristic-defining power (Adeline), modifications (-2/-0), counters.
  • Tokens (CR 111); durations "until end of turn" and "until your next turn" (CR 611.2); exile "until" a permanent leaves (CR 610.3); emblems (CR 114).

Acceptance criteria

  • Engine tests cover every trigger, replacement and layer case listed.
  • A test shows derived is never read dirty.

Derek Thurn2026-11-05

Delivered on staging 235cd13 (commits 9a975c8..235cd13). New modules: event.rs (Event, Sink, zone-change pipeline with replacements, look-back LKI, settle), trigger.rs (matching, APNAP TriggerOrder decisions with equivalence collapse, delayed triggers, resolve of triggered abilities), layers.rs (recompute from base when dirty; State::derived debug-asserts clean). SBA: lethal damage, 0 toughness, 0 loyalty, tokens cease to exist; legend rule now moves through the pipeline (dies triggers). Invariants (1.5's) updated for tokens, EXILED_UNTIL links and a stale-derived check. State is 17,440 bytes. Deviations, all per epic decision 1 (only mechanics the 29 cards use):

  • CR 616.1 ordering of several replacement effects is not a decision: the cards' replacements are self-replacements for entering plus one floating 'exile instead', which never conflict (documented in event.rs).
  • No in-place Transform event: Jace exiles and returns transformed; EffectCtx::put_onto_battlefield takes the face.
  • 'Unless you pay N life' entering (Soporific Springs) is asked as Pending::EnterPayingLife only for land plays; an effect putting it onto the battlefield would need to ask first (none does).
  • Legend rule runs in the repeated SBA check after other simultaneous SBAs, not with them (it needs a choice).
  • Triggered abilities with targets are not handled when put on the stack (CR 603.3d): target selection belongs with casting's target machine (1.6); noted on the card beads.
  • trigger::resolve handles abilities only; spells resolve through 1.6's work. Object.controller stays the base controller; the real one is Derived.controller via State::controller(slot).
