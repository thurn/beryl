Description

The layers group (by-bajq.2) proved several behaviours with invented cards ('Test ...' CardDefs in rust/crates/beryl_rules/src/tests/) that no implemented real card has, so no card scenario checks them against XMage and Forge. Implement one real card per behaviour (the card-writing skill: just card brief, just card new, just card check with both oracles) and write the scenario that shows it. Cards in no deck are fine (root AGENTS.md).

Behaviours, each with the rules test that shows it now and a suggested card (pick another real card if the vocabulary fits it better):

  1. A static ability's 'as long as' that reads layer results, against a layer 4 change: layer_sets.rs a_condition_on_the_layer_results_is_read_as_its_layer_applies. Suggested: Wild Nacatl ('gets +1/+1 as long as you control a Mountain / a Plains'), with a scenario beside Blood Moon making a nonbasic land a Mountain.
  2. A layer set filtered by tapped and by mana value: layer_sets.rs a_filter_reads_whether_a_permanent_is_tapped_and_its_mana_value. Any real static with 'untapped creatures' or 'creatures with mana value N or less'.
  3. Setting colors and switching power and toughness (layer 5 SetColors, layer 7d SwitchPt after 7c counters): ability_removal.rs colors_one_lost_ability_and_switching_apply_in_their_layers. Suggested: a P/T switch effect (e.g. Inside Out) for 7d with a +1/+1 counter. AddColors on permanents is left to Painter's Servant (by-bajq.5.1).
  4. A static ability granted in layer 6 whose own effect applies in an earlier layer, so the layers run again: static_abilities.rs an_ability_granted_in_layer_6_applies_its_effect_in_an_earlier_layer.
  5. 'Each other' in a resolving effect (Objects::Other outside a static ability): effects.rs each_other_permanent_is_every_one_but_the_source.
  6. A layer 4 set that another layer 4 type change empties (CR 613.8a): land_types.rs an_effect_whose_set_a_type_change_empties_waits_for_it. Suggested: Life and Limb ('All Forests and all Saprolings are 1/1 green Saproling creatures and Forest lands') with Blood Moon on Dryad Arbor.
  7. A keyword granted after a 'loses all abilities' stays: ability_removal.rs a_grant_after_the_removal_stays_and_one_before_it_is_lost and the vigilance half of many_layers.rs equipment_attached_after_the_effect_grants_its_ability_and_before_it_only_its_bonus. Any real Equipment or Aura that grants a keyword, attached after Dress Down or Oko's +1.

Out of scope: the test definitions that check internals no scenario can see (dependency trial counts, the stale flag, the 3-pass cap, mask width stalls, table refusals).

Acceptance criteria

Each listed behaviour is shown by a scenario of a real card that passes just card check on Beryl, XMage and Forge (a disagreement settled by the rules and recorded in data/oracle-divergences.json). The count gate holds.
