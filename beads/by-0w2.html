Description

Retarget V1 to the Arena Powered Cube and its WU Control mirror

17lands publishes human pick, deck and per-turn replay data for the MTG Arena Powered Cube (~/17lands/Cube_-_Powered, see AGENTS.md); nothing comparable exists for the MTGO Vintage Cube. So V1 now targets the 540 cards of the Arena run that began 2025-10-30, data/arena-powered-cube-2025-10-30.csv (commit 69b8d7d), and the Milestone 1 mirror moves to a deck from that run.

The new mirror

docs/sample-decks/2025-11-18-17lands-cb8d5d5f-wu-control.txt: a mythic-rank drafter's WU control deck from 17lands game data (draft cb8d5d5feb0f48f7af41d2416adb42c3, build 0, Premier Draft, 1-3 in recorded games). Of all 70,000 Arena decks it shares the most cards (11) with the old mirror. 28 nonbasics + 6 Plains + 6 Island.

Already implemented (11): Jace, Vryn's Prodigy; Jace, the Mind Sculptor; Teferi, Time Raveler; The Wandering Emperor; Mana Crypt; No More Lies; Oust; Seachrome Coast; Spara's Headquarters; Staff of the Storyteller; Tundra.

Design

Decisions, 2026-11-05 (user):

  1. Target: the Arena Powered Cube run of 2025-10-30 as frozen in 17lands' data, not the current MTGO Vintage Cube. Rejected: keeping Vintage and using 17lands data only for the 389 shared cards (72% overlap loses pack context).
  2. Card names: Arena's. Six cards carry Through the Omenpaths names on Arena (Scryfall set om1): Ademi of the Silkchutes (Spectacular Spider-Man, #1), Goben, Gene-Splice Savant (Norman Osborn // Green Goblin, #30), Luis, Pompous Pillager (Morlun, Devourer of Spiders, #60), Makdee and Itla, Skysnarers (Spider-Woman, Stunning Savior, #145), Nia, Skysail Storyteller (Gwen Stacy // Ghost-Spider, #89), Yera and Oski, Weaver and Guide (Arachne, Psionic Weaver, #23). The engine, names.rs and the UI use the Arena names, which match 17lands' columns.
  3. Mirror: the cb8d5d5f deck, main deck only (its sideboard is listed after the blank line for reference). It replaces WU_CONTROL and the PrinceJools deck.
  4. Kept: Aang's Iceberg, Swift Reconfiguration and Sphinx of False Conclusions (implemented, not in the Arena cube) stay implemented, with their scenarios and mechanics, as cards outside the cube (user, 2026-11-05: never delete existing card implementations). Only data/vintage-cube-2026-10-07.csv is deleted with the mirror switch. The Vintage decklists in docs/sample-decks stay as references.
  5. The CSV's color column follows the Vintage list's scheme (the MTGO section for cards in both lists; Scryfall colors, or produced mana for lands, otherwise). Nothing reads it.
