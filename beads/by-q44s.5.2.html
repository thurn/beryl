Description

Read first: the epic by-q44s ('Rules for every bead'); rust/beryl3d/AGENTS.md; docs/beryl-3d.md 'The flat layer' (all of it), 'Hosts' (the inputs and requests), 'Sound'. Code, all in rust/beryl3d/crates/beryl_scene: src/element/mod.rs and prompt.rs, src/layout/mod.rs, write.rs and glyphs.rs, src/text/mod.rs, src/client.rs (Client::handle, show_prompt, point), src/command.rs, src/input.rs, src/frame.rs (Role), src/lib.rs.

Why this bead exists. Milestone 3 has nine tracks (tokens, elements, text, widgets, prompts, furniture and cards, screens, assets, the shell) worked by several sessions at once. This bead lands the types they share and the places their code is called from, with a stub in a file of its own for each piece, so that every later bead fills in its own file and none edits another's. It adds no behavior: every recording plays and prints exactly as before.

This bead builds on milestone 2's contract (by-q44s.3.2: light::Lit, Client::lit_mut) and its floats (by-q44s.3.3: FloatId, Layer::float, FloatLook, element::floats), which must have landed. Keep both as they are.

Build, all in beryl_scene:

  1. Element in full (src/element/mod.rs). Add to Style, each with a builder method of the CSS name and Default equal to today's behavior: display: Display (Flex, Grid, None); position: Position (Relative, Absolute) with inset: [Option<f32>; 4]; min_width, max_width, min_height, max_height; margin: [f32; 4]; shrink: f32 (default 1); basis: Option<f32>; wrap: bool; align_self: Option<Align>; grid_template_columns and grid_template_rows: Vec<Track> with enum Track { Points(f32), Fraction(f32), Auto }, and grid_column/grid_row: Option<(i16, i16)>; overflow: Overflow (Visible, Clip, Scroll); opacity: f32 (default 1); background: Option<[u8; 4]>, border: Option<([u8; 4], f32)>, radius: f32; color: Option<[u8; 4]> for text. Style stops being Copy because of the track lists; fix the callers. Add Element::anchor: Option<Anchor> with enum Anchor { Point(Vec2, Vec2), Object(Subject, Vec2) } (a point of the window or a scene object's projected centre, and which point of the element's box lies there), and Element::shows: Option<Shown> with enum Shown { Face(FaceId, FaceSize), Object(Subject) } (a face drawn flat in the element's box, or the scene object itself placed in it), and Element::spans: Vec<Span> with struct Span { range: Range<u32>, style: TypeStyle, color: Option<[u8; 4]> } (styled runs of text, by byte range), and Element::focus: bool (it takes keys). Deviations and choices: (1) screens::screen returns Element as specified, but game::game with no prompt returns an empty region 'game', so Client::show_screen shows nothing on the game screen while no prompt is open (otherwise every recording gains an empty top panel). The game screen's track should delete that condition once game::game shows anything of its own. (2) opening.rs and game_over.rs return Option<Element> (None), like the hud/inspect pieces, and are called from game::game, because an always-present region would change every recording. Sheets go through screens::sheet(sheet, input); until built, an open sheet replaces the screen in the flat layer. (3) ShapeBody has no Zone or Pile variants; Candidates is routed to pick.rs. (4) prompts::own is called from the next Client::frame (it needs now) on open and change; a close makes no call because own takes the open prompt. (5) screen/<name> recordings put the client on a screen through a 'beryl3d-open' FixtureMessage event (driver::OPEN) that Page::begin turns into Client::press(Open/Sheet); settings and bug-report open over start. (6) Shape stubs carry #[expect(clippy::unnecessary_wraps)]; it fails once a shape returns None, so the prompts track removes it. (7) Style setters are generated by two macro_rules! (one method per field); the old builders keep their names.
