Decisions.

  • Dirs::new(base, log_base, profile) takes Tauri's log folder from the caller. desktop_logs() is the same folder without Tauri (~/Library/Logs/ca.thurn.beryl, or %LOCALAPPDATA%\ca.thurn.beryl\logs on Windows). If Tauri cannot find a log folder, beryl_app falls back to <data>/logs instead of just warning. That only happens when there is no home folder, and in that case app_data_dir fails first anyway.
  • Beryl 3D does not open the journal (Dirs::open), because two processes writing and rotating one beryl.jsonl would conflict. It uses only data, and later bug-report work should write to dirs.bugs.
  • The Beryl 3D sweep's LINKED list and docs/checks.md now include beryl_shell. docs/beryl-3d.md names beryl_shell under 'What the two clients share' and under 'Checks and isolation', as code both shells use.
