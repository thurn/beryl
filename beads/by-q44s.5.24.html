Derek Thurn2026-11-16

Deviations from the plan: (1) No deck import. ui/src/screens/StartScreen.tsx has none (the deck library lives in the table lobby), so the screen copies the web and SessionCommand::ImportDeck was not added. (2) With a game in progress the start button follows the web: the first press only switches its label to 'Concede & Start', and the second press sends Concede and then Start. The web's 'resumed' shortcut, where a game resumed at launch is conceded without asking, is not copied. (3) Host a table, Join a table and the Credits button are left out; only the 'Solo table' entry is built. (4) in_progress counts only Deciding, Thinking and Playing, so the manual table (Status::Free) and a stopped session are not conceded. (5) Input::Agents now carries AgentView (title and description) rather than names, so the rows show the web's words. (6) Every web fixture recording answers list_agents, so the driver gives Input::Agents after a recording's first views. A game recording therefore stays on the game screen, and its element ids are unchanged.
