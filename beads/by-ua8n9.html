Derek Thurn2026-11-16

Handoff: In rust/crates/beryl_cards/src/tests/props.rs, scenario_strings collects setup and action strings before the test checks declared interactions. The Cavern of Souls scenarios name Universal Automaton, which is generated from the card store and absent from the handwritten card list. The handwritten list still defines which undeclared references the check flags. Applying that rule to all generated cards in a trial also flagged established setup fixtures across many card and generated scenarios, so this repair leaves that policy in place. The original focused test reproduced both failures. The focused test and local macOS slow suite passed with the fix, and Enact's fast checks passed before 6bc400e4 reached staging.
