Flat-layer floats with FloatId ids, FloatLook, per-float taffy trees, written every frame; pushed b24a0b9

Description

Read first: docs/beryl-3d.md 'The flat layer' ('Elements'), 'The frame' (bands 5 to 7); the epic by-q44s ('Rules for every bead'); rust/beryl3d/AGENTS.md. Code: beryl_scene src/layout/mod.rs (Layer, Layer::show, reconcile, root_style), src/layout/write.rs (Layer::write), src/element/mod.rs, src/client.rs (Client::frame), tests/flat_layer.rs.

What is missing. The flat layer holds one screen, the prompt bar, laid out in the bottom right corner of the window. Milestone 2 needs small elements at given points: the turn banner in the middle of the window, a pill above a player, a life total, the number that floats off it, the count on a pile and the count of cards scrolled off the end of a row. Milestone 3 builds anchoring in full; this is the least that milestone 2's tracks share.

Build, in beryl_scene:

  • pub struct FloatId(pub u16) in src/element/mod.rs, with the ids every track uses in one module, element::floats: BANNER 0, SCRY_PILL 1 and 2 (the viewer, the opponent), COIN 3, LIFE 4 and 5, LIFE_CHANGE 6 and 7, POOL 8 and 9, PILE_COUNT 10 to 15 (library, graveyard and exile for each side), ROW_COUNT 16 to 27 (each end of each of the 3 rows of each side).
  • Layer::float(&mut self, id: FloatId, element: Option<Element>) keeps or removes one float. A float is matched against the one it had, as Layer::show matches a screen: an equal element keeps its layout and its shaped text. Each float is a taffy tree of its own, laid out at its content's size, outside the root's flex flow, so that a float never moves the prompt bar.
  • pub struct FloatLook { pub point: Vec2, pub anchor: Vec2, pub opacity: f32, pub tint: Option<[u8; 4]> } and Layer::set_float_look(&mut self, id, look). point is in logical points, and anchor says which point of the element's box lies there, from (0, 0) at its top left to (1, 1). Setting a look lays nothing out and allocates nothing, so Client::frame may call it on every frame to move or fade a float.
  • Layer::write writes each float after the screen, in Band::Layer: a resolved element for each node, a panel record where the screen's rules give one (has_panel), and its glyphs, with the look's opacity and tint. Give write a parameter saying whether the prompt bar is open; floats are written whether it is or not. Change Client::frame to call it on every frame.
  • A float with a Press is found by Layer::press_at; one without is not interactive.

Do not build: anchoring to a table object, transitions, grid layout or scrolling, which are milestone 3's (by-q44s.5.1, item 2).

Tests, in beryl_scene/tests/flat_layer.rs: a float text "20" with point (100, 50) and anchor (0.5, 0.5) has its box centred there in Page::tree; setting a new point moves its corners and leaves Frame::work.layout_nodes at 0 in that frame; removing it removes its element; a float beside an open prompt bar leaves every corner of the bar where it was; a float is drawn while no prompt is open; a frame after set_float_look allocates nothing.

Run: just b3d cargo-test -p beryl_scene; just b3d lane.

Handoff: floats live in beryl_scene src/layout/float.rs (FloatLook, Layer::float, Layer::set_float_look); ids in element::floats (FloatId; paired ids are arrays indexed by side, viewer at 0; ROW_COUNT is [side][RowName order][left,right]). Each float is its own taffy root laid out with MaxContent space; relayout() now computes the root and each dirty float separately (shared fn compute). Layer::write(builder, camera, open) writes the screen only when open and floats always, after the screen in id order; look.opacity scales every draw's alpha and Resolved.opacity, look.tint replaces the glyph color only (panels keep token colors). press_at(point, open) searches floats first (last drawn first), then the screen if open; Client no longer drops pointer input while the bar is closed. set_float_look on a float not shown is a no-op, so show first, then set the look. Deviation: the bead's centred-float test reads the tree printout through agent::tree::tree (what Page::tree prints) on a Layer written directly, because Client has no API to set floats yet (the tracks that use floats add their own). Allocation check extended in tests/frame_allocation.rs (single-test binary). Doc: new 'Floats' subsection under 'The flat layer'. Numbers: b3d gate unchanged (pay-default layout_nodes 4, text_runs 2; verbs-zones layout_nodes 5); check pay-default 0 faults; lane passed in 30 s.
