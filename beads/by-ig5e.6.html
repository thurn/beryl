Description

Add Codex as a second provider, so the 18% of beads that Codex sessions worked are counted. The store's rows are provider-neutral: this bead adds a parser beside the Claude one and changes no accounting.

Design sections: "Sources", "Token accounting" (last paragraph).

Source, as found on 2026-11-15

  • ~/.codex/sessions/<yyyy>/<mm>/<dd>/rollout-<time>-<id>.jsonl (also look under ~/.codex/archived_sessions).
  • The session_meta line's payload has id, timestamp, cwd and git. Keep only sessions whose cwd is this repository or one of its worktrees.
  • event_msg lines with payload type token_count carry info.last_token_usage (input_tokens, cached_input_tokens, output_tokens, reasoning_output_tokens) for the request just made and info.total_token_usage for the running total. input_tokens includes the cached part.
  • response_item lines of type function_call and custom_tool_call, with their ..._output lines, are tool calls and results.
  • A bead's enact_session metadata holds the Codex thread id when enact_spawn_provider is codex.

What to build

  • Rows in requests and tool_calls with provider codex: cached input as cache read, the rest of input as uncached input, output including reasoning as output.
  • Bead windows by the same shell-command rules as Claude.
  • Prices for the Codex models in data/efficiency-prices.json, from the provider's published price page.

Shared context

  • The design is docs/efficiency-dashboard.md. Read the sections named above before anything else; the rest can wait. The decisions taken with the user are in the epic, bd show by-ig5e.
  • The dashboard's code is the separate Python project in efficiency/ (package beryl_efficiency, standard library only, pyre strict, black). It imports nothing from tools/ and nothing imports it. Read efficiency/AGENTS.md first once it exists.
  • Tests use small synthetic sources built in the test itself or kept under efficiency/tests/. The repository is public: never commit a real transcript, session record or command line from this machine.
  • Real data exists only on the main Mac (host jarvis). Where the acceptance criteria name a check against real data, run it there; if this session is on another machine, record that the check was not run in a comment on this bead and close on the tests.
  • Collection must stay free for agents: no hook, wrapper or prompt text may be added to any session, and ingest must never run inside another command.

Acceptance criteria

Tests on a synthetic Codex log: per-request tokens come from last_token_usage and their sum equals the final total_token_usage; a session whose cwd is another project is ignored; windows are found from its shell commands. On the main Mac, just efficiency summary --since all --provider codex shows non-zero requests, and coverage no longer lists Codex beads that ran on this machine as having no data.
