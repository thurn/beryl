Close reason

by cpu sample/report records CPU by context, kind and worktree; gap to top's figure not closed

Description

What is wrong

Nothing records where the Mac's CPU goes. The run log (runlog.py) records how long each check took, but not builds, the commands agents run by hand, editors or leaked processes. The figures in by-gdn3 came from a throwaway script that sampled ps every 2 seconds for 3 hours. That script could not name 15% of the CPU it saw, and it missed about a fifth of the work because short-lived processes exit between samples.

Change

Add a by command (and a just recipe) that samples every process's cumulative CPU time and appends one row per minute under $BERYL_CACHE, and a report command that sums the rows.

  • Attribute each process to a context: slow CI (by ci), fast check (by check or enact push), a command an agent session ran, or other. Use the process's ancestors and its working directory (one lsof -d cwd -Fpn call covers every process).
  • Attribute it to a worktree under .worktrees/, and to a kind: compile, Rust test, browser, oracle, simulator, editor, desktop.
  • Record the executable name of anything that falls in "other", so the report can list the largest unnamed consumers.
  • Headless WebKit pages are started by launchd, so they have no check or session as an ancestor. Find another way to tie them to the run that opened them (for example the slot files ui/scripts/slots.mjs writes) or report them as their own line.
  • Also record, per minute, the largest number of runnable threads seen, or sample total CPU each second, so the report can show bursts shorter than a minute.

Files

tools/src/beryl_tools/system.py (existing load and priority helpers), tools/src/beryl_tools/cli.py, justfile, a new module and its test under tools/tests/.

Done when

The report for a one-hour run names at least 95% of the CPU it saw, its total agrees with top's idle figure to within 10%, and tools/AGENTS.md or docs/checks.md says how to run it. The measurements behind this bead are in its parent, by-gdn3.
