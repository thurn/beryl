Description

Bring the documentation to the shipped state, and retire the two plan documents: docs/project-50k-part-2.md (this epic's) and docs/rules-coverage.md (the plan of by-bajq, whose own documentation pass was closed unrun and moved here).

  • docs/engine-architecture.md:
    • the sections by-bajq changed: §4 (state layout and capacities), §5 (identity and last-known information), §7 (decisions: the decider, the transaction around a step), §8 (events, replacement effects, triggers), §9 (the layers), §10 (mana that remembers), §13 (hidden picks), §20 (open questions now closed);
    • what this epic changed: §3 and §12 (Format, the turn as a plan, restarts and subgames), §5 (typed references), §6 (the card's shape, the phrase library, the generated bar), §7 (casting inside a resolution), §11 (who assigns combat damage, bands), §16 (the crate map and the module layout by rule), §17 (the bar for a card, the rulings ledger, both layouts, the sampled per-card tests), §18 if a build setting changed;
    • "Decisions planned for Part II" becomes the decisions as shipped, P1 to P16, in the style of the K table, with the measurements behind them (the sentence-template count, the guard table from the bug log, the compile-time series, the pilot's numbers);
    • the table of what each other game mode would still need, from the plan;
    • the non-goals and "Absent, and so not designed for" lists, which name things since built.
  • The two contracts (rust/crates/beryl_kernel/src/lib.rs, rust/crates/beryl_rules/src/lib.rs): remove what describes a state before these epics, and any reference to a bead or a plan decision by its number (root AGENTS.md, Conventions).
  • rust/AGENTS.md: the card tools as they are (just card rulings, just set plan, the generated bar, the phrase library), the present-cost gate and how to add a family.
  • docs/benchmarking.md: the present-cost gate's families. docs/checks.md: the rulings, rule-ownership and phrases checks, the sampled card tests and the nightly.
  • data/AGENTS.md: each data file these epics added.
  • data/census-coverage.json and the census numbers: rerun just census.
  • Keep from the plans, in the architecture document: the decisions tables, what was designed and not built, and each family's present-cost number. Then delete the two plan documents and fix every link to them (grep -rn "rules-coverage.md\|project-50k-part-2.md").

Follow "Writing for readers" in the root AGENTS.md.

Bars (every bead of this epic)

  • The plan is docs/project-50k-part-2.md. If its design is wrong for the code, build what is right and amend the plan's section in the same push. Never wait for an answer: record the choice in this bead.
  • The absent-cost gate holds with no bump (just count-gate). When you touched the kernel, the rules or the card vocabulary, report the count before and after in the close reason. If it cannot hold after three attempts, stop and say so on the epic: this is the one thing that stops the run.
  • size_of::<State<Small>>() stays within 20,480 bytes. Report the size if you changed it.
  • The frozen saves replay and rollouts_never_change holds (just test-rust).
  • Rules code cites the Comprehensive Rules with a quotation (just citations). A card file cites a rule only for a card-specific ruling.
  • A new card follows the card-writing skill and passes just card check <name> (Beryl, XMage and Forge). A keystone or partner is listed in data/rulings-ledger.json once that file exists, with every ruling a scenario or a reason.
  • No UI work. beryl_cli script-check must pass for a new card from both seats with the verbs and prompt shapes that exist.
  • A rules bug found on the way gets its docs/bugs.md entry, naming the guard that now stops its class.
  • A bead you file is tier:opus for design, keystones and reviews, tier:sonnet for partner cards, sweeps and measurements, and never tier:fable.

Acceptance criteria

The technical documents and the two contracts describe the code as it is, the two plan documents are gone with no link left to them, and just fmt and the fast check pass.
