Close reason

Landed seat-specific table and entry projections with deterministic 2,000-action coverage on staging as 64ec18ab. Enact fast checks passed.

Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Hidden information' (the redaction rule and the example at its end).

Create rust/crates/beryl_table/src/redact.rs:

  • pub fn seen_by(table: &Table, seat: Seat) -> Table: the same table where every object whose known_to excludes seat has its card replaced by Card::Hidden (add that variant), and a library's order is kept but its cards are hidden unless known.
  • pub fn entry_seen_by(entry: &Entry, table_before: &Table, seat: Seat) -> Entry: the same for a log entry and its changes: object names, random outcomes of shuffles (never sent to any seat) and the cards a look or a draw touched are removed unless the seat knows them.
  • Proposal lines go through the same function for their text.

The rule is exact: nothing returned for a seat may contain a card name for an object whose known_to excludes that seat.

Tests (tests/redaction.rs):

  • The doc's example: seat 0 draws; seat 0 sees the name, seat 1 sees none.
  • A random test: from a fixed seed, apply 2,000 random valid actions on a two-seat table (write tests/common/random.rs generating valid actions of every kind; later beads reuse it). After each, serialize seen_by and entry_seen_by for each seat to JSON and assert the text contains no name of a card that seat does not know. Give each test card a unique name so a substring search is sound. It must be deterministic and finish in under 2 s.

Run just test-rust -p beryl_table.

Acceptance criteria

seen_by and entry_seen_by exist and are used by nothing else yet; the doc's example and the 2,000-action random redaction test pass deterministically in under 2 s; tests/common/random.rs generates every action kind.
