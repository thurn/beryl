Description

Enact's helper, ~/enact/scripts/enact.py, is about 5,000 lines of stdlib Python that takes roughly 100 ms to start before it does any work. Once by-r61mr has shipped, the ticket CLI is a Rust binary and enact.py runs it for every ticket, claim and lease operation.

This epic moves Enact's remaining commands (worktrees, push and the merge queue, the slow-CI runner, next, start, sync) into that same Rust binary, so every Enact command starts in milliseconds and there is one program to install. The user chose on 2026-11-16 to do this only after the cutover has settled and the bd shim has been deleted, so that working, tested code is not rewritten during the migration.

Keep the command names, flags, exit codes and output that the skills and role prompts rely on, and port the unit and integration tests in ~/enact/tests/ along with the code.
