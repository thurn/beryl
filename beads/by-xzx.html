Cause: ui-test 'the log folds away from a crowded table…' measured cutText before Crimson Pro (bundled, --font-card) had loaded. On the loaded CI machine the fallback font (Iowan Old Style) has a taller glyph box, so the P/T numerals '1' straddled span.card-pt. Reproduced exactly by forcing --font-card to the fallback. Product is fine; the test raced font loading (caff8a75's layout changes likely tightened the margin). Fix fdddbfd9: cutText (ui/scripts/capture.mjs) forces a layout then awaits document.fonts.ready before measuring, covering every caller. No tests deleted. just ci passed locally.
