Description

Part of Milestone 1 (epic by-b0q): a rules-exact engine, game UI and AI opponents for a mirror match of the 40-card WU Control main deck in docs/sample-decks/2026-10-17-PrinceJools-wu-control.txt (29 distinct cards). Read the epic's description (plan, card table) and design field (decisions) first; docs/engine-architecture.md is the design. Rules code cites the Comprehensive Rules with yawgatog links and quotations (AGENTS.md).

Design decision 16: the tooling that makes any part of docs/ui_mockups/ comparable 1:1 with what the UI renders. The pixel-fidelity beads use it.

  • Replica mode. A dev-only route (for example ?replica=<mockup>), kept out of production builds, renders a hand-authored fixture copying one mockup's board through the fixture transport: the same cards, names, P/T, life totals, zones, tapped states, stack, arrows and overlays, at the mockup's native size with device scale factor 1 (1672×941 for the four screens, 1536×1024 for ui_system.png). Replica fixtures may carry their own display data for cards outside the M1 deck: Inferno Titan, Baleful Strix, Goblin Guide, Lightning Bolt, Swords to Plowshares, Mountain, Plateau, Swamp, Counterspell, Preordain, the Beast and Angel creatures, and the graveyard's top card.
  • Mockup art. A committed region file gives each card's art window in each mockup. The harness cuts those windows out of the mockup PNGs at run time into a gitignored folder, and replica fixtures use them as art. Never committed; dev-only.
  • Parts. The same region file names every distinct part of every mockup with its rectangle and optional mask rectangles (for example battlefield/opponent-life-orb, ui_system/04-tapped, scry/done-button). Inventory all five mockups part by part, meticulously; the fidelity beads refine it.
  • just ui-compare [part-glob] [--zoom N] renders the replicas with headless Playwright WebKit (reuse just ui-shots), crops each part from the mockup and the replica, and writes per part: both crops, a side by side, a 50% onion skin, a difference image with masks blacked out, and a flip page (HTML alternating the two). Composite with canvas in the headless browser rather than adding an image library. Zoom is nearest-neighbor. It prints the output paths.
  • just ui-probe <mockup> <x> <y> [<w> <h>] prints the color at a point, a region's mean color, and the edges found along a row or column, for measuring sizes, radii, borders, shadows, glows and gradients.
  • Font sheets. A mode that renders candidate families over a cropped mockup text sample at matching size: open-licensed fonts (bundled) and macOS system fonts (referenced by name, never bundled).
  • The card back. Our own Project Beryl back, drawn in SVG or CSS after scry.png (brown leather, gold crest and wordmark, five colored dots), used for every library and the opponent's hand. Three mockups show the MAGIC back; mask its artwork in their regions, so shape, size, stacking and shadow are still compared. Nothing of Wizards' card back goes into the repo or the app.
  • Mask the mouse cursor in scry.png and in section 06 of ui_system.png.

Acceptance criteria

  • just ui-compare 'ui_system/*' writes all five outputs for every listed ui_system.png part; just ui-probe prints colors and edges; a font sheet renders.
  • Replica fixtures for all five mockups render without errors (rough is fine; later beads refine them).
  • The region file covers every distinct part of the five mockups; a comment on this bead lists the parts per mockup.
  • Replica code is absent from the production bundle (checked in the build output).
  • No mockup crops, screenshots or outputs committed; nothing opens a window; typecheck, prettier and just check pass.

Decisions and deviations:

  • Not through the fixture transport: the table is not IPC-driven yet (by-b0q.1.12 adds PlayerView but does not wire the table). TableScene now draws a TableBoard (screens/Table.tsx); replicas pass hand-authored boards (ui/src/replica/boards.ts, stage coordinates = mockup px / 1.045). When the table reads PlayerView, these boards become PlayerView fixtures.
  • Mockup art reaches cards through a SlotArt React context (components/Card.tsx): replica mode maps slot names (regions.json 'art') to /replica-art/<mockup>/<slot>.png; outside replicas it is empty, so the game is unchanged. Art windows take an optional 'rotate' (tapped -90, fanned hand cards) and are cut upright.
  • Art is cut into ui/replica-art/ (gitignored, served by Vite dev only) by ui-compare and ui-shots. Replica mode is behind import.meta.env.DEV + lazy import: a production build has one JS chunk with no replica code or strings and no candidate fonts (checked).
  • ui-shots now also captures the five replicas at native size (slow CI catches page errors there); settle waits for the app to render and for images.
  • Font sheet candidates: 8 @fontsource-variable packages added as devDependencies (Cormorant Garamond, Crimson Pro, Libre Baskerville, Source Serif 4, Cinzel, Open Sans, Source Sans 3, Noto Sans) plus the app's EB Garamond/Inter; 13 macOS families by name (missing ones are flagged). A family adopted by a fidelity bead moves to dependencies and design/fonts.ts.
  • The Project Beryl card back already existed (CardBack in Card.tsx, CSS + SVG crest); unchanged here, left to by-b0q.1.27 for fidelity.
  • Rough spots left for the fidelity beads: the combat banner has minimal new styles (.step-banner); the stack item's rules text is too large and overlaps the priority pill in the trigger replica; SAMPLE.angel carries a flying badge the mockups do not show.
