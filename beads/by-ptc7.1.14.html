Close reason

Nontoken copies of transformed back faces have mana value 0. Regression and performance bars verified on staging 67a5b5f3d.

Description

A card permanent copying Jace, Telepath Unbound has mana value 2 at staging 950e3c614. A scratch kernel probe put Jace on his back face, copied it onto a nontoken using State::become_copy, and read 2 for both the original and the copy. CR 712.6d gives the original 2 and the copy 0. State::mana_value in beryl_kernel/src/query.rs checks is_token as the proxy for a copied back face. The existing token regression in Fractured Identity passes because that copy is a token. Use the origin of the currently effective face to distinguish a physical back face from copied values. Preserve the stack X, original front-face cost, face-down and merge cases.

Acceptance criteria

A deterministic kernel/rules test compares an original transformed Jace to a nontoken copy of its back face and sees 2 and 0 respectively. Keep the existing token copy regression and record the bug and guard in docs/bugs.md. Preserve the size and absent-cost bars.
