Close reason

nightly launchd agent runs coverage on origin/staging at 03:00 (hourly retries to 08:00); installed, kicked run logged ok

Description

Run coverage recording nightly (plan K19: "A nightly Chromium run records the functions and CSS rules each browser check executes"). Step two of the CI track (by-w8gv.20). Builds on the coverage bead, which adds by coverage.

Decision already made (by-w8gv.20.5)

Nothing nightly exists in the repo or in Enact (the Marshal's hourly task nudges sessions; it runs no work). A launchd agent on the development Mac runs it. It costs no agent tokens and runs with no session open. Coverage lives in that machine's $BERYL_CACHE, as the run log does.

What

  • by nightly: fetch origin, run by coverage on origin/staging's tip under utility QoS, append one line to $BERYL_CACHE/nightly/log.jsonl (time, commit, seconds, outcome) and keep the last run's output beside it. Skip, logging why, if the last success is under 20 h old or the load average is over twice the core count (retry hourly until 08:00). Give it one entry point that later nightly work can join: the presentation track's motion captures and the nightly fuzz (by-w8gv.21's epic, "Agreed with the CI track").
  • just nightly-install writes and loads ~/Library/LaunchAgents/ca.thurn.beryl.nightly.plist (03:00 daily, plus hourly retries as above), idempotently, pointing at the main checkout's tools. just nightly-uninstall removes it. On Windows both print that it is unsupported and exit 0. The fast check falls back without coverage (the selection bead).
  • Install it on this machine. File a non-blocking bead labelled human (no approval wait, K31) saying the agent was installed, what it runs, and how to remove it.
  • just ci-report prints coverage's age in one line, so a stale nightly is visible.

Files

New tools/src/beryl_tools/nightly.py, cli.py, justfile, system.py (QoS helper, loadavg).

Tests

pytest for the skip rules (fresh success, high load) with a fake clock and runner. By hand: launchctl kickstart the agent once and show the log line.

Acceptance criteria

just nightly-install loads a launchd agent that runs by nightly (coverage on origin/staging) at 03:00 with the skip rules; one kicked run logs to $BERYL_CACHE/nightly/log.jsonl; pytest covers the skip rules; a human bead says it was installed.
