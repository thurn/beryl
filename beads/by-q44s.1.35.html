Description

Read first: docs/beryl-3d.md 'Interface checks' and 'Test speed' ('How a test costs a millisecond': the check times and the differential test). Read ui/scripts/stage-audit.mjs and audit.mjs for the exact rules of 'every step shown' and 'not crowded'.

In rust/beryl3d/crates/beryl_scene, behind driver where it needs Page:

  • The checks that read segments and steps: no jumps (where one of an object's segments ends and the next begins, the poses are equal); rest equals placement; each step is played for the duration its StepTiming gives; every step shown; not crowded. Port the last two from the web's audits with their thresholds, which go in data/beryl3d/gates.json under audit.
  • Page::check_times(): the frame after each input that changes the tree or starts a script; each segment's start, midpoint and end, and a flight's apex; the start and end of each flat-layer transition; the first still frame after each script.
  • Page::check_all(mode) -> Checked, with mode one of AtCheckTimes or EveryTick. It returns the faults and the number of frames it evaluated.
  • Functions that plant each kind of fault at a given tick, for the differential test the runner bead writes.

Tests in beryl_scene/tests, on hand-built scripts: two segments that do not meet fail 'no jumps'; an object left off its placement fails 'rest equals placement'; a step whose subject is outside the window fails 'every step shown'; four moves beginning at once fail 'not crowded'; and on a three-beat script, every fault that EveryTick finds, AtCheckTimes finds too.

Report in a comment: the frames evaluated both ways on the three-beat script.

Run: just b3d cargo-test -p beryl_scene.

Acceptance criteria

Each check fails on its planted fault and names the element and the moment; AtCheckTimes finds every fault EveryTick finds on the test scripts; the frame counts are in a comment.

The differential plants each of the five fault kinds (jump, off placement, short duration, unseen, crowded) at 450, 610, 900 and 1200 ms; for every plant, each fault EveryTick finds, AtCheckTimes finds too. Decisions: (1) No jumps exempts instant changes of verbs that do not travel (only fly travels so far; appear, vanish, set and the unbuilt verbs drawn as instant changes may place without a path) and any change while a side is transparent. (2) Every step shown judges only fly and appear, the verbs that are built and move a card; appear's window is [to, to+150ms), half-open, because the far edge is no check time (the differential caught this). (3) Seen = centre inside the window, covered <= 0.5, opacity > 0.3. (4) Compile builds the step and segment records only when the show keeps a history or has a plant, so handle's allocation gate is unchanged. (5) Page now takes a reply's due time from Client::rested() (when the last script ended), so the two modes play a recording identically. (6) The flat layer has no transitions yet, so they add no check times.
