Close reason

Guests can resume their saved join after restart. Verified in-process and over loopback TCP.

Description

Manual multiplayer QA requires a guest who quits and reopens Beryl to rejoin the same table without a fresh invite. GuestSession retains the dial closure in memory and TableConnections only saves host tables. Read rust/crates/beryl_table_session/src/{connections,sessions,guest}.rs and ui/src/table/lobby/TableEntries.tsx. Preserve the active join across an app restart and clear it on an explicit leave.

Acceptance criteria

An offline integration or kept browser test restarts the guest session with its persisted profile and verifies the same saved game and a working action with no new invite. Explicit leave clears the saved join.
