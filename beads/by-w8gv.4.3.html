Fast check runs scale tests when card or vocabulary files change

Description

From the M2 Mason audit (by-w8gv.4.1): the one check failure M2 caused, and the selection rule that let it reach staging.

CURRENT tools/src/beryl_tools/checks.py, fast() (about lines 630 to 660) adds the python lane only when a changed path matches ^tools/. But tools/tests/test_scale.py reads Rust: scale.pool() and the clone tests read rust/crates/beryl_cards/src/<color>/*.rs, and scale.card_crates() reads rust/crates/beryl_cards/Cargo.toml. M2's card port (3ff04752) changed only card files, passed the fast check, and failed slow CI in test_scale (Steward by-1ebx, fixed 9ea29fdd). The same port broke just scale's generated workspace (shards did not depend on beryl_card) with no check failing; 71126927 fixed it and made test_generated_workspace_holds_every_card_once assert every crate a pool card uses is a shard dependency. That test still runs in the fast check only for a change under tools/. Milestones 3 to 5 add crates (beryl_kernel, beryl_rules) and rewrite every card file. Each time one of them breaks the scale harness, staging goes red and a Steward session is spent on a failure its author could have seen in a second.

PROPOSED In fast(), when a changed path matches ^rust/crates/beryl_cards?/ (card files, the vocabulary crate and their manifests) and the python lane was not already chosen, run pytest on the tests that read those files: today tools/tests/test_scale.py alone (0.75 s on its own). One step, logged in the run log like any other (look at how python_lane()'s pytest step and beryl_tools.checks pytest take test names; reuse them). No black or pyre for a Rust-only change. If other Python tests read files outside tools/ that the fast check would miss the same way, include them in the same step and list them in a comment; grep tools/tests for paths.RUST, paths.REPO and scale.CRATES. Do not build a general declared-inputs mechanism.

WHAT IT ELIMINATES The class "a Rust change breaks a Python test that reads Rust, seen first by slow CI".

MUST NOT CHANGE Slow CI's lanes; the 60 s fast budget; what the python lane runs for a change under tools/.

FILES tools/src/beryl_tools/checks.py (fast(), python_lane()), tools/tests/test_checks.py (lane-selection tests to extend), tools/tests/test_scale.py and tools/src/beryl_tools/scale.py (read only). AGENTS.md, Checks, first bullet: one clause saying a card or vocabulary change also runs the scale harness's tests.

Acceptance criteria

A test in tools/tests/test_checks.py shows: for changed paths ['rust/crates/beryl_cards/src/blue/counterspell.rs'] or ['rust/crates/beryl_card/src/effect/mod.rs'] the fast check's chosen steps include one that runs tools/tests/test_scale.py; for ['rust/crates/beryl_engine/src/turn.rs'] they do not; for ['tools/src/beryl_tools/scale.py'] the python lane runs as before and the scale tests run once. The bead's handoff states the seconds the new step adds to just check for a card-file change (at most 3). just check passes.
