Decisions and deviations:

  • expert is in beryl_search::RETIRED, so the start screen never lists it. Added a tools-only app option --offer <agent> that appends agents to the start screen's list; the stand-in passes --offer expert, scrolls the list and presses toggle "Expert".
  • The list needs scrolling, and no action could turn the wheel: added the action 'wheel <locator> <x>,<y>' (tests, drive scripts, live).
  • The tree did not mark the primary button: added the state word 'primary' (StateBits::PRIMARY, set by widgets::primary).
  • The tree has no turn number, so the resume check compares life totals, pile counts and every card by name (or id when face down) and place, leaving out cards in 'nowhere'.
  • 'live tree' now starts with 't=<ms>ms' (the app's clock, for the 60 s prompt limit); 'live quit' ends the run as closing the window does, so the stand-in quits mid-game like a person and the frame log gets its summary.
  • just b3d live refused to choose while sockets of killed apps were left in TMPDIR (smoke killed the app with a signal); it now deletes sockets whose process is dead.
  • The rule's 'first enabled button' is limited to the prompt region, so Settings is never pressed. Bug found and fixed: about one game in two stalled with no prompt on the player's turn. The game thread sends the next decision's view before the session thread's Answered reply to the click that ended the previous decision, and Client::handle closed whatever prompt was open on Answered. The client now tracks the decision of each click in flight (beryl_scene client/mod.rs clicks, own.rs click_replied); test flat_layer::an_answer_to_the_decision_before_leaves_the_next_prompt_open.
