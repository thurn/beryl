Description

On Enact 0f63efebd58c, the full local Wrangler cutover rehearsal failed in the en mismatch case twice. Instrumenting the second run showed the operator returned [Errno 66] Directory not empty while removing archive/frozen/dolt-backup-*/.dolt. The by case reached the expected comparison rollback. scripts/cutover.py freeze places the transient DOLT_ROOT_PATH, which Dolt can populate asynchronously, under the same TemporaryDirectory as the raw backup. Remove that cleanup race, for example by isolating and quiescing private Dolt state before deletion. Confirm the source of the extra filesystem writes. cli/tests/cutover-rehearsal.py currently replaces the useful error with KeyError when details is absent. Preserve the operator error in the test assertion.
