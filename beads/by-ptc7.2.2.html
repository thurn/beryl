What to do

For each of these cards, make its entry in data/rulings-ledger.json complete (just card rulings <name> --add, then fill each entry):

Blood Moon, Humility, Opalescence, Oko, Thief of Crowns; Urborg, Tomb of Yawgmoth; Dryad Arbor; Glorious Anthem; Tarmogoyf; Dress Down.

For each ruling:

  • If a scenario of the card already shows it, name the scenario.
  • If none does and one can, write the scenario in the card's file, with a comment that says what the ruling requires in your own words (do not paste the ruling), and name it. Follow the card-writing skill for scenarios. A scenario about two particular cards uses Scenario::interaction.
  • If a vocabulary entry or a rules-library scenario (beryl_cards/src/library/) shows it for every card, mark it covered and name that.
  • Otherwise mark it untestable with the reason. "Needs a card nobody has implemented" is a reason only if the card would be large: a simple real card is implemented (the skill, "Cards for scenarios").

Run just card check <name> for each card you touched, so XMage and Forge play the new scenarios. An oracle disagreement is settled by the rules and recorded with just card diverge.

A scenario that fails on Beryl is a rules bug. Fix it if it is small, with its docs/bugs.md entry. If it is not, mark the scenario's entry untestable with the bead you file for it as the reason (a child of this milestone, tier:opus, naming the ruling, the scenario and what Beryl does), so the ledger check passes and the bug is tracked.

The ledger tool is a dependency of this bead; read its close reason for the file's format.

Bars (every bead of this epic)

  • The plan is docs/project-50k-part-2.md. If its design is wrong for the code, build what is right and amend the plan's section in the same push. Never wait for an answer: record the choice in this bead.
  • The absent-cost gate holds with no bump (just count-gate). When you touched the kernel, the rules or the card vocabulary, report the count before and after in the close reason. If it cannot hold after three attempts, stop and say so on the epic: this is the one thing that stops the run.
  • size_of::<State<Small>>() stays within 20,480 bytes. Report the size if you changed it.
  • The frozen saves replay and rollouts_never_change holds (just test-rust).
  • Rules code cites the Comprehensive Rules with a quotation (just citations). A card file cites a rule only for a card-specific ruling.
  • A new card follows the card-writing skill and passes just card check <name> (Beryl, XMage and Forge). A keystone or partner is listed in data/rulings-ledger.json once that file exists, with every ruling a scenario or a reason.
  • No UI work. beryl_cli script-check must pass for a new card from both seats with the verbs and prompt shapes that exist.
  • A rules bug found on the way gets its docs/bugs.md entry, naming the guard that now stops its class.
  • A bead you file is tier:opus for design, keystones and reviews, tier:sonnet for partner cards, sweeps and measurements, and never tier:fable.

Acceptance criteria
