Close reason

Pruned for every player under the smart stops; pins and count gate updated

Description

Since e34affb, cards declare what an activated ability needs (beryl_engine::card::Needs) and Profile::hides_pointless hides activations that would do nothing (Currency Converter's {T} with nothing exiled) from the human under smart stops only. Search, rollouts and expert-frozen still see them.

Measured with pruning on for every player under Stops::Smart (WU Control mirror corpus, which plays Currency Converter):

  • rollouts: 13,845 -> 13,623 decisions (-1.6%), 1,679 -> 1,666 turns
  • count gate: -1.18% instructions (436.75M -> 431.60M), with the needs check gated by a GameTable bit (a per-face bitmask in FaceFacts cost +2%)
  • frozen_moves_never_change and rollouts_never_change move: expert-frozen's moves change, voiding results measured against it, and a running longthink cannot adopt the binary in place.

Needs the user's call: is the search saving worth re-freezing the reference opponent? If yes: set hides_pointless for both seats in the search/rollout profiles (or prune under Stops::Smart), update both pins and lower count-gate.toml's bar.
