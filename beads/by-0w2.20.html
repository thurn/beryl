Description

Found by the architecture audit of the Arena retarget (by-0w2.14).

Current design

Each of the 28 fixtures in ui/fixtures.json is a seeded game between agents (beryl_cli's fixture.rs), played until a stopping condition, often with where conditions on the view. Fixtures that need a particular board were found by seed search: combat-double-block is seed 12001 from turn 36, marks-damage is seed 392, and attached-across uses fuzz decks. So anything that changes a game's course breaks them, even when the engine's behaviour is otherwise unchanged: a card added to the fuzz pool, a deck change, an agent retune, smart-stop changes.

This milestone alone:

  • 82fb5a9 reseeded attached-across after card additions reshuffled fuzz:20.
  • 2d7e268 reseeded arrow-ability; 7c72e48 and 8bb8649 reseeded for smart stops.
  • Two Steward beads (by-4b0, by-3px) were slow-CI failures from the same cause.
  • be17bae moved 8 fixtures back to vintage-wu-control because the new mirror never reached their boards. That deck now survives mostly for them.

by-0w2.17, retuning greedy right now, will change the game of every greedy-agent fixture (17 of 28).

Proposed design

A fixture can start from a board instead of a seed:

enum Start {
    Seeded { seed: u64, decks: [String; 2] },
    Board(Board), // a beryl_cards scenario by "<card>/<scenario name>", or an inline setup
                  // in beryl_scenario::Scenario's vocabulary (turn, step, battlefield, hands,
                  // libraries)
}
  • The session starts from the state beryl_scenario builds, through a StartGame variant or a Sessions entry point that takes a prepared state.
  • Agents play on from there to the stopping condition, as now.
  • Convert every fixture that has a where condition or a vintage deck.
  • Keep seeded whole games only where an organic game is the point: late-game, greedy-turn-9, opponent-turn, and any game-over fixture.

This removes seed hunting and reseed commits, and makes board fixtures independent of agent strength and of the card pool. Fixtures would probably no longer need vintage-wu-control.

Must not change

  • Every shot in ui/shots.json is still captured and shows the board it is for.
  • just ui-test still passes.
  • just ci stays within its 300 s budget (186 s now).

Acceptance criteria

  • Every fixture with a where condition, and every fixture on vintage-wu-control, starts from a board.
  • After a deliberate change to greedy's card values (rust/crates/beryl_search/src/values.rs), or with a card added to the fuzz pool, every board fixture records the same messages as before. Show it in a test or in the bead's close note.
  • just ui-shots and just ui-test pass, and just ci passes within budget.

Derek Thurn2026-11-06

Executor notes. Design as built (deviates from the bead's sketch where noted):

  • Boards are beryl_scenario Scenarios defined in rust/crates/beryl_cli/src/boards.rs (typed, using the scenario builder), named from ui/fixtures.json by "board". Not inline JSON setups, and not "<card>/<scenario>" refs: card scenarios end past the moment a shot needs.
  • The board's actions are a script played THROUGH the session: a Scripted agent per seat (boards.rs) takes that seat's actions in order. Short of its next action it passes priority, takes the first payment plan, answers forced questions; any other mismatch fails the recording. A seat whose actions are used up passes and takes first candidates. The recording also fails if any action was never taken. A scripted prefix outside the session was rejected: opponent-turn and the combat declarations need those turns recorded as views.
  • Boards take no agents, so they never consult greedy or any agent. New API: beryl_session::Prepared + Sessions::start_prepared (writes no replay); beryl_scenario::answer/describe, factored out of the strict runner.
  • Converted all 21 fixtures with a where or vintage-wu-control, opponent-turn included (the bead listed it as organic, but the acceptance requires it, and the board keeps its checks: a look, then an opponent turn with a land and a spell resolving). Dropped the fixture vintage-wu-control deck option; VINTAGE_WU_CONTROL stays (beryl_cards tests use it). shots.json at/slot numbers and interactions.mjs's hard-coded at:799 re-pointed.
  • Acceptance #2 evidence: changed greedy values (JTMS 90->10, Mana Crypt 70->5, Teferi TR 80->20) and the fuzz pool (dropped Mana Tithe from fuzz_deck), rebuilt, re-recorded. All 21 board fixtures byte-identical. Seeded late-game changed and stack-tall failed to reach its stop. Reverted.
  • New test every_board_fixture_records records each board fixture under just test-rust (all 21 in ~0.1 s), so the fast check catches a broken board (answers the Sage comment). Recording all 29 fixtures: 1.7 s, was ~9 s.
  • just ui-test and just ui-shots pass locally. One ui-test run hit 'trigger-order prompt shows the longest names' (an unchanged seeded fixture); it passed on rerun, so it's a flake.
