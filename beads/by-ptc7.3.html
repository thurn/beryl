Description

Make simple cards cheaper to write and test. Cover every part of a definition with mutants and generation, allow cards with no hand-written scenarios when the checks pass, provide shared prelude functions for useful compositions, and build a brief that drafts, a set planner and a rewritten card-writing skill. Prove the workflow on the existing cards and a dozen new ones. See Designs E and the revised P9 on by-ptc7.
