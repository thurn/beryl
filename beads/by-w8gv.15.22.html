Description

Reported-only match for by-w8gv.15.3 (milestone M8 of Project 50k, run epic by-w8gv). It must run on Cygnus, the Windows PC that plays every AI match (docs/ai-strategy.md §4.1); the Mac plays no ladder games, so the executor that built the estimate could not run it.

What it compares

by-w8gv.15.3 (staging 85a8963e) added rust/crates/beryl_search/src/estimate.rs, which values a card from its definition's effect data, and made Knowledge::Estimate (family name estimate) use it with no per-deck overlay. This match plays the champion's family with only its knowledge changed (derived-only) against the champion itself (hand-tuned overlay), on the WU mirror.

Steps

  1. On Cygnus, in a checkout at or after staging 85a8963e, with nothing else heavy running, run in the background: just ladder pimc72/hidden/rollout/estimate/anchor+guard --vs pimc72/hidden/rollout/tuned/anchor+guard --work 3M --bar audit --cap 100 --positions D:\beryl-cache\ladder\positions It plays all 100 games and prints the challenger's score with its 95% interval.
  2. Record the score with its 95% interval, the game count and the commit as a comment on by-w8gv.15.3 and on the milestone epic by-w8gv.15 (bd comments add ..., then enact sync).
  3. If the command fails in a way these steps do not cover, write what happened on this bead and on by-w8gv.15.3, and close this bead as failed.

Rules

  • No bar: never rerun it, never tune anything to it (run epic by-w8gv, "Defaults for anything measured on samples").
  • It is not a ladder rung: write no row in docs/ladder.md, change no champion, commit nothing. No code change, so no worktree is needed.
  • Expect derived-only to lose clearly (run-003 found hand-tuned values beat 17lands win rates by about 90 Elo, docs/ai-strategy.md §2.1).

Acceptance criteria
