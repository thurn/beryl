Derek Thurn2026-11-16

Cause: the bench VM was stopped (around 15:14-15:19) before the guest flushed the count gate's callgrind outputs, so files under ~/gungraun/count-gate/.../present_cost//callgrind..out.old began with zero bytes instead of their header. Gungraun parses the .old file to print a since-last-run diff, so count-gate-families failed on every commit (bisect blamed none). Reproduced locally. Fix d16a70772: count_script deletes the gate's Gungraun home before each run (the gate never reads Gungraun's comparison); worktree homes keep theirs. All 8 families pass after the fix.
