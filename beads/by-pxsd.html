Derek Thurn2026-11-14

Cause differs from the planned interpretation. The stage's draw track was already continuous: filmed with 'just motion --film fly draw', the held card's rotation goes 0 -> 0.05 -> ... -> 6.41 with no jump. The jump only happened with the pointer over the hold place. A drawn card's resting place is in the hand while it flies, so the pointer hovered it, and StageBoard's hand raise applied --raise-turn = -(its fan slot's rotation, about +12 deg at the fan's right end) to a card flying upright, tilting it about -12 deg. This matches the report's window.png, where the inspector shows Tundra, so the pointer was on it. Deviation from the acceptance criteria: no verb check on rotation continuity was added, because the stage's poses never had a discontinuity and such a check could not catch this bug. The pointer unit test covers the real cause. Side effect: the inspector no longer opens for a card in flight.
