Description

Review server/ as built by the three ticket-server beads, and fix what you find. This server will coordinate every unattended session, so look hardest at: two requests interleaving inside the Durable Object across an await; a claim or lease that two callers can both believe they hold; a lease that never expires or expires while its holder is renewing; a parent closing while a child is being filed under it; a WebSocket that keeps the object awake; any path that polls; and any operation whose requests or rows written exceed the contract's budget table.

Run the suite in wrangler's local simulator and add a test for each defect before fixing it.
