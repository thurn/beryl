Description

Seen after by-drghs's delve fix (bbf80243) let just fuzz go further: agents_decide_the_same_on_a_redeterminized_state (rust/crates/beryl_search/tests/games.rs ~line 494) fails with "seed 2655: the determinized game ended: Stalled(DecisionsPerTurn)". At some decision of game 2655, the state redealt from the decider's view (Observation::determinize) and then advanced with next stalls on the per-turn decision limit instead of offering the same decision. The earlier delve panic ended this test before seed 2655, so this was hidden, not caused by the fix (the delve change reads only the graveyard, which is public); confirm that first if in doubt by checking the cards of game 2655.

Note: the test's SplitMix64::new(7) rng runs across all seeds, so a repro must play seeds 0..=2655 in order: BERYL_FUZZ_GAMES=2656 CARGO_PROFILE_RELEASE_DEBUG_ASSERTIONS=true CARGO_PROFILE_RELEASE_OVERFLOW_CHECKS=true cargo test --release -p beryl_search --test games -- --include-ignored agents_decide_the_same_on_a_redeterminized_state. Likely a redealt hidden card (library, hand, a face-down or hidden pick) produces a loop of free decisions that the real state doesn't. Fix the engine or the determinizer, add a deterministic test for the case, and a docs/bugs.md entry if it is a rules engine bug.

Derek Thurn2026-11-16

Cause: game 2655 reached its 500th decision of a turn (the fuzz profiles' per-turn budget). next counts each decision it returns; the test redealt the state (copying that count) and asked the copy with next again, counting the decision twice, so the copy stalled. Not an engine bug: search resets the copy's budgets (State::search_limits, mcts::tree::smart) and the expert's payment-plan check falls back when next differs. Fix in tests only: common::redeal gives the redealt copy search's budgets; used by agents_decide_the_same_on_a_redeterminized_state and a_hidden_pick_redealt_shows_and_asks_the_same. Deterministic test: mcts.rs a_state_redealt_at_the_last_budgeted_decision_offers_it_again. No docs/bugs.md entry (test harness, not rules engine). Verification: BERYL_FUZZ_GAMES=10000 release+debug-assertions run now fails only at game 5842 inside the real game's next ('a public card unknown', Gemrazer mutating onto a manifested card), which is by-q44s.55's bug. With 5842 skipped locally (not committed), all 10000 games pass in 80 s. The acceptance's full run therefore also needs by-q44s.55.
