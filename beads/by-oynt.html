For each check, first ask: could a fast, deterministic test (a Rust unit test, a Node test with no browser, a check against a recorded fixture) keep most of what this end-to-end check protects? If so, write that test, then delete the check. If not, delete it when it caught nothing (delete above), or move it to the nightly (a step in nightly.STEPS, tools/src/beryl_tools/nightly.py) when it caught something (move to the nightly above). Either way the check leaves slow CI: when the fast check (by check) runs it too, keep it there and take it out of slow CI alone. Checks listed together failed in the same runs and go together. Make the cuts without asking anyone, and record on this bead what you did with each check and why. The cifix skill (.agents/skills/cifix/SKILL.md) says how to work this bead.
