Close reason

Concede (settings menu, Entry::Concede in replays), loss reason icon+word on the result after the final events play, Back to result after View battlefield, current_game command so a reloaded page resumes (live race fixed), New Game asks first and concedes; already fixed on staging: browser Back led to Return to Game

Description

  • The result: the Victory or Defeat overlay covers the killing blow and doesn't say why the game ended. Let the final events play first. Then give the reason as an icon or one word (life, library, concede, stall), with the detail in the log.
  • After "View battlefield": the only way out is gear → Leave game. Give a way back to the result and to a new game.
  • Concede: there is no concede option. Add it to the settings menu, as Arena does.
  • Reload: reloading mid-game shows "No game in progress" although the engine session is still running. Add a command that returns the current view, through beryl_session → beryl_app → ui/src/ipc.ts and beryl_cli serve. The game screen asks for it on load and resumes.
  • Leaving a game: browser Back and starting a new game abandon the running game silently. Resume it, or ask first.

Files: ui/src/screens/Game.tsx, ui/src/ipc.ts, rust/crates/beryl_session/src/{ipc,sessions}.rs, rust/crates/beryl_app/src/games.rs, rust/crates/beryl_cli/src/serve.rs.

Before changing anything, reproduce each item on current staging. Use just ui-live, as the ui-review skill describes (.agents/ui-review/SKILL.md), or a fixture. The findings come from reviews of the build before the 2026-11-05 UI fixes, so some may already be fixed. Drop those, and list them in the close reason.

Design rules (see the epic): follow the skill's design philosophy, and add no standing words to the table. What a player needs at a glance is shown as icons, badges, numbers, colour or position. Everything else goes behind disclosure: hover, the inspector, a pile's browser, or the game log.

Acceptance criteria

  • Rust tests cover the new command.
  • With just ui-live, reloading mid-game returns to the running game (a check through the driver, or a just ui-test check on the live transport).
  • A fixture shot shows the result with its reason, after the final event.
  • Concede ends the game (a check).
