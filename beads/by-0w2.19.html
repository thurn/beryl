Close reason

Face-down copies are face-up tokens of the synthetic FACE_DOWN_COPY; exemptions and Object::copy_of removed (75ad8e6, f1453db)

Description

Found by the architecture audit of the Arena retarget (by-0w2.14). Rules code cites the CR with yawgatog links (AGENTS.md).

Current design

EffectCtx::copiable_values (effect.rs) returns the original's CardIx and a TokenEntry with the original's face. So Fractured Identity's copy of a face-down permanent is a token holding the original's hidden card with FaceIx::DOWN up, and event::create_tokens then wipes both players' knowledge of it. Because the token's card is a real, hidden card, every face-down rule needs a token exemption:

  • face_down::face_up_cost: a token returns None.
  • zone::move_to_place: a token is not revealed as it leaves (CR 708.9).
  • layers::recompute: a token's controller is not told its card (CR 708.5).
  • invariants: token || in the face-down knowledge check.
  • event::create_tokens: the knowledge wipe.

c1ad83d fixed a missed exemption (the first entry in docs/bugs.md). The design is also wrong under the rules: face up/face down is a status (CR 110.5), and CR 707.2 says status is not copied. The copiable values are the printed ones "as modified ... by its face-down status" (707.2, 708.2). So the copy is a face-up token whose copiable values are the 2/2 with no name, text, subtypes or mana cost.

Proposed design

One synthetic card in beryl_engine, put in every GameTable (or in every table whose decks can turn something face down) at a known index:

pub static FACE_DOWN_COPY: CardDef = CardDef { name: "", faces: &[FACE_DOWN], tokens: &[] };

copiable_values of a face-down object returns that index with FaceIx::FRONT. The copy becomes an ordinary face-up token of a public card. Delete the five exemptions and the knowledge wipe above.

Also delete Object::copy_of. Nothing sets it: zone.rs and observation.rs only clear it, and protocol.rs:799 reads it as copy_of.or(card). Copies are tokens of the copied card.

The protocol and UI show the copy as a nameless 2/2 token, or as they show a face-down permanent today. Either way, nothing looks up art for an empty name. every_face_token_and_emblem_name_is_in_the_card_data exempts the synthetic card.

Must not change

  • No player learns the manifested card through its copy, while the copy is in play or as it leaves.
  • The copy can't be turned face up.
  • The copy is a 2/2 creature with no abilities, no name and mana value 0.
  • Face-down permanents themselves behave as they do now.

Acceptance criteria

  • beryl_cards' a_copy_of_a_face_down_permanent_hides_its_card still passes.
  • A new test (session or scenario): the copy's ObjectView is facing "up" for both viewers, and neither viewer's observation nor the engine's State::card of the copy is the manifested card.
  • grep finds no ObjectFlags::TOKEN test next to a FaceIx::DOWN test in beryl_engine, and no copy_of.
  • just test-rust, just fuzz and just check pass; just ui-shots is clean.

Derek Thurn2026-11-06

Implemented as proposed at 61e3ae3. Notes: (1) FACE_DOWN_COPY is appended last to every GameTable (after tokens) and read via GameTable::face_down_copy(); it lives only in game tables, not CARDS, so every_face_token_and_emblem_name_is_in_the_card_data needed no exemption. (2) a_copy_of_a_face_down_permanent_hides_its_card was adapted to the new design: it now finds the copy as P1's token and asserts it is face up, of FACE_DOWN_COPY, known to both, 2/2, with no TurnFaceUp option (the old face==DOWN / known-to-no-one asserts are the design this bead removes). (3) The protocol names the copy Some("") (face up, token), so the UI draws its unknown-face frame; no art lookup hits (byName has no ""). CLI transcript calls it 'nameless token'. (4) Removing Object::copy_of changes State's Hash input, so the rollout corpus pin moved (re-pinned). (5) Found while doing it: Observation::determinize only redeals deck slots, so the old hidden token copy handed its real card to the searching agent; recorded in docs/bugs.md. (6) Renamed the engine test helper copy_of_the_dead to copy_the_dead so grep finds no copy_of in beryl_engine.
