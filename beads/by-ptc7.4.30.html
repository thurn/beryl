Draw the top card past tokens waiting for cleanup

Description

The kernel draw mutator in rust/crates/beryl_kernel/src/zone.rs takes the last slot in the library and moves it to hand. During one resolution, a token put into a library can still occupy that slot until state-based actions run. CR 111.6 says a token is not a card, CR 111.8 prevents it from changing zones again, and CR 121.1 draws the top card. The top-card query regression in rust/crates/beryl_rules/src/tests/library.rs already constructs the position for the scry fix. Check the analogous spell-copy case under CR 704.5e.

Acceptance criteria

A draw past a token waiting to cease to exist takes the top actual card and leaves the token for the next state-based check. If those objects are the only entries, the draw records an empty library. Add a regression and docs/bugs.md entry and run the count gate.
