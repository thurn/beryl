Added case-insensitive card and token searches and exact deck-import lookup. Debug timing passed at 0.07 ms and 0.27 ms. Fast checks passed and aff53888 is on staging.

Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Cards and decks' (the last list, on search).

In rust/crates/beryl_card_store/src/lib.rs (208 lines; lookup today is Store::card(name) by exact name, a binary search over sorted card:<name> lines):

  • pub fn search(&self, text: &str, limit: usize) -> Vec<Record>: card records whose name contains text, ignoring case; names that start with it first, then the rest, each group in name order. Empty text returns nothing. A prefix search is a binary search; a substring search is one scan of the keys.
  • pub fn search_tokens(&self, text: &str, limit: usize) -> Vec<Record>: the same over token: keys.
  • pub fn card_ignoring_case(&self, name: &str) -> Option<Record>: exact match ignoring case, for deck import. A face name alias (a two-faced card's front face) resolves to its card, as card already does.

Do not load the store into a new structure at start-up unless a measurement says the scan is too slow: measure search("a", 20) and search("zz", 20) in a test and assert each is under 5 ms in a debug build. If it is not, build a lowercase key index once on first use.

Tests go in src/tests.rs. Run just test-rust -p beryl_card_store.

Acceptance criteria

search, search_tokens and card_ignoring_case exist with tests for prefix-first ordering, case, limits and aliases; the timing assertion passes.

Handoff: beryl_card_store now exposes Store::search, Store::search_tokens and Store::card_ignoring_case.
