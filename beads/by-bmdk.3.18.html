Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Turn and phase', and the appendix table 'Phases and turns'.

How interface beads in this milestone fit together: ui/src/table/client.ts (bead "Table screen") is the manual table's pointer client. It owns the selection, sends actions with tableAct from ui/src/ipc.ts, and lets each interaction register handlers from its own file. Put your code in the file this bead names and register it; change client.ts only to add a registration point it lacks. Check your work on a live manual table in a headless browser: ui/scripts/table.mjs (same bead) starts one through the HTTP server and gives a Playwright page. Add one scripted check per behavior to ui/scripts/kept-table-<topic>.mjs and run it with just ui-test <title>.

File: ui/src/table/turn.ts. The step track is StepStops in ui/src/components/Steps.tsx, drawn by ui/src/stage/Chrome.tsx:367; the forward button is TurnButton in ui/src/components/Controls.tsx.

  • The track shows the manual table's phase (TableView.phase, eleven phases). Find how the engine's steps map to the track's icons and show the same icons for the same phases; if the track has a step the manual table lacks (it shows twelve icons), that icon is never current and a click on it sets the nearest manual phase. Say on the bead what you did.
  • Clicking a step sends phase. When the active seat clicks the untap step while it is current, send untap_all for their permanents (the tap action over many objects; build it in the interface from the view, skipping doesnt_untap); clicking the draw step while current sends draw. For the other seat these clicks only set the phase.
  • Space or Tab: next phase. Shift+Tab: next phase and its action (entering untap untaps the active seat's permanents, entering draw draws for them; only if the presser is the active seat). F5 to F10: untap, draw, first main, beginning of combat, second main, end.
  • Cmd+Return sends next_turn.
  • The forward button shows what Space will do: "Next", with the phase it leads to beneath. It must not show an engine label such as "Opponent's Turn".
  • Whose turn it is shows on the life totals as in engine games.
  • In stops mode the track lets a player set stops in engine games; on a manual table a click only sets the phase. Check Steps.tsx and disable the stop toggling here.

Checks (kept-table-turn.mjs): each key; a click on the current untap step untaps; the button's label through a whole turn; Cmd+Return on a solo table keeps the same player.

Acceptance criteria

The step track shows and sets the manual phase; current-step clicks, Space, Tab, Shift+Tab, F5 to F10 and Cmd+Return behave as the doc says; the forward button names the next phase; headless checks cover each.
