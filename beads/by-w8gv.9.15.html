Description

Milestone 5 of Project 50k (plan K5 and K3; epic by-w8gv.9): the rules library and the card port. Line numbers and counts below were read at staging f5034c58; the code as it stands wins over this text, and a deviation is a comment on this bead.

First of three port beads. It takes the cards whose bodies are a few lines over entries that exist or nearly exist, and so sets the pattern for the other two, which depend on it. All paths are under rust/crates/beryl_cards/src.

The cards

  • white/mana_tithe.rs and azorius/no_more_lies.rs: "Counter target spell unless its controller pays {1}" and "... pays {3}. If that spell is countered this way, exile it instead of putting it into its owner's graveyard." One shape, Effect::Unless around a counter, with the player "its controller" (a Players entry read from an object) and, for No More Lies, where a countered spell goes (CR 701.6a). The audit's duplicate: counter-unless-pays.
  • blue/sink_into_stupor.rs: return_to_hand(TARGET). With Jace, the Mind Sculptor's -1, Teferi, Time Raveler's -3 and Reprieve, the audit's duplicate: bounce.
  • colorless/strip_mine.rs: destroy(TARGET), as Damn's first mode. The audit's duplicate: destroy_target.
  • white/aangs_iceberg.rs: exile_until_this_leaves(TARGET), which white/portable_hole.rs already writes (the audit found the two bodies byte-identical), and "Sacrifice this enchantment. If you do, scry 2" (Condition::Did).
  • blue/sphinx_of_false_conclusions.rs: draw then discard (the audit's duplicate: loot, with Currency Converter, Jace, Vryn's Prodigy and Malcolm), and "When this creature dies, if it wasn't a token, create a token that's a copy of it": an intervening "if" on what the object last was (CR 603.4, CR 603.10a) in place of conditions!(not_a_token), and a copy of the card it was (CR 707).
  • white/overlord_of_the_mistmoors.rs: create_tokens(YOU, &INSECT, 2).
  • white/get_lost.rs: destroy the target, then "Its controller creates two Map tokens" (the controller it had, CR 608.2h), and the Map token's "target creature you control explores" (CR 701.44).
  • colorless/mana_crypt.rs: "flip a coin. If you lose the flip, Mana Crypt deals 3 damage to you" (CR 705, CR 120).
  • blue/jace_wielder_of_mysteries.rs: "Draw seven cards. Then if your library has no cards in it, you win the game" (CR 104.2).
  • blue/malcolm_alluring_scoundrel.rs: put a chorus counter, draw, discard, then "if there are four or more chorus counters on Malcolm, you may cast the discarded card without paying its mana cost" (the cast offer of CR 608.2g, of the object the discard acted on).
  • blue/thieving_skydiver.rs: "gain control of target artifact with mana value X or less" (Modification::Control with no end; the kicker's X bounds the target).
  • azorius/teferi_time_raveler.rs: the +1, a rule change for a player until your next turn, with the entry the library lane's last bead made.
  • white/beza_the_bounding_spring.rs: four "if an opponent controls more lands than you" comparisons, each a Condition::Compare of two amounts, the larger read over your opponents.

New entries this bead owns

"Its controller" and "its owner" as players read from an object, as it is or as it last was; where a countered spell goes; explore; a coin flip and its result as a condition; dealing damage; winning the game; offering to cast an object an earlier instruction acted on; a rule change as an effect; an amount that is the most among a set of players. The other port beads use them and add their own.

How a card is ported

  • Start from just card brief <name>: Oracle text, rulings, matching vocabulary entries, the nearest implemented cards, the XMage class.
  • The card file takes the form the vocabulary lane's last bead set (see its handoff in enact brief and the fifteen data-only card files it converted): built with the const builders, every ability's behavior effect data, the definition check beside it, the vocabulary imported from beryl_card. Its Rust bodies, bodies!, conditions!, may_pause, needs and .removal() go, since the data now says them.
  • A new vocabulary entry is designed from its rule, not from the card's sentence: it takes Objects, Players, Amount, Condition or a Filter wherever the rule has a parameter, and it says what the card says (K7: "its controller", "each opponent"). It carries its Comprehensive Rules citation with a quotation, on the entry and on the library function. The interpreter's arm and the library function go where the contract at the top of rust/crates/beryl_rules/src/lib.rs says; Effect::asks, Effect::takes and the definition check are extended; one hand-written, CR-cited scenario for the entry goes where the contract says library scenarios live (K3). The library lane already made the functions general: most entries only name one.
  • A body stays only where the vocabulary cannot say the card and an entry for it would be one card's sentence again. Write it against Game and Resolution as the contract says, and say why in a comment on the body and on this bead. If a second card needs it, it moves into the library (plan, A card file).
  • Two cards that say the same thing use the same entry. Helpers shared by two cards live in the library, never in a card file (AGENTS.md).
  • The card's existing scenarios are the proof of parity: they pass unedited. Do not change a scenario to fit the port. Saves and rollouts replay each decision, so a ported ability asks the same questions in the same order with the same options, makes the same events in the same order and draws the same random numbers.
  • Port what the body does today. Where a body does less than the Oracle text (a clause the engine has no mechanic for), the data does the same and no more (K14: no new mechanic): list each such clause on this bead.
  • Delete each EffectCtx shim method that no body calls any more.
  • just oracle <each card> passes (the fast check runs it for changed card files).

What the reader of this bead should know

  • The WU Control mirror the benchmark plays holds many of these cards: interpreting data where a body ran is on the counted path. just bench-count before and after, and after each group of cards if the count moves.
  • The M2 Mason audit, item 6: beryl_cards/src/tests/effect_data.rs keeps five Rust bodies as a reference for the interpreter. Leave it; the closing bead deletes it.
  • The readings of each card below were taken from its body at staging f5034c58 and are a starting point, not a specification: the Oracle text in the card file's header and the brief decide.

Parity and checks

Parity (plan K11) at the push: just check passes; the frozen save corpus replays (cargo test -p beryl_session --test corpus); rollouts_never_change holds (cargo test -p beryl_bench rollouts_never_change); slow CI's counts lane (just count-gate, bar 389,343,295 instructions, 1% tolerance, rust/crates/beryl_bench/count-gate.toml) passes with no bump to the bar. Run just bench-count before and after and record both on the bead: the benchmark is the WU Control mirror, so what this milestone moves is on the counted path. No behavior changes: no rules fix, no new card, no new mechanic (K14). A rules bug you do find and fix gets a docs/bugs.md entry (AGENTS.md). A save or a rollout replays the decisions a game asked, in order: never change which questions a resolution asks, their order or their options.

Held by checks (AGENTS.md, Code structure): no card name in generic code; no source file over 800 lines (data/file-length-allowlist.json only shrinks, and a new file starts under the limit); rules code and card bodies ask the state for a player's opponents and never name the other of two; they change the state through a mutator, never the board door; a push whose bound is argued takes Queue::push_bounded and any other propagates Full; a count or position that grows with the layout is never narrowed with as. No procedural macro, and a macro_rules! only where a const fn cannot remove the repetition. beryl_card, beryl_kernel and beryl_rules take no runtime dependency. Rules code cites the Comprehensive Rules with a yawgatog link and a quotation; keep the citations of code you move, and check new ones against the pinned release with just citations. Forge is a test oracle only (K16): no entry, name or design comes from its scripts. beryl_search/src/expert and beryl_search/src/frozen are exempt from the project: edit them only where a call stops compiling, giving the answer the old read gave. Other tracks edit nearby files (presentation by-w8gv.21 in beryl_session and ui/, mobile, the AI ladder): enact push rebases and you fix the conflict.

Acceptance criteria

The fourteen card files have no Rust body, no bodies! or conditions! and no declared may_pause, needs or .removal(), or each body that remains is listed on the bead with the reason no general entry serves. Mana Tithe and No More Lies share one shape; Aang's Iceberg and Portable Hole share one entry; the four bounce cards and the four loot cards each say it with the same entries. Every new entry has its Comprehensive Rules citation, takes the vocabulary's expressions for its parameters, is covered by the definition check, and has one hand-written scenario where the contract puts library scenarios. The fourteen cards' existing scenarios pass unedited and just oracle passes for each. EffectCtx has lost every method these bodies were the last to call. just bench-count before and after is on the bead and parity holds with no bump to the count gate.

Decisions and deviations. No Rust body remains in the fourteen files. New entries (beryl_card): Effect::CounterInto{spells,zone} (the check refuses any zone but exile, Malformed::Countered: the one place the engine puts a countered spell instead); Effect::Explore; Effect::FlipCoin with Condition::WonFlip (the flip's outcome 'did' is that the player won it, so WonFlip and Did read one register); Effect::DealDamage{to: Recipients, amount} with Recipients::Players|Permanents (the source is the ability's own); Effect::MayCast{player,card,free} (offers one card as the effect finishes; it does not make Effect::asks true, since the engine asks after the resolution); Effect::ChangeRule{rule,duration} (Ability::effect takes the rule from the data via Effect::starts, so a card names the rule once and .starting stays only for Rust bodies); Condition::Token(Objects) for 'if it isn't a token' (the ability's own source that has left is read from the trigger's last-known information); Amount::Life(Players); Amount::Most(Players,&Amount). Deviations from the bead's text: (1) 'its controller'/'its owner' and winning the game already existed (ControllerOf/OwnerOf, WinGame), so nothing was added for them. (2) Amount::Most reads its amount for each player in the controller's place ('you' is that player) rather than through Players::ThatPlayer, because the kernel's filter reads only You/EachOpponent/EachPlayer in Filter::Whose and the card table refuses the rest; Beza writes the same amount on both sides of each comparison. (3) Amount::Life was needed for Beza's life comparison and is not in the bead's list. (4) Condition::Compare now compares the values as i32 clamped at zero rather than saturated to u8, so a life total over 255 compares exactly as the body did; Comparison::holds takes i32. (5) Effect::Modify with Modification::Control goes through continuous::gain_control for each permanent (summoning sickness and the GainControl event), which is what the Skydiver's body did; no data card used Control before. (6) counter::counter takes the zone the spell is put into instead of a bool. (7) Library scenarios: no tree existed, so this bead made beryl_cards/src/library (mirroring beryl_rules' modules) with library::SCENARIOS (module, card, scenarios); the card crate's scenario and props tests and the oracle dump play them under the card's name. The six effect entries each have one; the expression entries (Token, WonFlip, Life, Most) have none of their own there, being no library function: they are covered by their cards' scenarios and by three new tests in beryl_rules/src/tests/effects.rs (which also cover damage to permanents and control as data). Clauses the data, like the bodies, does less than the Oracle text for (K14): Thieving Skydiver's 'If that artifact is an Equipment, attach it to this creature' (no Equipment in the pool); Malcolm's chorus count once he has left the battlefield (no counters in last-known information, so the cast is not offered). EffectCtx lost explore, scry, sacrifice and win_game, the four methods nothing calls now; every other method these bodies used is still called by another card's body or by beryl_rules' test bodies. Get Lost's file header said {1}{W}{W}; its cost was and is {1}{W}, and the header now says so.
