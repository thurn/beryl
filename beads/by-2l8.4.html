Description

Part of the long-think epic: the last step, after the retuned and frozen expert (by-2l8.1), the MCTS speed-ups (by-2l8.2) and the runner (by-2l8.3) are on staging. Make just longthink with no arguments play the real ladder: expert-frozen as the default opponent, mcts-hidden with the exact stop, auto-pass and subtree reuse on, the rungs and schedule of the epic's D2, D3 and D6. Then it is ready for a human to start at any time.

Do not run the ladder: a smoke run proves it, and the human starts it.

  • Running the recipe again on a fresh cache starts at the first rung; running it on the smoke run's cache resumes there.
