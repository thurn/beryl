Close reason

Two-player lobby, private deck views, match results and gear controls landed on staging at 858c84e8 with fast checks passing.

Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Setup and match flow' (the lobby list and the end-of-game list).

Interface code goes in ui/src/table/, registered with TableClient (ui/src/table/client.ts). Headless checks start a table with ui/scripts/table.mjs and go in ui/scripts/kept-table-<topic>.mjs; run one with just ui-test <title>.

Extend ui/src/screens/Lobby.tsx and ui/src/table/lobby/.

  • The host's lobby shows the invite code with "Copy" beside it and, once the guest connects, their name and the connection: "Direct" or "Relayed", and the round trip time in milliseconds (onTableLink).
  • Each player sees of the other only that a deck is loaded and its counts.
  • The guest has "Ready" (Cmd+Shift+S). The host's "Start" is available when both decks are loaded and the guest is ready. Only the host sees game settings as editable; the guest sees them read-only.
  • The match score is shown and updated. After a game, decks stay loaded with sideboards open for changes, and "who plays first" defaults to "loser of the last game chooses" unless the host changes it. Nothing ends the match: Start is always one click.
  • The gear menu at a table (ui/src/game/Corner.tsx) gains: "Lobby" (opens the lobby panel over the table as game information), "Next game", "Concede" (F2; asks first), "Assists", "Shortcuts", "Leave table". "Next game" opens a choice of result: a win for either player, or no result; both players see the choice in the log.
  • Cmd+Q at a table asks to leave the table before quitting (table-quit-asked).
  • Host a table is Cmd+N on the start screen.

Checks (kept-table-lobby-pair.mjs, with pair()): host shows an invite; guest joins, loads a deck, readies; host starts; both see a table; "Next game" with a win shows 1-0 in both lobbies; the guest's page never contains a card name from the host's deck before the game starts (search the page text and the recorded table-lobby payloads). A fixture or kept moment of the two-player lobby.

Acceptance criteria

Host and guest lobbies show invite, names, connection, counts, ready, start and score; the gear menu has the game-level commands; next game and concede return both players to the lobby with the score; the guest never receives the host's decklist; headless checks pass.
