Close reason

Landed turn upkeep, four state nudges and reversible per-seat assist switches on staging in 79c85fbb. Fast checks passed.

Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Assists' (the shared rules, 'Turn upkeep', 'State nudges').

Create rust/crates/beryl_table/src/assist/mod.rs, upkeep.rs and nudges.rs. An assist is a pure function from a Table (and the card store) to proposals or labels. It changes nothing; its output is ordinary Actions. Nothing here uses the rules engine.

  • mod.rs: enum Assist { Upkeep, Combat, Nudges, LibraryFlows, AbilityMenus }; each Player gains assists: BTreeSet<Assist> (empty by default) and an action set_assist { assist, on } that only its own seat may send (add the variant in action.rs, its permission in permissions.rs, its change in apply/game.rs). pub fn apply_proposal(p: &Proposal) -> Action: a batch of the actions of every line still on.
  • upkeep.rs: pub fn proposal(table, seat) -> Option<Proposal>: offered to the seat whose turn has just begun (phase untap, no action yet this turn) if it has the assist on. Lines: untap their permanents (skipping the flagged), draw a card, move to first main. The draw line is absent on the first turn of the game for the seat that went first.
  • nudges.rs: pub struct Label { on: ObjectOrSeat, text, action: Action, show_to: Vec<Seat> } and pub fn labels(table) -> Vec<Label> for the doc's four conditions: a creature with damage at least its toughness or toughness zero or less; a planeswalker with no loyalty counters; two legendary permanents with the same name under one controller (one label per duplicate, each moving that one to the graveyard); a seat at zero life or less (concede; shown only to that seat). Labels go only to seats with the assist on. Use beryl_card_store::facts.

Tests in tests/assist_upkeep.rs and tests/assist_nudges.rs: each line and condition, the first-turn rule, assists off giving nothing. Run just test-rust -p beryl_table.

Acceptance criteria

set_assist exists and defaults to off for every assist; the upkeep proposal and the four nudge labels are produced only for seats with the assist on, with tests for each rule.

Handoff: beryl_table::assist exports the existing Assist/Proposal/Line types, enabled(table, seat, assist), apply_proposal, upkeep::proposal and nudges::labels. The table already stored per-seat assist vectors and the action's actor identifies its seat, so the implementation kept those types and wire names. Upkeep emits one selectable line per tapped, unflagged permanent and uses reversible turn-play counts to withdraw after manual play without blocking undo of unrelated actions. First-turn mulligans and bottoming opening-hand cards leave it available. When wiring the host view, suppress the first upkeep offer while the guided opening prompts are pending, and filter labels by show_to. Nudge card labels use the visible face and ignore face-down cards, and concession is limited to the affected enabled seat. Core tests and Clippy passed.
