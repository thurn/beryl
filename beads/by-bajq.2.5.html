Description

Why

A replacement effect that changes how a permanent enters is found by looking at the permanent "as it would exist on the battlefield", with the continuous effects that would apply to it (CR 614.12). Under Blood Moon, a nonbasic land whose text says it enters tapped unless its controller pays life would be a Mountain with no such text, so it enters untapped. Under Opalescence, an enchantment put onto the battlefield is a creature for an effect that asks about creatures entering. Today event::enter_replacements reads the printed face.

What to build

Plan: Designs 2, "As it would exist".

  • layers::as_it_would_exist(state, table, slot, entry) -> Derived: the recompute run with one more row for the entering object, in scratch memory, never in State. It applies the object's own static abilities and every effect already in force that would apply to it.
  • It is called only for an object whose face has a replacement of its own entering, or when a replacement of entering is live (group 3 wires the second). A permanent entering in any other game costs one test.
  • event::enter_replacements and event::life_to_enter use it: an entering replacement the object would have lost does not apply.

Tests

The scenario by-bajq.2.3 left: Soporific Springs or Seachrome Coast (both implemented) entering under Blood Moon. A unit test for an object that would be a creature only because of an effect.
