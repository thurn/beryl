Description

Part of Milestone 1 (epic by-b0q): a rules-exact engine, game UI and AI opponents for a mirror match of the 40-card WU Control main deck in docs/sample-decks/2026-10-17-PrinceJools-wu-control.txt (29 distinct cards). Read the epic's description (plan, card table) and design field (decisions) first; docs/engine-architecture.md is the design. Rules code cites the Comprehensive Rules with yawgatog links and quotations (AGENTS.md).

Design decisions 2 and 3: custom frames need Scryfall art crops and card text; inspect shows the full scan.

  • by cards (Python, standard library, in tools/): looks up a card list on Scryfall's /cards/collection (batches of 75, at least 100 ms between requests, User-Agent ProjectBeryl/<version> and an Accept header, per Scryfall's API guidelines). Default list: the M1 decklist plus its tokens (Map, 2/1 flying Insect, 1/1 Human, 2/2 vigilance Samurai, 1/1 flying Spirit; find the printings through each card's all_parts); a flag takes the whole cube CSV. It writes a committed data file in data/: per card the Scryfall id, set, collector number, layout, artist, and per face the name, mana cost, type line, Oracle text, power, toughness, loyalty, colors and the art_crop, normal and large image URLs. The default printing is Scryfall's; a small committed overrides file pins another. Tests run on recorded responses, never the network.
  • beryl_app: an asynchronous custom URI scheme (for example beryl-art://<scryfall-id>/<face>/<version>) serving images from the app's cache directory. On a miss it downloads from cards.scryfall.io through a single queue (one request at a time, at least 100 ms apart, the same User-Agent), writes atomically, and answers a failure with a status the UI turns into a placeholder. The CSP allows that scheme for images. Unit tests use a local stub server.
  • ui/: a small hook that maps a card name and face to its art URL and display text from the data file, with a placeholder until the image loads.
  • Update AGENTS.md's data/ line.

Acceptance criteria

  • by cards regenerates the data file byte for byte from recorded responses (test); it covers all 29 cards and the five tokens.
  • Rust tests cover a hit, a miss with a download, and a failed download, with no external network.
  • No image files are committed; just smoke and just ci pass with the network unavailable.

Delivered (staging 4fe6882). Decisions and deviations:

  • URI scheme: beryl-art://localhost/<version>/<side>/<x>/<y>/<id>.jpg mirrors Scryfall's image path (cards.scryfall.io/art_crop/front/a/b/<id>.jpg) instead of <id>/<face>/<version>. Face index -> front/back is ambiguous for split/adventure cards (one image), so the data file's per-face URLs decide; ui/src/ipc.ts cardImageUrl() swaps the origin and drops the ?timestamp. art.rs accepts only that exact shape (version in art_crop/normal/large, side front/back, lowercase uuid, shards matching the id), so no other host path and no traversal. Verified: every image URL of all 540 cube cards matches that shape.
  • HTTP: ureq 3 with native-tls (macOS Security framework), no rustls/ring build. One downloader thread; hits are read without queueing; misses re-check the disk before downloading; writes go to <file>.<pid>.part and rename. Bad path -> 404, failed download -> 502, cache not yet managed -> 503. Nothing is cached on failure; the next request retries.
  • CSP (bundled builds only; Tauri does not apply it to devUrl pages on desktop): default-src 'self'; connect-src ipc: http://ipc.localhost; img-src 'self' data: beryl-art:; style-src 'self' 'unsafe-inline' with dangerousDisableAssetCspModification [style-src] so nonces don't cancel unsafe-inline for React/Motion style attributes. Later beads adding fonts or other origins must extend it.
  • by cards: collection lookups by name use a split card's first half (Scryfall's collection endpoint misses 'Life // Death'). Tokens: every all_parts token component, so the data has 7: the five plus 'Copy' (Sphinx) and the Thundertrap Trainer offspring token. Scryfall lists no emblem for ORI Jace. The UI hook prefers cards over tokens of the same name.
  • Recording tools/tests/fixtures/scryfall-m1.json (90 KB) keeps only the fields the tool reads; the test regenerates data/cards.json byte for byte from it. --cube was run live once: all 540 cards resolve (75 tokens); its output is not committed.
  • data/card-printings.csv is header-only: no pins needed yet.
  • useCardArt (ui/src/cards.ts) is not used by App yet; the design-system bead consumes it. Vite dev server needs server.fs.allow ['..'] to serve data/cards.json (verified with a dev server + curl, no window).
  • End-to-end check: a temporary App rendering useCardArt('Soporific Springs') that only reported ui_ready once the image loaded passed just smoke: the MDFC back-face art came through beryl-art under the new CSP into ~/Library/Caches/ca.thurn.beryl/art. Reverted before commit; the committed smoke touches no network.
