Close reason

XMage oracle folds accents; Dandân's 3 non-Mind-Bend scenarios pass in XMage

Description

Symptom

just card check "Dandân" reports every Dandân scenario as unsupported: XMage lacks Dandân, though XMage implements the card (Mage.Sets/src/mage/cards/d/Dandan.java). So no scenario of Dandân is checked against XMage, including ones that need no other card ("Dandân attacks a player who controls an Island", "Dandân is sacrificed when its controller controls no Island"). Any other card whose name has an accent or another non-ASCII letter (Æ, â, û, é) is skipped in the same way.

Why

tools/src/beryl_tools/xmage_java.py xmage_cards() collects the names XMage's set files list (new SetCardInfo("Dandan", ...), which are ASCII. xmage.py export_one() checks a scenario's setup cards (setup_cards) against that set by exact Beryl name (Dandân), so the card counts as missing. Even with that check fixed, the exporter writes Beryl's spelling into the Java test (addCard(..., "Dandân") in Exporter in xmage.py, plus casts, attacks, targets and assertions), which XMage would not find.

What to do

  • Map each Beryl card name to XMage's spelling once, folding accents the way xmage_classes.card_class already does (unicodedata.normalize("NFKD"), Æ to Ae), and matching against the names xmage_cards() returns.
  • Use the mapping in the availability check in export_one and everywhere the exporter writes a card name into Java (every java_string(name) of a card name in xmage.py and xmage_java.py).
  • Add a test in tools/tests/test_xmage.py that a scenario naming Dandân exports with Dandan in the Java and is not unsupported.
  • Run just card check "Dandân" and record the result: the three scenarios without Mind Bend should play in XMage (XMage has no Mind Bend or Crystal Spray, so those stay unsupported).

Acceptance criteria

just card check "Dandân" plays Dandân's scenarios that use no Mind Bend in XMage, and they pass. A unit test in tools/tests/test_xmage.py covers an accented card name. No scenario that passed in XMage before stops passing.
