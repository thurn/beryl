Derek Thurn2026-11-16

Cause: beryl3d --fixture verbs-zones reads its recording from the recordings pack for the present sources ($BERYL_CACHE/b3d/recordings-<hash>.bin). When no command had built that pack yet for the commit under test, the app printed 'the recordings pack for the present sources is missing' and exited 1, so just b3d smoke reported 'the app showed no frame'. Reproduced by running the bisect worktree's binary at 527f7b266 directly. b3d commands avoid this by exiting 3 (recordings::MISSING_STATUS) and having cli.run_program build the pack and retry. Fix (ce5d182f2): beryl3d's main exits with the same status, and just b3d smoke / just b3d app call cli.record() and start the app again on it. Verified with BERYL_CACHE pointed at an empty folder: smoke built the pack (12 s) and passed. Note: the bead's output tail is the joined output of all failed steps, so it showed only timeline-parity's lines (by-q44s.33).
