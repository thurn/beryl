Close reason

export/import between hosts, per-host newest date in coverage, separator-free paths; pushed f13744bba

Description

Let the main Mac's dashboard include work done on the second Mac and on the Windows PC.

Design section: "Other machines".

What to build

  • just efficiency export --since <date> [--out FILE]: this host's rows from every table that carries a host, as one gzip-compressed JSON-lines file.
  • just efficiency import <file>: adds the rows. Rows are keyed by host and source, so importing the same file twice, or two overlapping exports, changes nothing after the first.
  • Ingest on Windows: find the providers' directories from the user's home directory (%USERPROFILE%\.claude\projects, %USERPROFILE%\.codex\sessions), build the project directory name from the checkout path as each provider does on Windows, and never assume a path separator. The CPU sampler and the lease log do not exist there: their tables stay empty and coverage says so.
  • coverage lists, per host, the newest row's date, so a stale import is visible.
  • A paragraph in efficiency/AGENTS.md on moving an export between machines. An export holds command lines and paths: it is copied between the user's own machines and never committed or published.

Shared context

  • The design is docs/efficiency-dashboard.md. Read the sections named above before anything else; the rest can wait. The decisions taken with the user are in the epic, bd show by-ig5e.
  • The dashboard's code is the separate Python project in efficiency/ (package beryl_efficiency, standard library only, pyre strict, black). It imports nothing from tools/ and nothing imports it. Read efficiency/AGENTS.md first once it exists.
  • Tests use small synthetic sources built in the test itself or kept under efficiency/tests/. The repository is public: never commit a real transcript, session record or command line from this machine.
  • Real data exists only on the main Mac (host jarvis). Where the acceptance criteria name a check against real data, run it there; if this session is on another machine, record that the check was not run in a comment on this bead and close on the tests.
  • Collection must stay free for agents: no hook, wrapper or prompt text may be added to any session, and ingest must never run inside another command.

Acceptance criteria

Tests: export then import into an empty store reproduces the exported host's rows; importing twice changes nothing; path handling tests pass with Windows-style and POSIX-style paths. On the main Mac, after importing an export made on another host, coverage no longer reports that host's beads as having no data.
