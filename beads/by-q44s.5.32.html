Attach (card.attach) uses the same pick with the host as {id, in}. (2) Selection marks are Mark::Selected spans the client keeps in Lit (selection::mark each frame on the table), the same outline the web's .stage-mark-selected draws. Only the area under the pointer is outlined, as the web's DropTargets draws one .table-drop-target. Drop actions port dropActions.ts except attaching an auto-attach card to the permanent it was dropped on and face-down (hidden) drops. (4) Viewers: graveyard/exile view commands and a press on those piles open inspect::viewer on the table; a right click on a viewer card opens that card's menu with the pile-card commands. Library looking and the viewer's own commands (search, sort, close and shuffle) are not built. (5) Escape on the table is taken before the table's shortcuts (the table binds Escape to viewer.close) when no menu, overlay or viewer is open.
