Close reason

longthink command, runner and tests deleted; ladder's shared core kept as match_log (bbd3e2e4)

Description

Found by the M5 Mason audit (by-w8gv.10.1), CI budget.

Measured from the run log (just ci-report; ~/Library/Caches/beryl/ci/runs.jsonl): the tests of the retired long-think arena are the largest single cost in the slow check's rust lane. At staging a65a9389 they summed 278 of the lane's 855 test-seconds, at f553102d 361 of 1,085; over 30 days rust:beryl_cli::longthink::full_power_plays_the_same_games alone is the most expensive check in the log (22,110 s over 296 runs), with longthink_tty::two_ctrl_cs_stop_at_once and longthink::stops_cost_nothing_but_time third and fourth among Rust tests. Slow CI took 480 to 615 wall seconds on the Mac on 2026-11-12 against a 300 s load-adjusted budget.

The arena is retired (AGENTS.md, Tournaments; docs/ai-strategy.md section 8: it holds the machine for days and the ladder replaced it). Its tests guard a command nobody may run, and several are load-sensitive by construction (they spawn the binary, play games at full power and time Ctrl-C handling through a pty).

Proposed: delete rust/crates/beryl_cli/tests/longthink.rs and longthink_tty.rs with the helpers only they use (tests/pty.py, tests/ansi, tests/exe if nothing else reads them), and the just longthink recipe with the beryl_cli longthink subcommand and rust/crates/beryl_cli/src/longthink/ (5,045 lines) if nothing else in the workspace calls into it; keep docs/longthink-run-003.md, the record of its last run. If another command still shares code with it (check beryl_search/src/long.rs's callers: the ladder may), keep that code and delete only the arena's command and tests. Update AGENTS.md's and docs/ai-strategy.md's mentions, the file-length exemption for the retired code in tools/src/beryl_tools/checks.py and docs/project-50k.md K17 if the code goes. Default taken under K31: retired code that costs a third of a lane is deleted, not kept opt-in; git history keeps it.

Must not change: the ladder (just ladder and its tests), every other beryl_cli command, card implementations (none is touched).

Acceptance criteria

cargo test -p beryl_cli runs no test named longthink; just ci passes; the rust lane's summed test seconds in the run log for the landing commit are at least 200 s lower than at a65a9389 on the same machine; just --list shows no longthink recipe, or the bead records why the command had to stay.
