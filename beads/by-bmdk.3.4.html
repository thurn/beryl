Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Views and animation' (the last rows of the verb table).

Finish rust/crates/beryl_table_session/src/script/:

  • undo: the verbs of the changes that reverse the undone entry (an undone draw flies the card back to the library).
  • batch: the verbs of its members, in one script, in order.
  • rewind, start, next_game: no motion. The script has reset set and one announce banner ("Rewound to 41", "Game 2").
  • load_deck, sideboard, ready, concede, set_assist: no script (they change the lobby or a setting).
  • A pending proposal: mark on each card a line would change, begun when the proposal appears and ended when it is applied or withdrawn. Use the existing mark suggested (data/ui-conventions.json, "marks"); do not add a mark.

Then run the random test over every action kind, with undos and rewinds mixed in, for both seats: every script replays, and nothing sent names a hidden card. This is the whole-run acceptance check for scripts; name it every_script_replays_and_names_nothing_hidden. It must finish in under 5 s.

Run just test-rust -p beryl_table_session.
