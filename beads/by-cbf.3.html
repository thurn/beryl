Player games lift decision/turn budgets; search resets to defaults (a0c2493)

Description

Part of the epic, independent of the layout work.

Player games keep Limits::DEFAULT (500 decisions per turn, 200 turns; profile.rs), set through with_stops in beryl_session/src/game.rs. A human manually repeating an Underworld Breach loop can reach 500 decisions in one turn and the game ends "Stalled". The budgets exist to stop runaway rollouts; a human can always concede.

Raise decisions_per_turn and turns to their type's maximum for player games only. Search and rollouts keep the defaults. Leave state_based_iterations alone: an endless mandatory loop is a rules draw (CR 104.4b), which needs a real loop check, not a bigger budget.

Done in a0c2493. with_stops sets Limits::PLAYER (u16::MAX decisions and turns, state_based_iterations at default). Deviation worth noting: mcts::smart spread ..s.profile(), so search below a player game would have inherited the lifted budgets; smart now sets State::search_limits(), which is Limits::DEFAULT unless the game has already gone past a default (turn >= 200 or >= 500 decisions this turn), in which case search gets the default's room again from where the game stands, so trees in a long player game aren't stalled before they play. Normal games' search is unchanged. Note: just check's rust tests lane ran 57 s of the 60 s budget.
