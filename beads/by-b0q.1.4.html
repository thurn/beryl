Description

Part of Milestone 1 (epic by-b0q): a rules-exact engine, game UI and AI opponents for a mirror match of the 40-card WU Control main deck in docs/sample-decks/2026-10-17-PrinceJools-wu-control.txt (29 distinct cards). Read the epic's description (plan, card table) and design field (decisions) first; docs/engine-architecture.md is the design. Rules code cites the Comprehensive Rules with yawgatog links and quotations (AGENTS.md).

Design decision 8 and architecture section 17.2: provision both oracles so agents can run them unattended.

  • just oracle-setup (in by): installs Maven and openjdk@21 with Homebrew when missing; shallow-clones magefree/mage and Card-Forge/forge at commits pinned in tools/ into ~/Library/Caches/beryl/oracles/; builds only the modules the harnesses need (XMage's Mage.Tests and its dependencies, Forge's desktop module for sim and its test harness) with JAVA_HOME on JDK 21. Idempotent; logs to the cache; prints a JSON summary.
  • A smoke for each: run one existing XMage test class and one Forge sim game.
  • Find which of the 29 cards and five tokens each oracle implements (their card sources) and post the list as a comment on the epic, so the exporters know what is exportable.
  • README's setup table notes that just oracle-setup provides Maven and JDK 21.

Acceptance criteria

  • just oracle-setup succeeds from scratch and is a quick no-op the second time.
  • Both smokes pass.
  • The coverage list is a comment on the epic.
