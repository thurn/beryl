Close reason

Spell copies that exile themselves stay in exile in scripts until a view drops them; Fork-on-Time-Spiral scenario added; unrelated fuzz panic filed as by-bajq.13

Description

Symptom

just fuzz 1000's session fuzz (beryl_session fuzz::session_games_keep_the_script_checks) panics in game seed 1059972789 (human P1, smart stops) after 212 choices:

a script breaks a rule: fly #36 graveyard>library top effect <- #513: its cause #513 is not on the table as it runs, and did not leave it in this beat

Fork (#26) copies Time Spiral (#295). The copy (#513) resolves: "Exile Time Spiral" moves the copy off the stack, and the script shows vanish #513 stack>gone exile. The rest of Time Spiral's effect (each player shuffles hand and graveyard into library, draws seven) is then scripted with <- #513 as its cause, which the script builder (script/build.rs, the rule at line ~176) refuses because #513 already left the table in an earlier beat. At the end of the same script, appear #513 (Time Spiral) nowhere>exile created puts the copy back in exile, so the engine and the script disagree about where the copy is: CR 707.10a says a copy of a spell in a zone other than the stack ceases to exist as a state-based action (CR 704.5e), so the copy is briefly in exile.

What to do

Decide from the rules where the copy is between its exile instruction and the next state-based action check, make the session's events say the same thing in order (either the copy moves stack>exile and later vanishes, or it vanishes at once and later effects name another cause), and add the case as a spec moment or fixture (Fork on Time Spiral, or any copy of a spell whose effect exiles itself) so the script checks cover it.

Files: rust/crates/beryl_session/src/script/build.rs, the session's event-to-script translation, rust/cards/cards_1994/*/fork.rs scenarios (just card path Fork), Time Spiral's card file.

Found by by-bajq.9.4 (every agent plays every keystone).

Acceptance criteria

The seed above no longer panics: BERYL_FUZZ_GAMES=1000 just fuzz 1000 passes its session fuzz. A spec moment or UI fixture with a copied self-exiling spell passes beryl_cli script-check.
