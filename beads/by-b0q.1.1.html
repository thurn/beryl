Description

Part of Milestone 1 (epic by-b0q): a rules-exact engine, game UI and AI opponents for a mirror match of the 40-card WU Control main deck in docs/sample-decks/2026-10-17-PrinceJools-wu-control.txt (29 distinct cards). Read the epic's description (plan, card table) and design field (decisions) first; docs/engine-architecture.md is the design. Rules code cites the Comprehensive Rules with yawgatog links and quotations (AGENTS.md).

Create beryl_engine and beryl_cards (architecture sections 2 to 7.2, 12 to 16). Nothing casts yet: the mana solver, casting and the stack are the next wave's.

beryl_engine:

  • Fixed<T, N>, Bitboard, and State laid out per section 4: objects and slots, battlefield, derived (filled by the layers bead), zones with ordered library and graveyard, players, turn, the stack, trigger, delayed-trigger and effect queues as typed Fixeds, pending, knowledge, rng, budgets, flags. A const assertion keeps size_of::<State>() at 20 KiB or less.
  • ObjectRef with incarnations (section 5); deck cards in slots permuted by the hidden RNG (4.2); two SplitMix64 streams (14).
  • The CardDef, Face, Ability and Filter types (6.2); CardTable and GameTable built from two decklists (6.4).
  • next, apply, Step, Decision, DecisionKind, Candidates, Choice, Answers, Scratch (sections 3, 7.1).
  • Turn structure and priority (12.1, CR 500 to 514, 117): steps, passes advancing a step on an empty stack. Playing lands (CR 305), one per turn. Drawing (CR 121), including from an empty library. London mulligan (CR 103.5) with bottom picks; play or draw by seeded coin flip.
  • State-based actions for life, drawing from an empty library and the legend rule (CR 704.5a, b, j).
  • Outcome with Stalled(reason), budgets (12.2, 12.3).
  • Profiles (15): exact and smart stops; silent passes and single-candidate auto-apply (7.2).
  • Observation: a borrowed view that masks unknown slots; knowledge bits set at chokepoints; shuffles rebind identities (section 13).
  • Hash for State; a test that greps the engine crates for banned types (HashMap/RandomState, Instant/SystemTime, thread_local!, static mut).

beryl_cards:

  • A names module generated from data/vintage-cube-2026-10-07.csv plus the basic lands, with a test that fails when it is stale.
  • The static CardTable; one file per card under color directories. CardDefs for Plains, Island and Tundra (CR 305.6, 605).
  • The WU Control main deck (40 cards) as a constant.

Test engine machinery with test-only CardDefs inside the engine crate.

Acceptance criteria

  • just test-rust passes; clippy pedantic clean; the size assertion compiles.
  • A land-and-pass game runs to decking under both the exact and smart-stop profiles, the right player wins, and the state hash is identical at every decision across two runs with one seed.
  • Mulligan test with bottom picks; an Observation test shows the opponent's hand never reveals identities.
  • Shuffle test: knowledge bits cleared, identities rebound.
  • The banned-types test is in place; every rules function cites the CR.

Executor notes (b0a802e):

  • State is 13.5 KiB (assert at 20 KiB). Queue entry types (StackEntry, PendingTrigger, DelayedTrigger, FloatingEffect) hold only source/controller/ability; casting, triggers and layers extend them. Derived is defined but unfilled; derived_dirty is set at the zone-move chokepoint.
  • Ability omits listens/matches/layer/modes from §6.2: the triggers, layers and card beads add them with real types instead of placeholders. Ability has may_pause.
  • Flow is Result<(), Pause> (a 1-byte marker), not Result<(), Pending>: clippy::result_large_err rejects a Decision-sized Err on every body. The question goes with the choice record when transactional replay lands.
  • Mana abilities: Ability::tap_for_mana(ManaSet); body add_produced_mana adds the ability's mana of the color its activator chose (EffectCtx.mana), so the solver passes the color in. Tundra has two intrinsic abilities (CR 305.6), not one with a choice.
  • apply recomputes the decision from the state (decision() is pure) instead of caching it in Scratch, so copying a state between next and apply is safe. Scratch is an empty struct for now.
  • CR 103.1: the seeded coin flip picks who chooses; the winner gets a PlayOrDraw decision (exact rules). CR 103.5 (current text): bottom picks happen as part of taking each mulligan, before the next round of declarations.
  • Legend rule is a decision (DecisionKind::LegendRule) via Pending::LegendRule{kept}; interchangeable legends collapse and resolve silently. SBA iteration budget counts consecutive performing checks (Budgets.state_based_iterations).
  • Smart stops: DeclareAttackers/DeclareBlockers are stops only when a creature is attacking.
  • Cleanup 514.3a via Turn.cleanup_check, consulted where every priority SBA check runs.
  • names.rs is generated by the names_are_current test (BERYL_UPDATE_NAMES=1 regenerates); card dirs follow the CSV color groups (white/plains, blue/island, azorius/tundra).
  • Workspace lint: allowed clippy::many_single_char_names, since the architecture's API is next(s, t, x, a).
