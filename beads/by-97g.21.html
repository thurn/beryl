Description

Part of the ladder epic by-97g. Read docs/ai-strategy.md first: §4.7 and §5.

The plan's measure is suite entries opened per human game, and nothing durable counts human games: the journal rotates at 16 MB.

Where

  • rust/crates/beryl_session/src/journal.rs: the journal (Level::Info records "a game began or ended"), for where a game's end is known.
  • rust/crates/beryl_app/src/lib.rs: where the app opens its journal, for the app's data directory.
  • rust/crates/beryl_session/src/bugs.rs: BugReport, what a report carries.
  • tools: by bugs (just bugs).

Build

  1. When a game against an agent ends (win, loss, concession), the app appends one JSON line to games.jsonl in its data directory, never rotated: the date, the build's commit, the agent's name, the result, and the turn count.
  2. A bug report carries two numbers read from that file: games finished against this agent name, and games finished since the last report.
  3. just bugs prints the file's total a day for the last 14 days.

Tests

A session test: a finished game appends one line; a conceded game too; a report made after three games carries 3.

Done

Pushed with enact push. Not in lane:ladder: it is the app's code and runs anywhere.
