Mason audit of by-2l8 (staging ebb0eec). Ranked:

Filed (children of by-2l8):

  1. by-2l8.15 Typed decision indices and entrants: two index spaces (game usize, agent u32) both named "decision", mixed in upgrade.rs and in decisions.jsonl (the D7 training data); u32::MAX "from the log" sentinel; Entrant {name, Option<Budget>} with string dispatch and a runtime error branch; game::Choose duplicating Agent with Option<(Option<&Search>, u32)>.
  2. by-2l8.16 One standings model: three per-matchup tallies (run::tally/schedule::Tally, summary::Row, panel's Tally) with three Verdict-to-points mappings, three matchup namers, and two different statistics both called "Elo per tripling" (summary: adjacent-rung differences; panel: WLS slope). by-2l8.13 (Archivist) now waits on it.

Sound, no change proposed:

  • mcts.rs: exact stop is per-tree slicing of an unchanged iteration sequence, so moves equal the full budget; the stop rule has an exhaustive test; reuse gate (incarnation/knowledge per slot plus shows_the_same on each tree) is narrow and documented; resume_point/resumed make a rebuilt agent deterministic.
  • Runner durability: append-only JSONL with torn-line repair, commit-last ordering, recover() trimming uncommitted lines, lock, supervisor. Kill-at-random test verdict is timing-independent (results compared to an uninterrupted run).
  • expert-frozen as a code copy pinned by a move hash (tests/frozen.rs): the right trade for a reference opponent.
  • panel.rs is a pure frame function; term.rs draws it. Sizes (776/614 with tests) are fine.

CI: slow CI 67-92 s of 300 s across the epic's pushes; no Steward bead in this epic; no wall-clock gates added (pty.py's 600 s deadline only prevents a hang).

Not filed (lower value):

  • CRATES (code.json) omits beryl_cli, whose longthink/game.rs and tournament::game_seed also decide play; only the advisory "code differs" message is affected, since --upgrade verifies by replay.
  • mod.rs mixes arg parsing, run dirs, code identity (code_ids/changed/adopt_binary) and the supervisor; code identity could live with upgrade.rs.
  • seat: u8 in GameRecord/Line/Spec rather than Seat (engine has no serde); Against::Below at rung 0 is representable (schedule never produces it; rung - 1 would underflow).
  • GameRecord.iterations is derivable from config + rung.
  • stops_cost_nothing_but_time asserts kills > 0, which a machine fast enough to finish a 2-game tiny run between 1 ms polls would fail; not seen in practice.
