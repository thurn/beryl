Description

Read the epic's contract first; this bead builds against it. Doc: docs/beryl-3d.md, 'Migration and compatibility' and 'The agent interface'.

Beryl 3D needs shadows, gradients, drop shadows, filters and masks that look like WebKit's. Tuning them on game screens mixes shader errors with layout errors, and every iteration replays a recording.

Change: add just b3d match samples [name-prefix].

  • data/beryl3d/match/samples.json lists samples. Each is one element with a CSS style, a size and a background. Cover what the web uses: box shadows (outer, inset, spread, several layers, on radii 0, 8 and 24), linear gradients (2 and 3 stops, angles), radial gradients, drop-shadow on a text run and on an icon, brightness, grayscale, blur, gradient masks, opacity over a gradient, borders with radius, and plain color panels as a baseline. Read ui/src/stage/*.css and ui/src/components/ for the actual shapes, and write the actual values the web uses where you can.
  • Web side. Generate one HTML page per sample and shoot it in WebKit at scale 2 (tools/src/beryl_tools/shots.py).
  • Beryl 3D side. Draw each sample through the real renderer. Add a b3d-render sample entry (beryl_pictures) that builds a one-element flat-layer screen from the sample's style. A property Style can't express yet makes that sample report unsupported, not fail.
  • Scoring. Print each sample's maximum and mean per-channel error, and write a picture with web, b3d and an amplified difference side by side. The tolerance is a maximum error of 4 levels on 99.5% of pixels, with text glyph pixels masked (decision M2). Results go under samples in data/beryl3d/web-match.json, with the ratchet rule. Unsupported samples are recorded as unsupported.

Files: tools/src/beryl_tools/beryl3d/match/, tools/src/beryl_tools/shots.py, rust/beryl3d/crates/beryl_pictures/src/main.rs, beryl_host/src/headless.rs, beryl_scene/src/element/style.rs, beryl_render/src/shader.wgsl.

Acceptance criteria

match samples runs every sample in a few seconds after the first build, plain panels and borders pass, the rest are recorded as unsupported or with their error, and web-match.json holds the results.
