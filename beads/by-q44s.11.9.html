Description

Read first: the epic by-q44s ('Rules for every bead'); rust/beryl3d/AGENTS.md; docs/beryl-3d.md 'Choosing a tier' (the setting) and 'The flat layer'.

Show the graphics setting on the settings sheet. The tier choice bead added Graphics { Automatic, Baseline, Enhanced }, Settings::graphics and Setting::Graphics (beryl_scene src/settings.rs) and the app's handling of a change; the settings screen bead built the sheet in beryl_scene src/screens/settings.rs from widgets. The web interface has no such setting and Arena's is not recorded, so it is built from the sheet's existing widgets. Rule 17 keeps this bead out of data/ui-conventions.json: instead, add a comment on the epic by-q44s naming the row as not seen in Arena, for the parity list and the epic's closing note.

Build, in src/screens/settings.rs: a row named graphics with the label Graphics and a three-way choice of Automatic, Baseline and Enhanced, built from the widget the sheet already uses for a choice (a menu or a row of toggles from src/widgets; use what the sheet uses), sending Press::Setting(Setting::Graphics(..)). Place it after the sound controls and before full control.

Tests, in beryl_scene/tests/screens.rs beside the settings screen's: the row shows the saved value; choosing Baseline sends Request::SaveSettings with graphics: Baseline; the row is reachable and its text fits in the desktop window matrix (just b3d test b3d:screen/settings).

Run: just b3d cargo-test -p beryl_scene; just b3d test b3d:screen/settings; just b3d lane.

Beads named above: the contract bead (the tier input and the check) is by-q44s.11.2; the renderer skeleton bead is by-q44s.11.3; the shadow map bead by-q44s.11.4; the lighting bead by-q44s.11.5; bloom by-q44s.11.6; particles by-q44s.11.7; the tier choice bead by-q44s.11.8; the settings row by-q44s.11.9; the limits bead by-q44s.11.10; the settings screen bead by-q44s.5.27. Every bead of this milestone depends on by-q44s.4, the review gate before it.
