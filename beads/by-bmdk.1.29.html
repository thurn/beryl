Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Keyboard shortcuts'.

Create ui/src/table/shortcuts.ts (pure logic) and ui/src/table/bindings.ts (storage).

  • A binding is written "Cmd+Shift+W". Match a KeyboardEvent by physical position: use event.code (KeyW, Digit1, Minus, Equal, Comma, Period, Slash, BracketLeft, F5), never event.key, because Option with a letter types an accented character on macOS. Cmd is metaKey on macOS and ctrlKey elsewhere; Option is altKey. Take the platform from AppInfo.platform.
  • resolve(event, scope, bindings) -> commandId | undefined. Scopes are table and lobby; a key bound in both resolves by the scope given. Outside both, nothing resolves.
  • bindings.ts: defaults come from data/table-commands.json; a player's changes are stored through the profile-aware storage helper (ui/src/profile.ts if bead "App profiles" has landed, else localStorage with a TODO-free plain key) as a map of command id to key or to null (unbound). bind(id, key) unbinds any other command in the same scope holding that key and returns which. reset().
  • describe(binding, platform) -> string for showing a key in a menu ("⌘W", "Ctrl+W").
  • Do not attach any listener to the window here: the table screen does that later.

Tests (npm test): matching by code with a simulated Option+U event whose key is "¨"; Cmd versus Ctrl by platform; scope separation for Cmd+N, Cmd+Shift+N and Cmd+Option+U (bound twice in the appendix); rebinding steals and reports; unbound commands; describe. Run cd ui && npm run typecheck && npm test.

Acceptance criteria

Keys resolve by physical position and scope on both platforms; bindings persist, steal conflicts and reset; no global listener is added; tests cover the cases listed.

Bindings.bind(id, keyOrNull) returns the id displaced in that scope. A custom key replaces the command’s default keys, including aliases. Stealing any alias unbinds its owner, since the profile stores one key or null per command. On macOS Delete maps to the physical Backspace key. There are no listeners.
