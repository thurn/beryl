Close reason

Mockup pixel harness, replica mode and replica hooks removed; docs updated (331632b)

Description

The docs/ui_mockups images are generated references, not a pixel spec: they are not consistent with one another, and pixel-matching each region of each mockup fitted the game UI to every image separately (see the sibling beads: by-e24, by-jgv, by-skm, by-dlw, by-kq9, by-dcj). As long as a per-region pixel verdict is the bar, agents will keep fitting to it.

Retire the harness that scores the UI against the mockups: just ui-compare and just ui-verdict (tools/src/beryl_tools/mockups.py's compare and review packets, verdicts.py and its test, the verdict ledger in docs/ui_mockups/regions.json), replica mode (ui/src/replica/, the ?replica= branch in App.tsx, the replica shots in ui/shots.json, the art cutting into ui/replica-art in shots.py), and the hooks in game code that exist only to pose replicas: Card.tsx's SlotArt and useSlotArt, and ChoiceOverlay.tsx's holding prop. Keep the mockup PNGs as visual references. just ui-probe and just ui-fonts may stay if they still work without replicas (ui-fonts renders its sheet through ?replica=fonts: move it to its own dev route or drop it); otherwise remove them too.

Update AGENTS.md and docs/ so nothing describes the mockups as a spec or mentions the removed commands. by-b0q.5 is adding these commands to the docs, so this bead waits for it.

Acceptance criteria

Nothing in the repo scores the UI against docs/ui_mockups; replica mode and its game-code hooks are gone; docs mention no removed command. just check and just ci pass.
