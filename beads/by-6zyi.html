Derek Thurn2026-11-13

Handoff: Cause: Drudge Skeletons (2ad51022) entered the generated-scenario pool in rust/crates/beryl_cards/src/generate.rs, because OUTSIDE_CUBE is a hand-kept list. That renumbered every 'Generated N' scenario. Forge failed Generated 51 (its AI paid Winds of Abandon with the only Swamp, so no {B} was left for regeneration). XMage failed Generated 110 on some runs (an unseeded Timetwister shuffle drew different cards) and Generated 22 on others (its AI paid Stock Up's generic cost with blue before Mana Drain). The Forge gap for Generated 22 in data/oracle-exporter-gaps.json went stale. Fix in 4a0572fa: Drudge Skeletons added to OUTSIDE_CUBE, which brings back the generated set that had been passing. tools/src/beryl_tools/xmage.py now emits RandomUtil.setSeed(<scenario seed>) in arrange(), as the Forge harness already does. Verified: the full oracle passed (xmage 514/0, forge 535/0 with the old pool), Generated with the new pool passed 3 of 3 runs, and 'by ci oracle python' passed. Note: Leonin Scimitar is also in no deck but is still in the pool. I left it alone, because removing it would renumber the set again.
