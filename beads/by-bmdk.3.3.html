Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Views and animation' (the verb table).

Extend rust/crates/beryl_table_session/src/script.rs (split into script/ modules by topic before any file passes 800 lines) with the rows: reveal (showcase, for the seats shown); look, lend (lift: cards lifted off their pile; the other seat sees how many and never which); arrow, clear_arrows (point begins or ends); roll, phase, next_turn, shuffle (announce, a banner; a shuffle also plays set for the new order); always_reveal_top, always_look_at_top (set).

  • lift and point are spans: they begin in one script and end in a later one. Read beryl_session/src/script/spans.rs and check.rs (carried) for the invariants a span must keep across scripts, and keep them: a look that is closed, a card that changes zone or a turn that passes must end its span.
  • Banner text for announce: "Shuffled", "Rolled 4 (d6)", "Heads", the phase name, "<name>'s turn". Wording is checked against the appendix's log list.

Tests in tests/script_library.rs: each action for each seat, the span begin and end pairs, and the random replay and redaction test extended to these kinds. Run just test-rust -p beryl_table_session.

Acceptance criteria

Each listed action produces its verb for both seats; spans begin and end as the session's span checks require; the random replay and redaction test passes with these kinds added.
