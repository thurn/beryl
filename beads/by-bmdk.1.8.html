Close reason

Text and Cockatrice deck import, exact case-insensitive lookup, and named JSON saves passed the fast check and landed on staging as 209279f4.

Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Cards and decks'.

Create rust/crates/beryl_table/src/deck.rs:

  • pub struct Deck { name, main: Vec<(String, u16)>, side: Vec<(String, u16)> }.
  • pub fn parse_text(text) -> Deck: every form in the doc's example block: a count, an optional x, a name; a set code in parentheses and a collector number after the name are ignored; a two-faced card named by both faces with // or by its front face; the sideboard begins at a blank line or a Sideboard heading, or is marked line by line with SB:. A line that is not a card is skipped and collected in a skipped list.
  • pub fn parse_cod(xml) -> Result<Deck, DeckError>: Cockatrice's .cod format: zones named main and side holding <card number="4" name="..."/>. Write a small hand parser for exactly that shape; do not add an XML dependency.
  • pub fn unknown(deck, store) -> Vec<String>: names the card store lacks. Names match exactly, ignoring case; no near match is guessed. A deck with unknown names still loads.
  • pub fn counts(deck) -> (u16, u16): main and sideboard sizes, the only thing the other seat is shown.
  • pub struct Decks with save, list, load, delete over a directory of JSON files, one per deck name. The directory is passed in; this crate does not know where app data is.

Tests in tests/deck.rs: the doc's example block verbatim; each form alone; a .cod sample; unknown names; save and list in a temporary directory (use std::env::temp_dir with a unique name and clean up). Run just test-rust -p beryl_table.

Acceptance criteria

The doc's example decklist parses to the expected main and sideboard; .cod parses; unknown names are listed case-insensitively; decks save, list, load and delete.
