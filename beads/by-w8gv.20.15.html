Derek Thurn2026-11-11

Decisions: (1) Stale updates and flakes count over the window (bead stale verdicts + backfilled rewrites, as Tally/by-w8gv.20.4 did); catches count all-time, so a check that once caught a bug is never deleted for age. Mixed verdicts count as neither. (2) 'Never failed' = no fail in the window's log and no verdict ever on its bead. (3) Costliest tenth ranks only tests the fast check can leave out (prune.SLOW_ONLY_LANES = rust, ids with '::'; step checks like rust:clippy and rust:allocations excluded), by fast-check seconds per run; SLOW_ONLY entries stay in the ranking with their recorded seconds, else each weekly prune would move another tenth. (4) Checks missing from the latest slow-CI run of their lane (commit of the lane's latest pass) are skipped: the 28 checks by-w8gv.20.4 deleted still have rewrites in the 30-day log. (5) Keeps: '// keep: <reason>' within 12 lines above a check() in ui/scripts/interactions.mjs (template titles resolve string consts, other ${} parts match anything), above a test fn inside the rust lane's CHECK_SIDE (tests regions or rust//tests/), and shots.json's existing per-shot 'keep' field (not $comment: by-w8gv.20.4 put keeps there). Oracle scenarios have no keep form yet. (6) Deviation: nextest errors on a binary_id() that matches no binary, and a run-log id does not say where the binary ends (beryl_cli has no lib binary, for one), so the SLOW_ONLY filter is package(<crate>) & test(/^(<target>::)?<rest>$/); verified with cargo nextest list (516 tests -> 512 with four excluded, a missing test matches nothing). Browser checks: the selection chooser has not landed, so only Rust tests are left out.
