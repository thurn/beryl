Close reason

Delivered per-seat history, batch undo controls and last-draw lookup backed by authoritative undo checks.

Description

by-bmdk.3.1 commits to producing TableView.log with undoable and blocked_by, and by-bmdk.3.19 requires Undo last draw by key. Log exposes only entries/is_struck/rebuild. The only real decision about eligibility and conflicts is private undo::target. The adapter could guess from Action discriminants or replay a whole cloned table to test each button. Also log::line requires the table projected for the viewer and entry_seen_by requires its exact previous host state: rebuilding every earlier entry on every view repeats table replay, and formatting historic moves with the current state loses former names when ids change.

In beryl_table/src/{log.rs,log/line.rs,undo.rs,redact.rs}, expose a read-only per-viewer history projection and undo query from the same eligibility and conflict logic that applies the action. Use a single forward projection pass on load/rebuild or keep projected lines incrementally from the correct view at each entry. Keep strike status live and use actor seat labels only in display. Do not expose raw host entries or invent eligibility in beryl_table_session.

Acceptance criteria

Given draw, unrelated tap, blocked batch, rewind and save reopen, compare the public query and offered controls with real Undo results for both seats. Recent draw remains discoverable, the query names exactly the blocking entries, and previously recorded wording stays redacted and consistent after an id change. Rendering the full log does not replay the same prefix per row.

Handoff: Use Log::history(&table, seat) for cached per-seat row text, actor seat IDs, live strike status and batch UndoControl. Use Log::undo_target with the same Option<u32> that Action::Undo accepts. Log::last_draw finds the most recent live draw by the acting seat even when blocked, so the shortcut can report that draw’s blockers. Undo rows reuse the target’s recorded wording. A move that gives a card a new private hand ID is anonymous to the other seat, while prior public rows keep their original names. Save replay repopulates the wording from existing action/outcome records. The existing projected Entry and standalone formatter are still available for existing callers.
