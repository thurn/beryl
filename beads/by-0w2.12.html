Description

Part of the Arena Powered Cube retarget (epic by-0w2): Beryl's V1 cube is now data/arena-powered-cube-2025-10-30.csv and the mirror match target is the 40-card main deck in docs/sample-decks/2025-11-18-17lands-cb8d5d5f-wu-control.txt (30 distinct cards, 17 of them new). Read the epic's description and design field first; docs/engine-architecture.md is the design. Rules code cites the Comprehensive Rules with yawgatog links and quotations (AGENTS.md). Follow the existing card files in rust/crates/beryl_cards/src (for example blue/mana_drain.rs, white/overlord_of_the_mistmoors.rs) for layout and scenarios.

Replace WU_CONTROL in rust/crates/beryl_cards/src/decks.rs with the main deck of docs/sample-decks/2025-11-18-17lands-cb8d5d5f-wu-control.txt (28 nonbasics, 6 Plains, 6 Island) and move every consumer to it: the session and app, beryl_cli (play, tournament), beryl_bench, the UI fixtures (re-record ui/fixtures.json and remap ui/shots.json states), ui/scripts, and tools/src/beryl_tools/cards.py's default DECK. Regenerate data/cards.json with just cards for the new deck.

Then drop the Vintage list (epic design decision 4): data/vintage-cube-2026-10-07.csv and the transitional sentence in AGENTS.md; update docs/engine-architecture.md where it names the old deck. Never delete an existing card implementation: Aang's Iceberg, Swift Reconfiguration and Sphinx of False Conclusions stay implemented with their scenarios and mechanics, as cards outside the cube (turn any retired-names list into a permanent list of implemented cards outside the cube). Keep the old WU_CONTROL list available as a second deck if fixtures, tests or fuzzing still benefit from it.
