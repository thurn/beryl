Description

No-equivalent UI Conventions entries Beryl 3D does not follow yet (found while mapping them on 2026-11-16):

  • "Manual table: a click acts": clicking a life total opens no number prompt, the table shows no mana symbols or player counters to click, and a refused action does not shake what was clicked.
  • "Manual table turn controls": the manual table shows no step track beside the active player's life total and no Next button (screen/table's tree has neither).
  • "Manual counters and untap flags": check named counter badges, Add counter's six names, player counters beside the mana pool and the lock on a permanent that skips its untap; build what is missing.
  • "Manual table announcements": hud/notices.rs has the words (Shuffled, Rolled 4 (d6), Rewound to 41, Game 2), but no banner shows on the table: table-board's announce step (116 ms to 1316 ms) puts no text in the tree.
  • "Quitting from a manual table": Cmd+Q on screen/table leaves the table at once (it sends table_leave) instead of asking whether to leave the table and quit, with Cancel keeping it open.

Read first: docs/ui-conventions.md (generated from data/ui-conventions.json) for each entry named below; docs/beryl-3d.md "The parity list"; .claude/skills/b3d/SKILL.md; data/beryl3d/conventions/no-equivalent.json and rust/beryl3d/crates/beryl_inspect/tests/all/conventions.rs (an entry is {"recording", "at", "do"?, "shows"}; "do" lists actions such as menu <locator>, a right click, run at "at" before "shows" is looked for). The manual table client is rust/beryl3d/crates/beryl_scene/src/manual/ and src/client/manual*.rs; screen/table and the table-* recordings show it (just b3d tree screen/table --at end --do ...). The web interface is the reference: ui/src/table/ and ui/src/screens/Table.tsx.

For each entry: build what Beryl 3D lacks in beryl_scene, following the web code, add a recording (a screen recording in beryl_inspect/src/screens.rs, or a stress board) if none shows it, and replace the entry's {"open": ...} in data/beryl3d/conventions/no-equivalent.json with {"recording", "at", "do"?, "shows"}. Never edit data/ui-conventions.json or add a numbered exception. If one entry would pass about 600 lines, leave it open naming a new bead under by-q44s.9.

Run: just b3d cargo-test -p beryl_inspect conventions, just b3d test, just b3d parity (conventions line). Before enact push: run just b3d cargo-test and just b3d test yourself. Tests in beryl_inspect locate elements by role and name, never by numeric id. Do not re-pin limits in data/beryl3d/gates.json by hand.

What changed (rust/beryl3d/crates/beryl_scene):

  • Turn controls: screens/table.rs controls draws the life orbs, hud::steps::table_steps (a Mode::Table of the step icons; a press sends TablePress::Step) and manual::turn::next (Next button, caption from turn::caption). manual/turn.rs maps icons to phases; commands::actions_for now builds phase.next / phase.next_with_action (Tab / Shift+Tab made nothing before) via turn::advance.
  • Clicks: client/manual.rs table_click taps permanents, plays hand or library-viewer cards (face down with Shift), resolves stack entries, draws from a library (pile press via table_library_at/table_library_clicked in client/table_pointer.rs and client/input.rs); life_clicked opens Set life. manual/pools.rs draws each player's six mana symbols and named player counters where a game shows the pool (click adds, right click removes via adjust_counter); the pool float is hidden on the table (CountFloats::pools). The opponent's row takes clicks only at a two-seat table, as the web's Chrome.
  • Counters: Add counter's ask dock offers the web's six common names above its field (ask::COUNTER_SUGGESTIONS, TablePress::AskSuggestion).
  • Banners: beryl_inspect/src/screens.rs gives screen/table a second update announcing a shuffle. The table's first view's script never plays (play/compile.rs, as on the web stage), which is why table-board's "Game 1" showed nothing; that is by design.
  • Quit: Cmd+Q (table.leave by key) opens manual/quit.rs "Quit Beryl?" with Cancel and Quit (the web's native-dialog words). Quit sends the new Request::Quit; beryl_3d's AppFeed ends the run, and the session thread's end shuts the table down so it can be resumed. The Leave table menu row still leaves at once.
  • Controls hide under the guided start's opening screen, and the new commands do nothing on a frozen table.
