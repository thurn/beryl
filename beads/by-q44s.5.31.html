Description

Read first: the epic by-q44s ('Rules for every bead'); rust/beryl3d/AGENTS.md; docs/beryl-3d.md 'The flat layer', 'Hosts'; docs/manual-multiplayer.md (the manual table's design: what a command is, the context menus, the command list, keys). What has shipped in the web interface is the solo table and everything on it; hosting and joining have IPC wrappers in ui/src/ipc.ts (tableHost, tableJoin, tableResume, tableSaved) but no screen calls them, so they are not built here. Code: beryl_scene src/manual (from the bead before), src/widgets (list, field, menu), src/screens/table.rs. Web: ui/src/table/CommandList.tsx (CommandList: a searchable list of commands as a panel or full screen, onRun(id, shift)), TablePalette.tsx (TablePalette: the list behind Cmd+K), commandList.css; AskPrompt.tsx and ask.ts (AskPrompt: a typed number or text in the dock; parse: an integer, where a sign means a change; parseStats: 'p/t'; clamp); TokenSearch.tsx and tokenSearch.css (TokenSearch: search by name, the deck's related tokens, a custom token; shift-click variant); LibraryOrder.tsx (LibraryOrder: the ordering tray that opens when several cards are dropped on a library); TableLog.tsx and tableLog.ts (TableLog: lines with undo and rewind controls, folding); the cardSearch call in ui/src/ipc.ts and the Rust command behind it.

Build, each in its own file of src/manual: palette.rs (Cmd+K opens the command list over the table, filtered by a field, rows run their command, Shift runs its shifted form); ask.rs (a command that needs a value opens the ask prompt in the dock, parsed as ask.ts does, sending the action with it); tokens.rs (the token search, with a new SessionCommand::CardSearch(String) answered as the web's card search is); order.rs (the library order tray, built on milestone 2's tray); log.rs (the table log at the table's left with undo and rewind sending their actions).

Tests, in beryl_scene/tests/manual.rs: typing 'shuf' in the palette leaves the shuffle command first; '+3' in a life ask sends a change of 3 and '7' sends a set to 7; '2/3' sets power and toughness; the token search lists the deck's tokens before searching; undo on a log line sends its action.

Run: just b3d cargo-test -p beryl_scene; just b3d test b3d:screen/table; just b3d lane.
