Description

Symptom: on origin/staging (checked at 6780191a6 and 08589bff8, in a clean worktree), two Beryl 3D tests fail every run, so every Beryl 3D push whose fast check selects them fails beryl3d-tests:

  • beryl_assets glyphs::every_icon_and_demanded_glyph_fits_the_atlas_at_every_display_scale (rust/beryl3d/crates/beryl_assets/tests/all/glyphs.rs:253): "every icon at scale 1": the worker sent 106 icon cells where beryl_assets::icons::ALL holds 42 (assert_eq!(icons, icons::ALL.len())). Either icons are now rasterized more than once (wasted atlas room), or the icon list the worker draws from is no longer icons::ALL.
  • beryl_inspect furniture::the_life_orbs_are_drawn_in_the_webs_core_bezel_and_ring (rust/beryl3d/crates/beryl_inspect/tests/all/furniture.rs:160): "no panel is drawn on Rect { x: 670, y: 618, width: 260.3, height: 111.0 }".

Both passed on the base 790c47f21 (fast check of a push at about 19:50 on 2026-11-16) and fail from 6780191a6. The commits between that touch this code are 827edf753 (b3d manual table turn controls, banners, quit) and 03ffb6b3c (manual table clicks, mana and counter suggestions), which add icons and furniture; e29affac9 and 1750f7f43 touch the orbs and their test. Slow CI does not run the Beryl 3D workspace, so it stayed green.

Read: rust/beryl3d/crates/beryl_assets/src/glyphs.rs (GlyphWorker::icons, pages), rust/beryl3d/crates/beryl_assets/src/icons.rs (ALL), the two tests above, rust/beryl3d/crates/beryl_scene/src/hud (life orbs).

Acceptance criteria

On origin/staging, just b3d cargo-test every_icon_and_demanded_glyph the_life_orbs_are_drawn passes, and enact push of a Beryl 3D change no longer fails beryl3d-tests on them.
