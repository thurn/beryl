Close reason

Hand cards show their mana cost above the top right corner in Beryl 3D; settled entry is a recording entry

Description

UI Conventions, settled entry "The hand's fan": each hand card's mana cost stands above its top right corner, turned with the card, so a crowded hand still shows every cost. Beryl 3D lays the fan on its circle (rust/beryl3d/crates/beryl_scene/src/table/hands.rs) but draws no cost label (just b3d tree hand-ten --at end lists no cost text, and the b3d skill says text in the table is not drawn yet). Read how the web places the cost (search ui/src/stage and ui/src/components/Card.tsx for the hand cost, by-c4f4/by-kgn7/by-pic0) and add it to Beryl 3D, using the face's mana_cost (rust/beryl3d/crates/beryl_scene/src/faces.rs). Then replace the open entry for "The hand's fan" in data/beryl3d/conventions/settled.json with a recording entry (hand-ten, at end, shows the cost element of one card).

Acceptance criteria

The entry is a recording entry; just b3d cargo-test -p beryl_inspect conventions and just b3d test pass; enact push passes.

Handoff: Beryl 3D now draws each face-up hand card's mana cost above its top right corner (rust/beryl3d/crates/beryl_scene/src/table/badges/cost.rs, called from Table::write_card in table/scene.rs; symbols shaped on view arrival by Show::shape_badges in play/mod.rs). Sizes are the web's .hand-cost values, in badges.cost of data/beryl3d/space.json. The cost is lifted 3 mm toward the eye so it draws in front of the next cards of the fan. It is a Role::Text child element of its card, named by the cost string, marked StateBits::PASSES so presses go through it (as the web's pointer-events: none); without PASSES it made 23 phone 'reachable' faults. RECORDS_PER_OBJECT went 12 -> 16 (hybrid symbols take 3 glyphs each), ELEMENTS gained one cost element per object, and the badges' own budget stays 8. Gate limits for verbs-zones and pay-default were raised to measured values (listed in the commit body). Picture comparison: Beryl 3D /b3d/out/hand-ten-you-1600x900-end-904.png against web /ui-shots/by-q44s.9.29/game-hand-ten.png (hand-ten, at end, 1600x900). Symbol size, position and how neighbouring costs overlap match. Checks: just b3d test (8280 passed), conventions test, gate, lane all passed. The phone run has 166 failing tests both before and after this change, none involving a cost element. Reviewer: check the lift value for very large fans, and the instruction count on pay-default's first frame (+38%, from shaping the symbols).
