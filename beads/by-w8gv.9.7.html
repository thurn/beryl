Description

Milestone 5 of Project 50k (plan K5 and K3; epic by-w8gv.9): the rules library and the card port. Line numbers and counts below were read at staging f5034c58; the code as it stands wins over this text, and a deviation is a comment on this bead.

Last bead of the library lane. The vocabulary holds five entries that are one card's sentence each (data/card-names-allowlist.json, "mechanics"):

  • Rule::OpponentsCastAsSorceries: Teferi, Time Raveler's static ability, "Each opponent can cast spells only any time they could cast a sorcery."
  • Rule::SorceriesAsFlash: his +1, "Until your next turn, you may cast sorcery spells as though they had flash", started as an effect on a player.
  • Rule::InstantLoyaltyTheTurnItEntered: The Wandering Emperor, "As long as The Wandering Emperor entered this turn, you may activate her loyalty abilities any time you could cast an instant."
  • Replacement::WinInsteadOfDrawingFromEmptyLibrary: Jace, Wielder of Mysteries, "If you would draw a card while your library has no cards in it, you win the game instead."
  • Modification::PowerIsCreaturesYouControl: Adeline, Resplendent Cathar, "Adeline's power is equal to the number of creatures you control", mirrored in the kernel as effects::LayerChange::PowerIsCreaturesYouControl.

Replace each with data composed from the expression types the vocabulary has (Players, Filter, Amount, Condition, Effect), designed from the rule it is an instance of. The design is yours; the shapes the rules suggest:

  • A rule change (CR 613.11, CR 101.2 "can't" beats "can"): who it applies to (a Players value read from the source's controller), what it governs (casting spells a filter accepts; activating loyalty abilities of some permanents), how (only at sorcery timing, CR 307.1; as though it had flash, CR 702.8; any time they could cast an instant, CR 606.3), and an optional Condition.
  • A replacement (CR 614): the event (a player would draw), a Condition (their library is empty) and what happens instead (an Effect: that player wins, CR 104.2).
  • A characteristic-defining ability (CR 604.3, CR 613.4a): set power to an Amount, counted over a filter.

Who evaluates an amount (M4 Mason audit, comment on by-w8gv.9.1, item 1)

The kernel stores payloads and cannot evaluate a vocabulary expression; the layers (rules code) can. A value locked in as an effect begins (CR 608.2h) is a number in the payload. One read as the layer applies (CR 613.4a) is not: the payload names the expression and the layers evaluate it. Decide and record which each new entry is.

Where they are read

  • beryl_card/src/continuous.rs: the rules! macro (which makes Rule::ALL, Rule::words() and the Rules bit set), Rule::whose, Replacement, Modification, Layer.
  • beryl_kernel: table.rs (per-game capability bits and FaceFacts), effects.rs and effects/store.rs (the payloads, and rule.words() in the store's description of an effect, which the UI shows), trackers.rs.
  • beryl_rules: rule_change.rs (75 lines), the timing reads in cast.rs (sorcery_speed_only line 98, instant_speed line 111) and mana.rs (instant_speed line 773), wins_instead_of_drawing in event.rs (line 417), layers.rs, and tests/cast.rs, casting.rs, events.rs.
  • beryl_search/src/rollout/policy.rs and values.rs name these entries in generic search: move them to whatever query answers the same question. beryl_search/src/frozen is exempt and changes only to compile.
  • Cards: azorius/teferi_time_raveler.rs, white/the_wandering_emperor.rs, blue/jace_wielder_of_mysteries.rs, white/adeline_resplendent_cathar.rs. Change the static abilities and the payload Teferi's body starts; the bodies themselves are the port's.

Constraints

  • A rule check is one AND behind a capability bit when no card in the game makes that kind of change (docs/rules-coverage.md, Principles 1 and 2). The layers and the timing checks are on the counted path: prove it on just bench-count.
  • The effects store's entry stays 24 bytes in Small; a larger rule value is stored by reference to static data or by index, not inline.
  • The words the UI shows for a lasting effect come from words(): the text a player sees for these three rules must not change (beryl_session's tests and the specs hold it; just check runs the script lane).
  • The previous bead of this lane typed what a continuous effect may affect; build on its type.

No new rules features (run epic by-w8gv, K14): the vocabulary may now say things no implemented card says. Where the engine has no code path for an expressible value, the card table must refuse the definition when it is built (TableError, beryl_kernel/src/table.rs) or the definition check must reject it, with a test; it must never run as a silent no-op. List each such gap in a comment on this bead: they are docs/rules-coverage.md's project, not this one's.

Tests: the four cards' scenarios (cargo test -p beryl_cards teferi, wandering, wielder, adeline), just oracle "Teferi, Time Raveler" "The Wandering Emperor" "Jace, Wielder of Mysteries" "Adeline, Resplendent Cathar", beryl_kernel's effects and trackers tests.

Design (executor, before the code; the handoff says what landed). Counts before, just bench-count at staging 8be4a265: copy 13,481; next_apply 360,866,181; policy 1,746,603; rollouts 388,132,971.

  1. The draw replacement. Replacement::WinInsteadOfDrawingFromEmptyLibrary becomes Replacement::WouldDraw ('if you would draw a card'), with the ability's own condition (Ability::condition, here 'your library has no cards': Compare(Count(All{Library, Whose(You)}), Equal, Fixed(0))) and its body as what happens instead (effect data). Two new Effect entries for the body: WinGame(Players) and LoseGame(Players), with arms in ending.rs. The engine's path for 'instead' is those two; the table refuses any other body on a draw replacement. A capability bit says a card of the game replaces draws, so a draw in any other game costs one AND.
  2. The power-defining ability. Modification::PowerIsCreaturesYouControl becomes Modification::SetPower(&'static Amount). On a static ability of the permanent itself with no condition it is characteristic-defining (CR 604.3) and applies in layer 7a, and its amount is READ AS THE LAYER APPLIES (CR 613.4a): the layers evaluate the Amount against the results of layers 2 to 6, so the kernel's LayerChange has no mirror of it and the payload holds no number. Paths: Fixed, Count of permanents by a filter of characteristics and controller, Times. The table refuses every other use (an Aura's or a conditional one, which is layer 7b; one in Effect::Modify, which would lock a number in as it begins, CR 608.2h; an amount outside those three), since the engine has no layer 7b.
  3. The three rules. A rule change is data: RuleChange { players: Players, what: CastSpells(Filter) | ActivateLoyaltyAbilities(Objects), when: OnlyAsSorcery | AsInstant, condition: Option<&Condition> }. A game numbers the rule changes its cards can make (GameTable, in order of first appearance; RuleId, one byte), so Payload::Rule holds the number and the entry stays 24 bytes, and the sets of rules in force for each player (static abilities', the effects') are sets of those numbers in one word. The table keeps a mask of the numbers of each kind the engine checks, so a check is still one AND when no rule of that kind is in force; when one is, the check reads that rule's filter or condition. An ability whose effect starts a rule change names it in Ability::rule, as a static ability does, so the table can number it though the body is Rust. Words: RuleChange carries none; the store's description words are derived from the data for the shapes the three cards use.

Order of work: 1, 2, 3, a commit each.

What landed (executor). The five entries are gone from beryl_card, and LayerChange::PowerIsCreaturesYouControl from beryl_kernel; data/card-names-allowlist.json's mechanics holds four, none of them these.

Each new entry, and whether what it reads is locked in or read as it applies:

  1. Replacement::WouldDraw, with the ability's own condition and its body. READ BEFORE EACH DRAW: the condition, for the permanent's controller, and the players its body names. Jace is { condition: your library has no cards, body: WinGame(You) }. New effect entries WinGame(Players) and LoseGame(Players) (ending.rs: win, lose, their instructions).
  2. Modification::SetPower(&Amount). READ AS THE LAYER APPLIES (CR 613.4a), never locked in: LayerChange::DefinedPower { face, ability } names the static ability that says it and holds no number, and layers::apply reads that ability's amount against the results of layers 2 to 6. Adeline is SetPower(Count(creatures you control)).
  3. RuleChange { players, what: CastSpells(Filter) | ActivateLoyaltyAbilities(Objects), when: OnlyAsSorcery | AsInstant }, named by Ability::rule; a static ability's 'as long as' is Ability::condition (new Condition::EnteredThisTurn(Objects) for the Emperor's). No amount. WHO it applies to: for a static ability, read with the layers for the permanent's controller as layer 2 leaves it; for a resolving effect (continuous::change_rule), LOCKED IN as it resolves, one Effects entry on each player. A game numbers the rule changes its cards name (beryl_kernel rule_changes.rs: RuleId, Rules, a u64; RuleKind), Payload::Rule holds the number, and the entry is still 24 bytes. size_of State<Small> is 20,216 (each of the four per-player sets is a word, where it was a byte).

Checks stay one AND with no such card: State::rules_for(player) AND GameTable::rules_of(kind) for casting, GameTable::rules_of(LoyaltyAsInstant) empty for loyalty, the battlefield's listener mask bit kind::DRAW_REPLACEMENT for draws.

Words: RuleChange::words() makes them from the data; the three shapes give the three old strings exactly (a test in beryl_card holds them, and the kernel's checkpoint test still reads 'player 1 casting sorceries as though they had flash until their next turn').

Second instances, each through the cards' own path (beryl_rules/src/tests/static_abilities.rs): 'if you would draw a card, you lose the game instead' and 'each opponent wins instead' (no condition, a full library); 'power equal to twice the number of artifacts you control'; 'each player can cast spells only any time they could cast a sorcery'; 'you may cast creature spells as though they had flash'; an effect-started 'each opponent can cast instant spells only as a sorcery until end of turn'; a permanent's own loyalty rule on two other conditions (no cards in hand, read with no scene; tapped, read in a scene).

GAPS: expressible, no engine path, refused by the card table (TableError::Static, beryl_kernel/src/static_abilities.rs and rule_changes.rs), each with a test; rules-coverage's project, not this one's:

  • a draw replaced by anything but a player winning or losing (Unsupported::Instead); read for players other than you / each opponent / each player (Players).
  • a power set by an Aura's or a conditional static ability, which is layer 7b, or by Effect::Modify, which would lock a number in as it begins, CR 608.2h (SetPower); a defined power as anything but a number, a count of permanents by characteristics and controller, or a multiple (Amount). There is no SetToughness entry.
  • a rule change about other permanents' loyalty abilities, or restricting loyalty abilities to the timing they have (Rule); one an effect starts that is asked of a permanent (Rule); casting governed by a filter that asks more than a spell's own characteristics: whose, tapped, mana value (Filter); a rule for players as long as a condition holds, since the layers that find the players read no condition, and two abilities making one rule change on different conditions (Condition); players other than the three (Players); more than 64 rule changes in one game (Rules). Not refused, and unchanged from before: a static ability of an emblem that changes a rule or replaces a draw does nothing, since both are read of the battlefield; the table cannot tell an emblem's definition from a card's. 'If an opponent would draw' has no entry (WouldDraw is its controller's draws).
