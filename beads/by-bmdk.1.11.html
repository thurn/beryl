Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), sections 'The table' (the stats rule), 'Placement', 'Click' ("enters tapped").

Create rust/crates/beryl_card_store/src/facts.rs (pub mod facts). These are plain readings of a Record's front Face; none interprets rules.

  • is_land, is_creature, is_planeswalker, is_permanent, is_legendary, is_attachment (Aura, Equipment or Fortification), from the type line.
  • row(record) -> Row3 where Row3::{Creatures, Others, Lands}: the battlefield row from the type line (a creature of any other type goes to creatures; a land that is not a creature to lands; everything else to others).
  • printed_stats(face) -> Option<(i32, i32)>: power and toughness, a * or other non-number counting as 0.
  • shown_stats(printed, manual, plus, minus) -> Option<(i32, i32)>: the manual value if set, otherwise the printed one, plus the +1/+1 counters and minus the −1/−1 counters.
  • starting_counters(face) -> Option<(&'static str, u16)>: ("loyalty", n) or ("defense", n) from the printed loyalty or defense.
  • enters_tapped(face) -> bool: the rules text, outside reminder text in parentheses, contains "enters tapped" or "enters the battlefield tapped" with no "unless" in the same sentence.
  • mana_value(face) -> u32 from the mana cost string.
  • keywords(record) -> &[String] (already a field; expose it), and has_keyword(record, name) ignoring case.
  • tokens_made(record) -> &[TokenLink].

Tests in src/facts/tests.rs use real records from STORE (card names are fine in tests): one per function, including a creature land, a card with * power, a planeswalker, a battle, a tapped land and a land that enters tapped "unless". Run just test-rust -p beryl_card_store.

Acceptance criteria

Every function listed exists with a test on real store records; nothing in facts.rs names a card outside tests.
