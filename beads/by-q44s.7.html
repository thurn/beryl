Description

Native iOS and Android builds. Milestone 1's phone spike (by-q44s.1.23) already drew the table in the iOS Simulator and the Android emulator with minimal hosts, and its bead holds what each graphics path needed. This milestone turns those into the real hosts. Doc: 'Hosts', 'The flat layer' (Sizes), 'Migration and compatibility' (Platforms and versions).

Exit checks:

  • A Swift host and a Kotlin host drive the app through the C functions beryl_3d exports.
  • The phone layout passes every interface check at 393 by 759, 375 by 647 and 430 by 932.
  • Touch, the system keyboard through a native text field, safe-area insets, suspend and resume with the surface lost and recreated, and the low-memory path all work.
  • The hosts contain no game or layout logic.
