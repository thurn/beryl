Description

Card

Opalescence: "Each other non-Aura enchantment is a creature in addition to its other types and has base power and base toughness each equal to its mana value."

It is one effect with parts in layer 4 and layer 7b, over a set a filter finds, with a base P/T read for each affected permanent as the layer applies.

The interaction

With Humility on the battlefield, Opalescence makes Humility a creature in layer 4. Humility then removes its own ability in layer 6, and still sets base P/T in layer 7b, because an effect that began to apply keeps applying (CR 613.6). In layer 7b the later timestamp wins: if Humility came later, every enchantment creature is 1/1; if Opalescence came later, each is as big as its mana value. Write both orders as scenarios, and two Opalescences (each makes the other a creature).

A granted static ability

Plan: Designs 2, "A granted static ability". If an ability granted in layer 6 has an effect in an earlier layer, the recompute runs once more with it present, at most three times, only in a game where the table says some card grants a static ability. Build it here with a test definition; no card of this epic needs it.
