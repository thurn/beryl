Description

Part of Milestone 1 (epic by-b0q): a rules-exact engine, game UI and AI opponents for a mirror match of the 40-card WU Control main deck in docs/sample-decks/2026-10-17-PrinceJools-wu-control.txt (29 distinct cards). Read the epic's description (plan, card table) and design field (decisions) first; docs/engine-architecture.md is the design. Rules code cites the Comprehensive Rules with yawgatog links and quotations (AGENTS.md).

Design decision 16. Meticulously reproduce the mockup parts listed below, one part at a time:

  1. Measure the part from the PNG with just ui-probe: sizes, corner radii, border widths, colors, shadow offset and blur, glow color and falloff, gradient stops, letter size, weight and spacing.
  2. Implement or adjust the real component and its styles.
  3. Run just ui-compare on the part and study the side by side, onion skin, difference and flip outputs, zoomed.
  4. Repeat until the part is indistinguishable from the mockup.

Compare every mockup a part appears in, not just one. In replicas the art windows hold the mockup's own art, and masked regions (the MAGIC card back's artwork, the mouse cursor) don't count. Garbled mockup text (for example "Mounstain") is matched in style, not spelling. Changes go into the components and styles the game uses, never into replica-only overrides. If the region file lacks a part or draws it wrong, fix the region file.

Done for a part: a fresh reviewer subagent (not your own judgment), given the part's side by side, onion skin and difference images, calls it indistinguishable from the mockup at a glance. No numeric thresholds. Post each part's verdict, and anything the reviewer accepted as out of reach (painted lighting, texture noise), as a comment on this bead.

Now that the game screen exists, make whole screens match. Build a replica fixture for each screen named below through the real game screen (not the gallery), then compare the whole screen and every part in place: the position and size of every zone, row and card, the perspective, the hand fans, life orbs, piles, overlays, arrows and buttons. Fix the layout code the game uses. The layout must still work at other window sizes: capture 1280×800 and 1920×1080 with just ui-shots and check for overlap or clipping.

Screen: battlefield.png. Every element on it: the crest and wordmark, the Opponent and You badges, the opponent's hand of card backs, both life orbs, the opponent's library and graveyard, the settings gear, both players' land stacks, the four creatures, the player's library, the hand fan, the phase tracker, Next and its caption. Then the whole screen as one overlay.

  • The changes live in the game's own components and styles.
  • npm run typecheck, prettier, just smoke and just check pass; no screenshots, crops or comparison outputs committed.
  • A whole-screen verdict for battlefield.png.
