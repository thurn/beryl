Description

Part of the AI ladder epic by-ix1t. Read docs/ai-plan.md first: §3, §4.3 step 1 and §6.1.

The new design makes the policy the player at every decision, so the policy's own blunders must be measurable without a search. Today only plain greedy is a registered agent. There is no way to run greedy with the rules hold and waste set, or with the combat planner answering combat, on the blunder suite. just blunders greedy --seeds 1 takes seconds because greedy is deterministic; this bead makes the same true for the whole policy.

Where

  • rust/crates/beryl_search/src/lib.rs: AgentInfo, the AGENTS table, agent(name), and the greedy entry's constructor.
  • rust/crates/beryl_search/src/rollout.rs: RolloutPolicy::with_rules, Rules { hold, waste }, RolloutPolicy::choose.
  • rust/crates/beryl_search/src/long.rs, LongSearch::choose_traced: how the search builds its default. With Options::combat it deals one world (obs.determinize, from a stream seeded by the agent's seed and the decision) and asks combat::Sim::<_, combat::General>::new(...).choose(&start, d), keeping one combat::Plan across a turn's declarations and resetting it when the game resumes or the declaration is not played. Do the same.
  • rust/crates/beryl_cli/src/blunders.rs and ladder.rs (resolve): how an agent name becomes an agent for the suite and for a match.

Build

  1. Names of the form greedy+RULE[+RULE...], with the rules hold, waste and combat in that order, resolve to an agent wherever greedy does: the suite, just tournament, just ladder --vs. greedy alone plays exactly as today. An unknown rule is an error that lists the three.
  2. hold and waste set the rollout policy's Rules. combat makes the planner answer wherever combat::handles(d.kind) is true.
  3. Tests: greedy+hold+waste+combat round-trips; greedy plays the same seeded games as before; with combat, a seeded game is the same on two runs.

Done

Run these On Cygnus and paste each table into the notes:

  • just blunders greedy --seeds 1
  • just blunders greedy+hold --seeds 1
  • just blunders greedy+hold+waste --seeds 1
  • just blunders greedy+hold+waste+combat --seeds 1
  • just blunders expert --seeds 1

Then, in the same push, add a column Policy to the table in docs/ai-plan.md §5 with right or wrong for greedy+hold+waste+combat at each entry. For each entry the full policy gets wrong, write one line in the notes on which rung of §6 should fix it, or that none does.

Acceptance criteria

The four greedy+... names run on the suite in seconds, the five tables are in the notes, docs/ai-plan.md §5 has a Policy column, and just test-rust and just check pass.
