Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), sections 'Turn upkeep', 'Combat' and 'State nudges', and the 'Assists' part of the doc's Manual QA list.

Interface code goes in ui/src/table/, registered with TableClient (ui/src/table/client.ts). Headless checks start a table with ui/scripts/table.mjs and go in ui/scripts/kept-table-<topic>.mjs; run one with just ui-test <title>.

The computations and the panel exist. This bead makes the three assists right in play and proves it in the browser. Fix what the checks below expose, in whichever file it lives.

  • Turn upkeep: when the turn passes to a seat with the assist on, they are offered the proposal (untap, draw, go to first main; no draw on the first turn of the game for the seat that went first). Applying it runs the stage's untap and draw motions in one script.
  • Combat: appears once an attack arrow exists and updates as arrows are added and removed, so it previews a block before the block is committed to. Applying marks damage on survivors, moves the dead to their owners' graveyards, changes life and loyalty, and moves to end of combat. Either seat with the assist on may apply it.
  • State nudges: the four labels; clicking applies the fix; the legend rule offers a label on each duplicate; the zero-life label is shown only to that player and concedes.

Checks (kept-table-assists-play.mjs, with pair() where two seats matter): with Combat on, draw one attack arrow and one block arrow: the proposal appears with a line per change, updates when the block arrow is removed, and applies to both players' cards on one click; switch one line off and apply: only the rest happens; the other player undoes it and every part is reversed at once; with State nudges on, mark lethal damage on a creature: the label appears and a click moves the creature; with Turn upkeep on, pass the turn and apply.

Acceptance criteria
