Description

This change is made in the Enact repository at ~/enact (scripts/enact.py, tests in tests/test_unit.py and tests/test_integration.py), not in Beryl. Read ~/enact/AGENTS.md first and follow that repository's workflow; record design decisions in ~/enact/docs/design.md. Keep changes backward compatible: projects and live sessions on every machine run this repository directly.

Why

Even with leases, old registrations and runs whose viziers died stay in the graph and clutter enact status.

What to change

  • Add enact run prune. For each run with no fresh lease on any of this host's routes (leave other hosts' routes alone): if its delivery is complete, mark it finished (the state from the finish bead); if work is still pending, mark it paused with a reason naming the expired lease, so a returning vizier resumes it explicitly with enact run resume --explicit.
  • enact ci runs the prune when it files a Steward bead, and enact status suggests it when it finds stale runs.

Done when

Tests cover pruning a complete stale run, a stale run with pending work, and a run with a fresh lease (left alone). Running it once in Beryl cleans up by-w8gv, by-gdn3, by-97g and by-sxgz unless their viziers are actually live.
