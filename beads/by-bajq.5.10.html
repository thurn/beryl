Close reason

Fork's copy colors read through Fork's text changes; CopyChange::Colors holds ColorWords

Description

Symptom: Crystal Spray on Fork, changing "red" to "blue", should make Fork's copy blue: "except that the copy is red" is a color word in Fork's text (CR 612.1, CR 707.9b), and both cards are implemented. Beryl makes the copy red.

Why: the copy exception's color is a plain value, CopyChange::Colors(Colors) in beryl_card/src/effect/terms.rs (CopyException::RED), not a word type from beryl_card/src/words.rs (ColorWords). A copy's exceptions are read lazily from the card (beryl_kernel/src/additions.rs Addition { card, entry }, Copiable::colors_of_additions in beryl_kernel/src/copiable.rs), so nothing records the words of the effect that made the copy. The Warden of group 4 (by-bajq.5.7) found it while walking every vocabulary type that holds a Colors or a Subtype; it is the only one left that a card's text names as a word.

Design to settle: the copy's colors are fixed when the copy is made (CR 707.10), by the words of the spell or ability that made it (Fork on the stack: State::words_of of the spell, or Scene::words in beryl_rules/src/actions/copy.rs). Options: make CopyChange::Colors hold ColorWords and record the read colors on the copy where the words change colors (rare and cold), or keep a words index on the addition. CopyChange::AddSubtype holds a creature type today (Phantasmal Image's Illusion), which no text change of the pool names; give it the same treatment only if it is free.

Bars: count gate with no bump; State<Small> within 20,480 bytes.

Acceptance criteria

A scenario in Fork's or Crystal Spray's file (or beryl_cards/src/tests/text.rs if neither oracle can play it, recorded per card-writing): P0 casts Lightning Bolt, Fork targeting it, Crystal Spray on Fork changing red to blue; the copy is blue (Assertion::Colors on the stack, or a blue-filtered effect). CopyChange::Colors no longer holds a plain Colors. just card check Fork; just count-gate holds.

Design chosen: CopyChange::Colors holds ColorWords; Copiable gains a private ReadColors (place of the exception + colors), set by Copiable::with_addition_read only when the copier's Words change the colors (cold). Only the last color-setting exception counts (CR 707.9b), so one record suffices; it travels with the additions (with_additions_of, relayout). Copiers in copy.rs, continuous.rs (become copy) and tokens.rs use it; replace.rs (as-enters copy) and checkpoint/board restore keep with_addition (words as printed). State<Small> 20,128 -> 20,168 (LastKnown pads 60->62; a one-byte packing saved nothing). Scenario lives in beryl_cards tests/text.rs: Forge keeps the copy red and XMage lacks Crystal Spray, so card diverge cannot record it. AddSubtype left as a plain Subtype: no text change in the pool names it and it would not be free.
