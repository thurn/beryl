Close reason

Beryl 3D shows the bug button and undo under the gear, undoes on Cmd+Z, and says why a refused click is refused; all three conventions entries pass

Description

No-equivalent UI Conventions entries about the engine game that Beryl 3D does not follow yet (found 2026-11-16; pay-default at prompt:1 has only the Next and Settings buttons):

  • "Undo": every answer can be undone, across turns and prompts, the cast and its payment together. Beryl 3D's game has no undo button (the manual table's log has one).
  • "Chrome": round icon buttons, the log toggle top left, and the bug button above undo with no gap kept for a missing button. The desktop game shows no bug button or undo.
  • "Why a click is refused": an illegal click shows its reason at the permanent that forbids it. Read the web's handling of a refused click (the Click reply's reason) and show it in Beryl 3D.

Read first: docs/ui-conventions.md (generated from data/ui-conventions.json) for each entry named below; docs/beryl-3d.md "The parity list"; .claude/skills/b3d/SKILL.md; data/beryl3d/conventions/no-equivalent.json and rust/beryl3d/crates/beryl_inspect/tests/all/conventions.rs (an entry is {"recording", "at", "do"?, "shows"}; "do" lists actions such as menu <locator>, a right click, run at "at" before "shows" is looked for). The manual table client is rust/beryl3d/crates/beryl_scene/src/manual/ and src/client/manual*.rs; screen/table and the table-* recordings show it (just b3d tree screen/table --at end --do ...). The web interface is the reference: ui/src/table/ and ui/src/screens/Table.tsx.

For each entry: build what Beryl 3D lacks in beryl_scene, following the web code, add a recording (a screen recording in beryl_inspect/src/screens.rs, or a stress board) if none shows it, and replace the entry's {"open": ...} in data/beryl3d/conventions/no-equivalent.json with {"recording", "at", "do"?, "shows"}. Never edit data/ui-conventions.json or add a numbered exception. If one entry would pass about 600 lines, leave it open naming a new bead under by-q44s.9.

Run: just b3d cargo-test -p beryl_inspect conventions, just b3d test, just b3d parity (conventions line). Before enact push: run just b3d cargo-test and just b3d test yourself. Tests in beryl_inspect locate elements by role and name, never by numeric id. Do not re-pin limits in data/beryl3d/gates.json by hand.

Acceptance criteria

Each of the three entries in data/beryl3d/conventions/no-equivalent.json is a recording entry that the conventions test passes; just b3d test passes; enact push passes.
