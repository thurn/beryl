Description

Read first: docs/beryl-3d.md 'Determinism' (third-party code is held to the same test), 'Performance gates' ('What is counted') and 'The flat layer' ('Text'). Read docs/benchmarking.md ('The VM') and tools/src/beryl_tools/bench.py (VM, provision_script, vm_ensure, vm_shell).

Three facts decide parts of this design. Learn them now, before the beads that depend on them are built. The code is thrown away, under rust/beryl3d/spikes, and deleted before this bead closes; the virtual machine and the answers stay. Each answer goes in a comment on the epic with the commands that reproduce it, and the doc is corrected where an answer changes it.

First, the machine. Beryl 3D counts in a Lima virtual machine of its own, beryl3d-bench, so that nothing it installs can move the engine's counts and neither gate waits for the other. In the tools package add vm.py, which makes and provisions it with bench.py's helpers under that name (Valgrind, the pinned Rust and the gungraun-runner, as beryl-bench has, and the distribution's Mesa Vulkan drivers package). If bench.py's helpers fix the name beryl-bench, give them a parameter that defaults to it: that is the one edit to bench.py.

  1. Do taffy and parley do identical work on every run? A small Gungraun benchmark lays out a row of one text and three buttons with taffy 0.15.1, and shapes "Pay {1}{U}" and a 200-character rules text with parley 0.13.0, using Open Sans from the google/fonts repository with system fonts off. Run it three times in the machine and compare the instruction counts.
    • Equal: the design stands.
    • Not equal: find the functions that vary with callgrind_annotate, and try a fixed-seed hasher and a warmed cache. If something makes them equal, say what. If nothing does, the doc's 'Determinism' says the work moves out of the counted boundary: file a bead under milestone 1, 'Lay out text outside the counted boundary', make the pay-default bead (by-q44s.1.36) depend on it, and correct the doc.
  2. Does a software Vulkan driver count fragments? In the machine, with wgpu 30.0.2, create a device with no surface on Mesa's software driver, once with default limits and once with Limits::downlevel_webgl2_defaults(). Draw one opaque quad in front of another with a depth buffer, in both orders, inside a pipeline statistics query. Is the count of fragment shader invocations the same over three runs, and does it leave out the fragments the depth buffer rejects?
    • Both yes: the GPU-count bead uses the driver's count.
    • Otherwise: it computes the count in test code, as the doc says.
  3. Can parley select a weight from a variable font file? Lay out one word in Open Sans at weights 400 and 700 from the variable file and compare the glyph ids and advances.
    • Yes: the flat-layer slice commits the variable files.
    • No: it commits the static Regular and Bold instances.

Run: the commands you used, listed in the comment on the epic.
