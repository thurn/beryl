Description

The docs/ui_mockups images are generated references, not a pixel spec: they are not consistent with one another, and earlier pixel-matching work fitted code to each one separately. This bead removes one such fit. Prefer one rule that holds in every state over matching any single mockup. just ui-compare verdicts for the affected regions may get worse; that is expected, so do not tune values back toward the mockups.

ui/src/screens/Table.tsx's TableScene, with screens/samples.ts's SAMPLE_BOARD and the production /table and /table/scry routes in App.tsx, is a second, static implementation of the battlefield, built to be compared with the mockups. The live game draws the board with game/Board.tsx and game/layout.ts instead, and the two have drifted: TableScene puts the opponent's graveyard at (1321, 37), 84 wide, and layout.ts at (1327, 40), 91 wide. The library piles' depth vectors are hand-written per side ({x: -29, y: 37, flare: 32} with squash 0.85 for the opponent, {x: 6, y: 12, twist: 7} for you) and duplicated in Table.tsx and Board.tsx, though depthScale and lean exist to derive how a pile lying on the table looks.

Remove the static table: delete TableScene, TableScreen, Hand, Creature, Lands and the TableBoard types along with samples.ts' board, and the /table routes. Keep the shared pieces Board.tsx imports (Stage, StageScale, Lying, StepBanner, Brand, Gear, depthScale, lean, the size constants), moved wherever they read best. Replace the table and table-scry shots in ui/shots.json with fixture shots of the real game screen (ui/fixtures.json). The gallery's 06 Scry panel draws TableScene too: show the real game screen there, or drop that preview. Derive the library and graveyard piles' look from their position on the table through one function used for both sides.

Acceptance criteria

TableScene, samples.ts' board and the /table routes are gone; shots cover the real game screen; library and graveyard piles share one derivation for both sides. just check and just ci pass, with no new constants tuned to a single mockup.
