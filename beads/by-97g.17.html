Description

Part of the ladder epic by-97g. Read docs/ai-strategy.md first: §3, §4.7 and §6.

Policy rungs each add one named rule to the rollout policy. This bead adds the plumbing and no rule: with no rule set, every agent plays exactly as before.

Where

  • rust/crates/beryl_search/src/long.rs: Options (four bools today), Options::to_name, impl FromStr for Family (the list of option names and its error text), and LongSearch::new, which builds the policy with RolloutPolicy::with(t, settings.family.knowledge).
  • rust/crates/beryl_search/src/rollout.rs: RolloutPolicy, RolloutPolicy::with, RolloutPolicy::view (which builds a Policy).
  • rust/crates/beryl_search/src/rollout/policy.rs: Policy (see its expert field for how a flag reaches the rules).
  • Commit 1c43427 added the option guard: copy how it touched Options, to_name, FromStr and the families_round_trip test.

Build

  1. In rollout.rs add #[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Hash, PartialOrd, Ord)] pub struct Rules { pub hold: bool, pub waste: bool }.
  2. RolloutPolicy stores a Rules. Add RolloutPolicy::with_rules(t, knowledge, rules); RolloutPolicy::with and RolloutPolicy::new pass Rules::default(). view copies it into a new Policy field rules: Rules.
  3. Options gains pub hold: bool and pub waste: bool, and a method fn rules(self) -> Rules. to_name and FromStr accept the names in this fixed order: anchor, expert, guard, mid, means, hold, waste (keep expert if it is already there; do not add it). Update the error text. (Rung 4 adds combat after them and rung 7 adds order last; they are options of the search, not rules of the policy.)
  4. LongSearch::new builds its policy with RolloutPolicy::with_rules(t, family.knowledge, family.options.rules()).
  5. No code reads Policy::rules yet. Do not touch rust/crates/beryl_search/src/frozen/.

Tests

  • families_round_trip (long.rs) covers …/anchor+hold, …/anchor+guard+hold+waste and rejects …/hold+anchor.
  • A search of a family with hold set chooses as the same family without it on the positions the test mid_lets_greedy_answer_below_the_root uses (no rule is implemented yet, so the moves are equal).
  • just test-rust and just check pass. rollouts_never_change is untouched.

Pushed with enact push. just blunders pimc72/hidden/rollout/tuned/anchor+hold --only oust-own-token --seeds 1 --work 3M runs and prints a result.
