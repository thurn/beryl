Offer dredge for a card milled earlier in the same run

Close reason

may_ask holds in every dredge game; a dredge offered for a draw after the same run milled the card (3429db45)

Description

replace::may_ask (beryl_rules/src/replace.rs) is read when a resolution or a step's turn-based actions begin: it is true only while a dredge card already sits in a graveyard with enough cards in its owner's library. A run that starts with it false is not opened to pause, so a replacement choice met later in that run takes its first candidate (replace::choose), which for dredge is declining.

Symptom: Jace, Wielder of Mysteries' +1 ('Target player mills two cards. Draw a card.') targeting its controller mills Life from the Loam, and the draw that follows is not offered dredge 3 (CR 702.52a: dredge works from the graveyard at the time of the draw; ruling: a card milled by an earlier dredge may replace a later draw).

Fix options: widen may_ask while a game has a dredge card (Capability::Dredge) to cover a dredge card in a library or hand that the run could mill or discard, or reopen the run when choose() meets a choice with the channel closed (run again on the copy from its start). Keep the absent-cost gate: games without dredge must pay only the table bit. Files: beryl_rules/src/replace.rs (may_ask, choose), resolve.rs (resolve, resolve_on_copy), engine/paused_step.rs. Test: a Life from the Loam scenario with Jace +1 milling it, then dredging the draw.

Acceptance criteria

A Life from the Loam scenario where Jace, Wielder of Mysteries' +1 mills Life from the Loam and the following draw is offered dredge passes just card check (Beryl, XMage, Forge). just count-gate shows no rise for the WU mirror.

Handoff: replace::may_ask (beryl_rules/src/replace.rs) is now just t.can(Capability::Dredge), and its State parameter and the dredge_live scan are gone. Callers in resolve.rs and engine.rs are updated. Decision: I widened the check rather than reopening runs. A run on the committed state cannot be rolled back when choose() meets a choice with the pause channel closed. Also, a dredge card can reach a graveyard mid-run from almost anywhere (mill, discard, a creature dying), so a narrower scan would almost always be true anyway. Cost: in games with dredge, every resolution and every step's turn-based actions now run on the scratch copy. Games without dredge pay only the table bit. The WU mirror count gate is +0.00% against the last staging tip.
