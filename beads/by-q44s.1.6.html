Tree printout, locators, hit testing and frame checks on staging at c73ecddbe

Description

Read first: docs/beryl-3d.md 'The agent interface' ('Times, moments, locators and actions' and 'What is printed') and 'Interface checks'. For what the web interface checks today, read ui/src/stage/fault.ts, phoneFaults in ui/scripts/capture.mjs, ui/scripts/stage-audit.mjs and audit.mjs, and search ui/scripts for 'overlap' and 'reachab'.

Everything here is a function of a Frame, tested on frames built by hand with FrameBuilder. Nothing here plays a recording.

In rust/beryl3d/crates/beryl_scene:

  • tree(&Frame, &TreeOptions) -> String in the doc's format: every line has role, quoted name, id, place, corner, size and then states, in that order, indented by parent. States are the doc's closed list. A place holding more than 12 cards prints its first three and a count line. TreeOptions holds within, role and full. The two header lines are the tool's, not this function's.
  • locate(&Frame, &str) -> Result<u32, LocateError>: a locator is the start of a tree line, with > to look inside another element. Names match whole and exactly. The error for no match or several lists the elements with the nearest names (by edit distance) and says how to narrow it.
  • hit(&Frame, point) -> Option<ElementId>, nearest depth first, honouring clips, and uncovered(&Frame, index) -> Option<Rect>, the largest uncovered rectangle of an element. The 'reachable' check and the test driver's presses both use it.
  • The checks that need one frame, each a function from a frame to a list of faults, exactly as the doc's 'Interface checks' states them: on screen; no overlap (flat-layer elements only); reachable; no duplicates; named; no blank card. And 'lines hold', which needs two frames: nothing draws a line until milestone 2, so test it on a planted pair.
  • Fault holds the rule, the elements and the moment, and prints in the doc's format. The command on its show: line is built from a Context the caller passes (recording, seat, layout, size).
  • Thresholds (the 24 and 44 point strips, half uncovered, and the rest) are in data/beryl3d/gates.json under audit, read through the build script's constants. List the new keys in rust/beryl3d/AGENTS.md.

Tests in beryl_scene/tests: one planted fault per check, reported with the right rule and elements; two overlapping cards in a row are not a fault; every line tree prints, fed back to locate, finds that line's element; a locator matching two elements fails and its message names both; the tree of a 300-card frame is under 80 lines without full.

Run: just b3d cargo-test -p beryl_scene.

Acceptance criteria

Each check fails on its planted fault and names the element; every tree line is a locator for its own element; the printout matches the doc's format, including its bounds; no function here takes anything but frames and options.

Handoff: beryl_scene src/agent/ — tree.rs (tree, TreeOptions, line, locator_of, place_word/place_from_word), locate.rs (locate, LocateError; trailing text allowed only after #id so a whole tree line locates), hit.rs (hit, uncovered, free_rect(min size), covered, bounds, is_within), checks.rs (check + on_screen, overlap, reachable, duplicates, named, blank_cards, lines_hold), fault.rs (Fault, Rule, Subject, Context{recording, seat, layout, size, safe_area, at}, Layout). Deviations: hit returns the element's index (Option<u32>), not ElementId, to match locate/uncovered and because card and flat-layer ids can share a number; every tree line (flat layer included) prints #id so lines are unique locators (doc example updated); 'moving' prints without verb/percent because Resolved carries neither (doc notes it); fault element text includes #id. Added Resolved::face (Option<u16>) for 'no blank card' and Role::Arrow (corners = Bezier control points) for 'lines hold'; table/scene.rs writes face: None since faces aren't loaded, so real frames will report blank-card until the faces work sets it. Hit order: flat layer over table; later tree index over earlier in the layer; smaller depth on the table. uncovered is computed on a grid cut along overlapping boxes, sampling centre + inset corners via hit. HashMap is banned by scene-purity, use BTreeMap. Thresholds: gates.json audit.{target_points, phone_target_points, line_end_points, line_reshape_points} -> data::audit::* f32 consts (build.rs). Tests: tests/agent.rs.
