Description

Read first: the epic by-q44s ('Rules for every bead'); rust/beryl3d/AGENTS.md; docs/beryl-3d.md 'Elements', 'Sizes', 'The frame' (bands 5 to 7, Resolved). Code: beryl_scene src/layout/mod.rs (Layer, show, reconcile, relayout, root_style, and milestone 2's float, set_float_look), src/layout/write.rs, src/element/mod.rs (the fields the contract added), src/table/camera.rs (projecting a scene point to the window), src/client.rs (Client::frame), tests/flat_layer.rs.

What is missing. The layer matches a new tree against the old one by position only, knows flexbox only, and places floats at points. The screens of this milestone need the rest of CSS layout that the contract's Style names, and elements that follow a card or a player.

Build, in beryl_scene src/layout:

  1. Reconciliation by name and position: a child is matched to the old child with the same role and name, or, among children with neither, the one at the same index. A matched node keeps its taffy node, its laid-out text and its id; an unmatched one gets a new id; a node that moves among its siblings keeps its id. Children are matched in one pass with no allocation when the order is unchanged.
  2. Every Style field the contract added except overflow, opacity and focus (the next bead's): map each to taffy's style (Display::Grid with the track lists, Position::Absolute with inset, min and max sizes, margin, shrink, basis, wrap, align_self). taffy 0.15.1's grid is behind its default grid feature: enable it in beryl_scene's Cargo.toml if the build says it is off.
  3. background, border and radius written as a Panel record (see how Layer::write writes the prompt bar's panel today, has_panel), and color as the text's color.
  4. Anchors. An element with anchor: Some(Anchor::Point(..)) is laid out at its content's size outside its parent's flow, like milestone 2's floats; Anchor::Object(subject, at) puts the given point of its box at that scene object's centre projected by the camera, read on every frame from the table's current pose with no layout and no allocation, as set_float_look moves a float. Re-express milestone 2's floats as anchored elements if that removes code; keep Layer::float and FloatId as its callers use them.
  5. Remove the 'the elements track' notes from the fields this bead builds.

Do not build: scrolling, clips, transitions, focus or keys (the next bead), text spans (the text bead), widgets.

Tests, in beryl_scene/tests/flat_layer.rs: two siblings swapped keep their ids and their Frame::work.layout_nodes is 2, not the whole tree; a grid of [Points(100), Fraction(1)] in a 400-point row puts the second column at x 100 with width 300; an absolute child with inset right 10 and bottom 20 sits there in its parent; an element anchored to a card stays centred on the card while the card flies in verbs-zones, with no layout work in those frames; a frame after an anchored card moves allocates nothing.

Run: just b3d cargo-test -p beryl_scene; just b3d test b3d:pay-default; just b3d lane.

Acceptance criteria

The five tests pass; just b3d test reports no new fault; just b3d gate passes without --update, or the commit body gives the old and new counts; no file in src/layout is over 800 lines.

Handoff: beryl_scene src/layout split into reconcile.rs (match by role+name, unnamed by index among unnamed; in-order fast path allocates nothing; link_children keeps anchored children out of the parent's taffy children), style.rs (taffy_style: display grid/none, position+inset, min/max, margin, shrink, basis, wrap, align_self, grid tracks/lines, border width as taffy border), anchor.rs (Layer::follow, Node::corner, layout::centre_of). An anchored element is its own taffy root laid out at max content (CONTENT); Layer::relayout computes dirty anchored roots via compute_anchored; place() lays anchored children from (0,0) and write/press_at offset them by Node::corner(). Anchor::Object reads the card/ability centre from what the table already wrote this frame (Frame::centre / FrameBuilder::centre, by element id), players from table.player_pose; Client::frame calls follow right after show.frame. A node whose object is not drawn is skipped in write and press. Panels: write.rs panel() draws under buttons/screen tops as before, plus any element with background or border; radius 0 keeps the usual radius. style.color tints text (after a float look's tint). Floats were left as they are: re-expressing them as anchored elements would not remove code, because prepare/show_prepared still need their own lists. Deviations: the tests are in tests/all/elements.rs, not flat_layer.rs, because flat_layer.rs is 660 lines and adding them would pass the 800-line limit. The anchored-to-a-flying-card test uses a hand-built flight (common::three_beats), not the verbs-zones recording, which beryl_scene's tests can't load. The allocation check is in tests/frame_allocation.rs. verbs-zones handle_allocations limit lowered 9057 -> 9049. Overflow, opacity and focus are left to the next bead.
