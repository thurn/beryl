Description

Milestone 8 of Project 50k (run epic by-w8gv; plan docs/project-50k.md, "Authoring tools", decisions K16). Read the plan's sections named here and enact brief on this bead before starting. This milestone starts once M7b (by-w8gv.13) closes: read its beads' handoffs for the set crates, the generated registry and characteristics, and the card store as they landed.

K16: "Forge is a test oracle and a census of mechanics." Plan "Authoring tools": "A census tool parses the scripts only to count which mechanics block the most cards." M8 scope: "a parser in tools/ over the card scripts in $BERYL_CACHE/oracles/forge that counts effect, trigger, static and replacement kinds by cards using them and, against the vocabulary as built, lists the missing mechanics ordered by cards blocked (the backlog for docs/rules-coverage.md). Counts only: it never emits a definition."

What to build

  1. tools/src/beryl_tools/census.py, run as just census (add a justfile recipe in the data group): reads every script under $BERYL_CACHE/oracles/forge/forge-gui/res/cardsfolder (the path forge.py already uses for the checkout; reuse its constant), restricted to cards in the card store (card_store.py: the pool, by name), and counts, for each kind, the cards that use it: effect kinds (A:/SVar: lines' AB$, SP$, DB$ API names), trigger modes (T: Mode$), static modes (S: Mode$), replacement events (R: Event$) and keywords (K:). Parse just those fields; never read a script's parameters into anything but a count.
  2. Coverage against the vocabulary. A data file, data/census-coverage.json, maps each Forge kind name to whether Beryl's vocabulary covers it and, if so, the beryl_card entry that does (Effect::Draw, TriggerEvent::…, a keyword constant), checked against tools/src/beryl_tools/vocabulary.py's entries so a stale entry fails a test. Kinds not in the file count as uncovered. Fill it for every kind used by more than 50 in-pool cards; leave the long tail uncovered. This file holds Forge kind names and Beryl entry names only: no Forge parameter, text or logic (K16).
  3. The report. A card is blocked when any kind it uses is uncovered. Print and write to $BERYL_CACHE/census.json (not the repo): counts per kind, the share of in-pool cards fully covered, and the uncovered kinds ordered by the cards that only that kind blocks and then by cards it blocks at all. Record the top 30 on the milestone epic by-w8gv.15 and add a short "Census" section to docs/rules-coverage.md with the command and the top 15 (that document is the backlog this feeds; edit it in place, add no new Markdown file).
  4. Tests in tools/tests on a few synthetic script files (no real Forge script committed), pyre strict.

Files

tools/src/beryl_tools/census.py (new), forge.py (its checkout constant only), card_store.py, vocabulary.py, the justfile, data/census-coverage.json, docs/rules-coverage.md. Need not read: anything in rust/, xmage*.py, the UI. Run just oracle-setup once if $BERYL_CACHE/oracles/forge is missing.

Parity at the push (plan K11)

just check passes; the frozen save corpus replays (cargo test -p beryl_session --test corpus); rollouts_never_change holds (rust/crates/beryl_bench/src/rollout.rs); slow CI's counts lane (just count-gate, bar 405,276,238 instructions, 1% tolerance, rust/crates/beryl_bench/count-gate.toml) passes with no bump to the bar. Never delete a card implementation. Work the card-names and file-length allowlists (data/card-names-allowlist.json, data/file-length-allowlist.json) down in the files you touch; no new source file over 800 lines. K16: Beryl stays Apache-2.0, and no definition, vocabulary entry, template or brief is derived from a Forge script or from Forge's code. Record decisions and anything this packet got wrong as comments on the bead; nobody answers questions (K31): proceed on the default given and record it.

Acceptance criteria
