Description

Read the epic by-r61mr first: it holds the decisions, the code map and the directory layout this bead assumes. The work is in the Enact repository (~/enact) unless this bead says otherwise, delivered with that repository's own enact worktree create and enact push.

The free plan allows 100,000 rows written a day, and a full import of Beryl's 4,644 beads with their history may need more than a day's share (the importer bead recorded how many). Run tk import against the production server for Beryl, closed beads first, once a day until tk compare reports no differences, leaving the share of the limit the contract reserves.

The bead store keeps changing while this runs. That is expected: each run imports what changed, and the cutover's final import takes the rest. The dashboard will show the imported tickets; that is fine.

This is the cutover's second gate, "a rehearsal import matches the bead store ticket for ticket". Record each day's rows written and remaining differences in a comment on this bead.

Acceptance criteria

tk compare between Beryl's bead store and the production server reports differences only for beads changed since the last run, and a run made immediately afterwards writes rows only for those. No day's rows written passed the limit.
