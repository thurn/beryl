Close reason

Typed object references landed at eb61cf4aa. Count gate passed from 379,367,575 to 379,552,664 instructions (+0.05%). State<Small> is 20,240 bytes before and after.

Description

Why

Seven logged bugs were the wrong kind of object assumed: a Treasure token counted as a graveyard card, a hidden card behind a copy, a spell that had left the stack. Today every rules function takes an untyped ObjectRef<L> (a slot and an incarnation that each zone move bumps), tests State::is_current itself, and reads the zone at run time. Plan: Designs B5, which this bead may amend.

What to build

In rust/crates/beryl_kernel/src/ (object.rs or a new reference.rs, query.rs, mutate.rs, zone.rs, relayout.rs, lib.rs):

  • Permanent<L>, Spell<L> (a spell or an ability's stack entry, as the code needs), CardIn<Z, L> for a card that is not a token or a copy in one zone, and the set types Permanents<L> and Cards<Z, L>. All are transparent wrappers of ObjectRef or Bitboard, so State does not grow.
  • Only kernel queries make one, each checking: State::permanent(ObjectRef) -> Option<Permanent>, State::permanents(), State::cards_in(player, zone) with tokens left out, and the like. An incarnation changes on every zone move, so a typed reference that is still current is still in its zone: State::current(reference) is the one staleness test.
  • The kernel's mutators take the type they mean. Relayout maps the types as it maps ObjectRef.
  • The bare slots that bypass ObjectRef today (Memo::ExiledWith, Memo::PartOf, Object::attached_to, AttackTarget::Planeswalker, Affects::Object) become references, or the contract says why each is safe.
  • Convert three rules modules as the pattern the module passes will copy: beryl_rules/src/zones.rs, actions/destroy.rs and counters.rs, and interpret/run.rs's Run::permanents, which becomes the place a vocabulary Objects value turns into a typed set.
  • Rewrite "Entities and records" in the kernel contract, and add a short section the module passes follow: which type each kind of rules function takes, and how a caller in a module not yet converted adapts with one line.

ObjectRef's incarnation is 16 bits and wraps. Say in the contract what holds after 65,536 moves of one slot, and add the invariant or the widening that makes it true.

The exile cost that counted a Treasure (docs/bugs.md, "Exile costs counted a Treasure") must now fail to compile if written the old way: show it in a compile_fail doctest.

Bars (every bead of this epic)

  • The plan is docs/project-50k-part-2.md. If its design is wrong for the code, build what is right and amend the plan's section in the same push. Never wait for an answer: record the choice in this bead.
  • The absent-cost gate holds with no bump (just count-gate). When you touched the kernel, the rules or the card vocabulary, report the count before and after in the close reason. If it cannot hold after three attempts, stop and say so on the epic: this is the one thing that stops the run.
  • size_of::<State<Small>>() stays within 20,480 bytes. Report the size if you changed it.
  • The frozen saves replay and rollouts_never_change holds (just test-rust).
  • Rules code cites the Comprehensive Rules with a quotation (just citations). A card file cites a rule only for a card-specific ruling.
  • A new card follows the card-writing skill and passes just card check <name> (Beryl, XMage and Forge). A keystone or partner is listed in data/rulings-ledger.json once that file exists, with every ruling a scenario or a reason.
  • No UI work. beryl_cli script-check must pass for a new card from both seats with the verbs and prompt shapes that exist.
  • A rules bug found on the way gets its docs/bugs.md entry, naming the guard that now stops its class.
  • A bead you file is tier:opus for design, keystones and reviews, tier:sonnet for partner cards, sweeps and measurements, and never tier:fable.

Acceptance criteria

The types and queries exist with the contract section. The three modules use them. A compile_fail doctest shows a token cannot be passed as a graveyard card. The count is reported and holds. State<Small>'s size is unchanged.
