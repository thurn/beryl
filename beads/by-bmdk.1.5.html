Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'Permissions'.

Fill rust/crates/beryl_table/src/permissions.rs: pub fn check(table: &Table, by: Seat, action: &Action) -> Result<(), Refusal>, called by apply before anything changes.

  • Implement every row of the doc's Permissions table. A hand, library or sideboard belongs to its owner; another seat may act on a card in it only if that card is revealed to them (they are in its known_to and it is in a hand) or the zone is lent to them.
  • peek is for the card's controller. Decks, readiness and concession belong to their seat.
  • Stale check: every object the action names must be in the zone the action says it was seen in; otherwise Refusal::Stale. Run this before the permission check.
  • An action naming an object or seat that does not exist is Refusal::Invalid.
  • batch is allowed only if every member is allowed.
  • A refused action changes nothing and produces no Entry.

Tests in tests/permissions.rs: for each row of the table, one allowed and one refused case, named after the row; the revealed-hand discard example from the doc as a test (seat 0 reveals, seat 1 moves the card to seat 0's graveyard); the stale case. Run just test-rust -p beryl_table.

Acceptance criteria

check() is wired into apply; every Permissions row has an allowed and a refused test; stale and invalid actions are refused without changing the table.
