Derek Thurn2026-11-13

Cause: 0b9902ff (year crates) reordered CARDS; beryl_cards::generate built its random pools in CARDS order, so all 100 Generated oracle scenarios changed. Windows skips the oracle lane, so the commit reached master and every later macOS run failed (bisect blamed nothing since master). Generated 39/xmage was a separate, older flake: the XMage exporter's pay() read taps only at the position after a cast, which for an X spell is the X answer, so XMage auto-paid and sometimes spent the white Adeline needed.

Derek Thurn2026-11-13
