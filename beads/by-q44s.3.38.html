PROBLEMS FOUND AND FIXED

  • The web timelines' cache missed most of what the web timeline reads (66b60fe71). Its hash covered ui/src/stage, ui/src/game and timeline.mjs, but the script also loads cardRecords.ts, the constants of components/Card.tsx, generated/protocol.ts, ipc.ts and (through stage/timing.ts) data/ui-conventions.json, so a change to those kept a stale web timeline. The hash now follows the relative imports from timeline.mjs (web_sources) plus ui/package-lock.json. A new test changes each reached file, including JSON outside ui/, and requires the hash to move, and requires it to stay put for a file nothing imports.
  • The count gate failed on staging (6848630f5). stress-255 frame 30 counted 3,267,119 against its 2,442,066 limit (+33.8%, past the 20% build-out tolerance). With kept_in_window (47967ad95, fly.rs) switched off it counted 2,454,163, so the rise is that per-flight sampling, about 140 instructions a sample over 255 flights x 23 samples. That is new work, so the limits rose to what was measured, with the numbers in the commit.
  • Catch-up holds (by-q44s.3.66, now closed by another session): the no-more-lies and verbs-place-theirs entries were a native mistake, holds converted at the new script's rate after a double-speed script, not a layout difference.
  • docs/beryl-3d.md 'Test speed' now describes the per-rule judged line.
