Replacement statics and object rule changes from under a merged permanent; Gemrazer over Hullbreacher and Bloodghast pass Beryl/XMage/Forge; count gate holds, no bump

Description

What is wrong

A merged permanent (CR 731) has every ability of each card that represents it (CR 702.140e). Since by-bajq.8.8, State::abilities yields ObjectAbility::Merged(place, index) for the abilities of the cards under it, and activation, the mana solver, the layers (static abilities with a continuous effect, layers/merged.rs), the listening and replacing masks and player rule changes (layers/player_rules.rs) read them. Two kinds of reader still skip them, because they keep an AbilityIx on the permanent's own face as an ability's identity:

  • static replacement abilities: replace::statics (beryl_rules/src/replace.rs) drops every ability that is not ObjectAbility::Own; its callers record Source::Ability(slot, AbilityIx) (replace.rs entering_destinations, static_destinations), DrawReplacement::index and the sink's applied list (replace/draws.rs), and Key::Ability (replace/damage.rs);
  • object rule changes: rule_change::maker_of and the mask readers in beryl_rules/src/rule_change.rs read the top face only (Copiable::rules).

So a creature with If ... would ..., instead or a cost-changing static ability, put under Gemrazer, loses it silently.

What to build

Give a replacement's and rule change's source an identity that can name a card under a merged permanent (the card, face and index, as AbilityRef does for the stack), make replace::statics and maker_of yield merged abilities, and read static_condition_holds for them with that card's face.

Acceptance

  • Scenarios in Gemrazer's file: Gemrazer over a non-Human creature with a static replacement ability (implement a real one if none exists, e.g. a creature with "If a source would deal damage ..., it deals double") and over one with an object rule change; the effect applies. They pass on Beryl, XMage and Forge.
  • just count-gate holds with no bump; just test-rust.
