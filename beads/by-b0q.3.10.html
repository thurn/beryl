Warden review of by-b0q.3.1 (5d16d07); fixes in ed3bac8.

Acceptance re-verified on staging by running it:

  • greedy v random, 200 seeded games, --check: 192/200 (96.0%), 193/200 (96.5%), 192/200 (96.0%) for seeds 1-3 after the seed fix.
  • 10,000 random mirror games, release build with debug assertions and overflow checks, --check: 0 invariant failures, 0 stalls, 0 draws (4992-5008, 28.0 turns, 253 decisions, 2.2 s wall). Greedy mirror 1000 games: 504-496, 0 stalls.
  • Zero allocations in 8 rollouts (tests/allocations.rs) still holds. Transcript format (both hands and boards, P/T, counters, tapped; decider, kind, candidates, choice) checked against just play output.

Found and fixed:

  1. Tournament seeds overlapped. game_seed XORed the game index into the raw seed, so for N games divisible by a small power of two, seeds 1, 3 and 7 played the same set of games in a different order (seeds 1/3/7 all gave 192-8 with identical means; the epic's 10k at seed 7 and mine at seed 11 were both 5041-4959). Now the seed is hashed before mixing. Test: different_seeds_play_different_games.
  2. The rollout policy scried every card to the bottom, most valuable first (ChooseUpTo scored objects by value and Done as None, so Done was never picked). Only reachable after Aang's Iceberg's waterbend, which greedy never activates, but searchers that activate it would get bad rollouts. Now a library card goes to the bottom only when worth less than 30 in hand (a flood land; lands while short and every real spell stay). Test: a_rollout_scry_keeps_the_card_worth_drawing (fails on the old policy).
  3. Added wins_go_to_the_agent_not_the_seat: a seat-attribution bug in the tournament would have gone unnoticed (only Wilson and pairings were tested).

Checked and left alone: other decision kinds against their engine call sites (Brainstorm puts back least valuable, Thundertrap/Spellbinder take most valuable, Time Spiral untaps all lands, unless-pays always pays); no timing-dependent tests; search+cli tests take ~5 s debug. Nits not fixed: play silently accepts --games/--json/--check, tournament ignores --out; targeting reads only the first target spec's friendliness; kills() ignores first strike/deathtouch (fine for D21).
