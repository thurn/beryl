Description

Card

Containment Priest: flash; "If a nontoken creature would enter and it wasn't cast, exile it instead."

What it needs

  • "Wasn't cast": the entering proposal says whether the object is the permanent a spell becomes as it resolves. event::Entry knows what its caller is (resolve.rs for a permanent spell, everything else for the rest); make that a field of the proposal, not a guess from the zone it left.
  • "Creature" is asked of the object as it would exist on the battlefield (by-bajq.2.5): an enchantment that Opalescence would make a creature is exiled, and a creature card that would enter face down as a 2/2 is a creature.
  • The Priest's own entering is not replaced by itself when it is put onto the battlefield (CR 614.12: it is not yet on the battlefield as the event is modified).

Scenarios

Flickerwisp's missing vocabulary is built by by-bajq.3.14 and the card by by-bajq.3.6; this bead waits for both (edges), so do not build them here.

With Flickerwisp (by-bajq.3.6): the permanent Flickerwisp exiled returns at the end step, wasn't cast, and is exiled instead if it is a creature. A creature spell resolving enters. A token enters. The interaction with Animate Dead is a scenario of by-bajq.8.2.

Files

The card's file, beryl_rules/src/{event.rs, replace.rs, resolve.rs}.

Decisions: (1) 'Wasn't cast' is replace::Move::cast, set from the batch's Reason::Resolve (only enter_battlefield in resolve.rs moves for it), not a field of event::Entry: the extra byte in Entry, which move_batch_to default-fills 128 times, cost the rollout count +0.4%. (2) Replaced::Enters { objects, not_cast } + Replacement::enters_not_cast; kernel replacement::check maps it to ReplacementKind::Move, so it is gated with Rest in Peace's PutInto. (3) New Filter::Token (nontoken = Not(Token)). (4) The filter is asked of the object as it would exist on the battlefield via layers::entered (closure over a state copy; as_it_would_exist now uses it). Count gate: base 391,993,166 -> 392,174,653 (+0.05%, no bump). State<Small> unchanged (no state fields). Rulings: 'enters at the same time as other creatures' has no scenario (no card in the pool puts a Priest and a creature onto the battlefield together); the code handles it (each move of a batch is proposed before any moves). The March of the Machines ruling is shown with Opalescence (XMage divergence, CR 614.12). Manifest under the Priest: no card scenario, since XMage manifests the card and Forge graveyards it, so no divergence can be recorded; a unit test covers it.
