Architecture audit of milestone 5 (M5: rules library and card port) of epic by-w8gv.

Audit against docs/project-50k.md, not against taste:

  • Each decision this milestone implements (K ids in the milestone's description) is implemented as decided, or the deviation and its evidence are recorded on the milestone epic.
  • The conventions hold in new code: no card name in generic code, no file over 800 lines added to the allowlist, no procedural macros, words spelled out, no runtime dependency in the kernel, rules or card crates.
  • Nothing shaped by Forge has entered the engine or the vocabulary: string-typed parameters, script-variable indirection, per-card AI hints, or an entry whose only justification is that Forge has it (K16).
  • The hot path did not gain a general hook that runs in case some card cares (docs/rules-coverage.md, Principles).
  • The next milestone's plan section still fits the code as it now stands; if not, file the correction as a child here so the decompose bead sees it. File important findings as children of this gate epic. Do not rerun tournaments.

Audit against docs/project-50k.md:

  • K5 as decided: EffectCtx is gone; the library is free functions over Game and Resolution in modules named for their rules (actions/, keywords/, life, damage, counters, tokens, zones, ...), each with its arm; Run::instruction is the one table. Recorded deviations, both in beryl_rules/src/lib.rs's contract: library scenarios live in beryl_cards/src/library (rules code names no card), and the engine's own code (60 functions) still passes state, table and sink apart, converted as touched. English templates wait for M8 as planned.
  • K3 as decided: 234 generated scenarios, hand-written ones per library entry held by the tiering test, 9 props, scenarios behind a feature the app never builds.
  • Conventions hold: no Rust body in any card; card-names mechanics list empty and no names entry in kernel, rules or vocabulary; file-length allowlist is xmage.py alone, largest non-test engine file 768 lines; no procedural macro; kernel, rules and card crates have no runtime dependency.
  • K16: nothing Forge-shaped. No string-typed parameter (the only strings are names), references are typed values (Objects::Those, Amount::ThatMany), no AI hint: Takes and asks are computed from the data.
  • Hot path: no general hook. coverage::hit is empty without the test-only feature; triggers match through a per-kind listener index; the rollout count fell from 405.3M to 389.3M with no bump.
  • M7b's plan fits; facts for its decomposition are on by-w8gv.13.1 (scenario crate pulls the engine into set crates' test builds; 2.8 ms a card to check against the plan's 0.9).

Design judged sound, not filed:

  • The vocabulary says more than the engine carries out in seven places, each refused as the card compiles (Malformed: Fateseal of one, CounterInto exile only, copy exception 1/1, MayCast last, one ChangeRule, two Unless costs, two permission durations). That is the right shape: a widening is a mechanics job, and a card's generated scenarios catch a panic the check misses.
  • Entries that are an action plus a rider (ExileLinked, ExileUntilThisLeaves, CreateAttackingTokens, CounterInto, GainFlashback, ReturnTransformed) will multiply with the pool; fold a rider into its action's operands when a second card needs a second rider, not before.
  • Adding an entry touches seven sites in five files (two exhaustive matches for asks and takes, operands, builder, arm, table). Acceptable; the compiler lists them.
  • Single-letter bindings (s, t, d, e in Scene and the engine) predate M5.
  • Slow CI ran 480 to 615 wall seconds on a loaded Mac; the Steward beads of the last two days are all browser lanes and infrastructure, the CI track's, none from M5's code. repo:file-length failed at f553102d and a65a9389 and passes at 8e6fc07c.
