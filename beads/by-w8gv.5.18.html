712.8 -> 712.6; 712.8a -> 712.6a; 712.8b and 712.8c (a spell's faces) -> 712.6b; 712.8d -> 712.6c; 712.8e -> 712.6d; 712.8f -> 712.6e; 712.11 -> 712.8, 712.11a -> 712.8a, 712.11b -> 712.8b, 712.11c -> 712.8c; 712.12 -> 712.9; 712.13 -> 712.10; 712.14 -> 712.11, 712.14a -> 712.11a, 712.14b -> 712.11b; 712.15 -> 712.12, 712.15a -> 712.12a. Confirm each against the page by what the citing comment says, not by this table alone. Other rules moved or were reworded too: 401.1's "single face-down pile" is 401.2 ("Each library must be kept in a single face-down pile."), 402.3 now ends "look at it at any time", 707.2's list now ends "loyalty, and/or defense".
