Description

Read first: epic by-bmdk, sections 'Rules for every bead', 'Contracts' and 'Code map'. Design: docs/manual-multiplayer.md ("the doc"), section 'The log, undo and rewind'.

How interface beads in this milestone fit together: ui/src/table/client.ts (bead "Table screen") is the manual table's pointer client. It owns the selection, sends actions with tableAct from ui/src/ipc.ts, and lets each interaction register handlers from its own file. Put your code in the file this bead names and register it; change client.ts only to add a registration point it lacks. Check your work on a live manual table in a headless browser: ui/scripts/table.mjs (same bead) starts one through the HTTP server and gives a Playwright page. Add one scripted check per behavior to ui/scripts/kept-table-<topic>.mjs and run it with just ui-test <title>.

File: ui/src/table/TableLog.tsx and tableLog.ts. The panel is GameLog in ui/src/game/Narration.tsx, with lines built in ui/src/game/log.ts; reuse the panel and its styles, and feed it from TableView.log instead of engine events.

  • One line per entry: number, who ("You" for the viewer, the other player's name otherwise), text. Struck entries (after a rewind) are drawn struck through.
  • Cmd+Z sends undo. If the reply is refused with blocked_by, open the log with those entries highlighted.
  • Every line offers "Rewind to here" (a row revealed on hover and in the line's context menu); it sends rewind. No confirmation.
  • A batch's line carries an "Undo" control either player may use.
  • The undo button engine games show under the gear (ui/src/game/Corner.tsx) sends the table's undo here.
  • Cmd+Shift+D ("Undo last draw") undoes the viewer's most recent draw entry.

Checks (kept-table-log.mjs): tap a land, Cmd+Z, it untaps and the log has "Undid: …"; draw, tap a land, undo the draw by key and see "(seen)"; look at the top card, shuffle, rewind to before the shuffle, the same card is on top; a blocked undo highlights the blocking lines. A fixture or kept moment with the log open and one struck line.

Acceptance criteria

The log lists redacted lines with struck entries; Cmd+Z undoes or highlights what blocks; any line rewinds; batch lines can be undone by either seat; headless checks cover the doc's four undo cases.
