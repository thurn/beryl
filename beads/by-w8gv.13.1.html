From the M5 Mason audit (by-w8gv.10.1), for decomposing M7b against the code as it stands at staging 8e6fc07c. The plan's M7b section still fits; no correction filed. Facts the plan does not have:

  • A card file outside its scenarios module imports beryl_card alone (checked across beryl_cards/src: every top-level use of beryl_engine is in lib.rs, decks.rs, generate.rs, derive/, library/ and tests). So a data-only set crate can depend on beryl_card alone, as planned. No card has a Rust body, so no set crate needs beryl_rules today.
  • A card's scenarios module imports beryl_scenario and beryl_engine (DecisionKind, TurnStep, Zone, Seat, CounterKind), and beryl_scenario depends on the beryl_engine facade (its lib.rs takes Castings, FaceIx, ObjectAbility, Purpose, CardTable, DecisionKind, Seat, TurnStep, Zone). With the scenarios feature on, every set crate therefore rebuilds on any rules edit. If the one-edit budget is to hold for test builds too, beryl_scenario's value types need to name only beryl_card and kernel ids; DecisionKind is the one that lives in the rules.
  • The rules library's hand-written scenarios (beryl_cards/src/library/, mirroring beryl_rules) name cards of several sets plus the props, so they belong in the registry crate, not a set crate; generate.rs, derive/ and props.rs likewise.
  • CARDS and SCENARIOS in beryl_cards/src/lib.rs are hand-kept lists in table order; table order is a card's index, which saves and rollouts see, so the generated registry must keep it or migrate.
  • Scale, measured now (just scale --cards 5000 --crates 5, machine loaded, CPU seconds): cold check 14.2 s, release build 9.0 s, one-card rebuild 1.3 s, peak 0.64 GiB. That is 2.8 ms a card for check against the plan's 0.9 ms (card() now checks each definition as it compiles, by-w8gv.9.13): 50,000 cards is about 142 CPU-seconds, so the 60 s budget needs the set crates to build at least three wide. The harness clones 36 of the 47 card files. Script checks cost 0.099 s a card (about 83 CPU-minutes at 50,000), so they stay selected by changed card, never a sweep.
