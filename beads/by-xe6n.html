Choice: replace with a deterministic test (trimmed in place), commit 09c61856. Evidence: no failure output was kept (run log has outcome only, no catch verdict). 1,420 local runs (300 + 1000 single-test at 24-64 parallel, 120 whole-binary) never failed. Code reading of session.rs/sessions.rs/game/prompts.rs found no race up to the confirming click: every test step there waits on a channel message or a synchronous click reply while the session thread waits on the human, shared.open is set before emit, latest is set before the channel send, and Sessions::click patches latest while the thread is blocked in commands.recv. The only part running beside live play was the tail after the confirm (second click refused + block on the next human decision against a random opponent); that tail duplicates sessions.rs's double-choose race check and the Game-level click refusal test, so it is removed and the test ends at the confirming click (Answered). If this check flakes again, the cause is in the head and the next worker should delete it. 20/20 parallel passes after the change.
