Close reason

Nightly check failures on staging file a deduplicated P1 Steward bead (209e4d8d)

Description

by-w8gv.13.10 moved the full oracle sweep off slow CI into the nightly (tools/src/beryl_tools/nightly.py, oracle_step), on the plan that a card broken by a rules change is found and filed the next morning. Today no nightly step files anything on failure: run_nightly/measure only write $BERYL_CACHE/nightly/log.jsonl, last-output.txt and the run log (runlog.Run with place='nightly'); K21's bisection and Steward filing (bisect.py, Enact's slow-CI failure path) cover slow CI only. So a nightly oracle, fuzz or motion failure on origin/staging reaches nobody.

Build: when a nightly step that logs checks (oracle_step, fuzz_step, motion_step) fails, file (or update, deduplicated by check) a P1 bead with role:executor naming the commit, the failed run-log checks and the tail of last-output.txt, so a Steward or executor picks it up; optionally bisect the failed checks over the commits since the last nightly that passed them (reuse bisect.search with the step's narrowed command, e.g. 'by oracle <cards>'). Read nightly.py (measure, STEPS), runlog.py (Run, read_log), bisect.py (search, answer) and how Enact files Steward beads for slow-CI failures. Tests in tools/tests/test_nightly.py with fake steps and a fake bd.

Acceptance criteria

A failing nightly step's checks on origin/staging produce one bead (no duplicate on the next night's repeat failure) naming the commit and failed checks; a passing night files nothing; tests cover both; just check passes.

Deviation: filed beads are role:steward (P1, no parent), not role:executor as the description said. Enact's schedule() takes up parentless beads only when they are Stewards, so a parentless executor bead would reach no vizier. They carry no enact_ci_os/enact_ci_range (so Enact never folds slow-CI failures into them or treats them as covering a CI range) and set enact_ci_host so this machine's viziers take them first. Bisection (optional) not built: the bead names the last nightly commit that passed every step and the replay command instead.
