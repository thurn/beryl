Derek Thurn2026-11-06

Warden review of by-2l8.2 (cd02805), fixes in staging aeab4fc. Found and fixed:

  • Hidden-information leak: Observation::decisions counted decisions offered to either player; a player with only a pass is silent, so the count revealed whether the opponent held a castable card, and reuse was gated on it. Removed the accessor; each tree's replay must now reach the decision with no other decision between and show the whole public view the game shows (turn, players, stack, triggers, permissions, every object as known), which also covers an opponent acting without a zone change. Reuse count in the test games unchanged (18 either way). The reuse test now asserts no other player's action (anything but a priority pass) comes between reused decisions, instead of the leaky offered-decision index.
  • The 1k/10k x 200 exact-stop test was #[ignore]d (no check ran it). I ran it once in release on cd02805: passed, 224 s. Deleted it; added an exhaustive unit test of the stop rule against brute force (one tree and split across two). Mutation-checked: the in-suite game test still passed with the tie rule removed and with a plainly inexact rule (stop once lead + left/2 covers); the new test fails on both. Verified, no change: exact stop is exact (per-tree RNG makes sliced growth identical to unsliced); Pass is always the first priority candidate (decision.rs), so auto-pass's Choice(0) holds in release; per-decision seeding is the decision-th SplitMix64 output; resume_point/rebuilt-agent test passes; panicking tree still meets barriers. Left alone: the public-view comparison has no targeted test (an opponent's public action also stops every tree's replay, so it is defensive); rollout-saving figures are reported-only (6 games each), method checked, not rerun. Note: the fast check took 56 s of its 60 s budget on this push.
