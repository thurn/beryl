4. `tests`: go through public behaviour and cover cases the ticket did not name.

7. `fixed_or_filed`: dealt with a problem beside the code it was sent to change.
8. `verified`: exercised the change, or tested cases nobody asked for.
9. `pushed`: reached a finished result where the other gave up or landed less.
