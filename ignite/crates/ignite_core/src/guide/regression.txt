REGRESSION: a check that passed fails at the tip

This is the most urgent work there is: the main branch waits on it.

If upkeep switched the check off because it held the main branch back for
an hour with no record of catching a real defect, a comment on the ticket
says so. Fix or delete it as below, but do not switch it on yourself: tip
rounds at tips without your fix would fail it again. `ignite land` runs it
in your gate while it is off and switches it on once your fix is pushed.

Before you change anything:
- See whether the check still fails at the tip. If someone already fixed
  it, close the ticket with the commit. If it passes and you cannot find
  the fix, close it anyway, saying what you ran; never release it.
- Read the ticket that caused it, which this ticket links, to understand
  its intent before you change its work.
- A pass on another machine does not prove the failure was transient. Look
  for this machine's own state (caches, vendored files, tools) before you
  close it as already fixed.

Fixing it:
- Fix forward with a new commit. Do not revert someone's feature unless a
  fix is impractical, and if you revert, file a ticket to redo it
  properly.
- When the cause is in the product (a race, nondeterminism, a broken edge
  case), fix the product.
- When the fix changes only the test, delete the test or redesign it so
  it cannot fail for the same invalid reason. Keep essential coverage
  with a deterministic check. Adjusting the assertion alone, loosening
  a threshold or adding a retry leaves the cause in place.
- Say on the ticket which test you deleted or redesigned and why.
- When the ticket's comments show more failures that your fix does not
  cover, fix them too or file a ticket with the evidence.
- Filing that ticket does not move a check: the hub keeps reopening this
  one with it. Before you land, move each check you leave failing onto
  the follow-up ticket with `ignite ticket regression move <check>
  <ticket>`. `ignite land` and `ignite close` refuse while this ticket
  holds a check that is switched off, since no gate runs it.
- Run the repaired or replacement check before landing. If you deleted
  the check, verify that its family no longer lists it.

A failure of the machine itself is not a regression: ignite guide machine.
